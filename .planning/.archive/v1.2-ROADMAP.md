**Plans**: 2 plans

Plans:
- [x] 21-01: Auto-Generate Tools Reference (extraction + generation + verification)
- [x] 21-02: Add Missing Parameter Descriptions (gap closure)

**Details:**
Auto-generation infrastructure extracts tool metadata from FastMCP Tool object JSON Schema (not function introspection). Accesses tool registry via `_tool_manager._tools` for simpler synchronous extraction. Handles anyOf JSON Schema patterns for optional parameters. Escapes Jinja2 braces for TypeTable MDX syntax compatibility. Added Field descriptions to all 71 parameters across 5 modules achieving 100% parameter documentation coverage. Consistent description format: purpose + constraints + value ranges. Generated tools.mdx committed to git for version control and review.
