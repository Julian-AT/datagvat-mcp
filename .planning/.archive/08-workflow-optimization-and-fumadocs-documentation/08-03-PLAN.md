    ## Discovery Tools

    ### search_datasets

    Search for datasets with text queries and faceted filtering.

    **Parameters:**
    | Name | Type | Required | Description |
    |------|------|----------|-------------|
    | query | string | No | Search query for titles, descriptions, keywords |
    | themes | string[] | No | Filter by EU data theme codes (AGRI, SOCI, etc.) |
    | formats | string[] | No | Filter by file format (CSV, JSON, XML, PDF) |
    | limit | integer | No | Results per page (default: 20, max: 100) |

    **Returns:**
    ```json
    {
      "results": [...],
      "count": 1234,
      "facets": {...}
    }
    ```

    **Example:**
    ```python
    # In Claude Desktop
    search_datasets(query="population", themes=["SOCI"], limit=10)
    ```

    # Installation & Setup

    ## Prerequisites

    - Python 3.11 or higher
    - pip or uv package manager
    - Claude Desktop or compatible MCP client

    ## Installation

    ### Using pip
    ```bash
    pip install datagvat-mcp
    ```

    ### Using uv
    ```bash
    uv pip install datagvat-mcp
    ```

    ## Configuration

    Add to your Claude Desktop config (~/.claude/claude_desktop_config.json):
    ```json
    {
      "mcpServers": {
        "datagvat-local": {
          "command": "uv",
          "args": ["--directory", "/path/to/datagvat-mcp", "run", "datagvat-mcp"]
        }
      }
    }
    ```

    ## Environment Variables

    Optional configuration via .env file:
    - AUSTRIA_MCP_PIVEAU_API_BASE: API base URL (default: https://www.data.gv.at/api/hub/search)
    - AUSTRIA_MCP_REQUEST_TIMEOUT: Request timeout in seconds (default: 30)
    - AUSTRIA_MCP_LOG_LEVEL: Logging level (default: INFO)

    ## Verify Installation

    Restart Claude Desktop and run:
    ```
    list_catalogues(limit=5)
    ```

    You should see Austrian data catalogues listed.
