# Phase 03 Plan 01: Link Validation & Fixes

**Phase:** 03-link-validation-fixes
**Requirements:** CONTENT-02 (internal links valid), CONTENT-03 (external links valid)
**Wave:** 1 (single plan execution)

## Goal

Validate and fix all internal and external links in documentation after Phase 2 navigation restructuring. Ensure zero link errors through bulk automated fixes followed by targeted manual corrections.

## Context

Phase 2 changed URL paths from `/docs/tools/*` to `/docs/reference/tools/*`. All internal links pointing to the old paths need updating. The existing `bun run lint:links` infrastructure from Phase 1 (01-02, 01-04) provides validation capability with MDX component support (Card, Callout, Tabs hrefs).

From Phase 2 migration map:
- Only `/docs/tools/*` URLs changed to `/docs/reference/tools/*`
- All other URLs unchanged (folder groups don't affect routes)
- Link validator checks both markdown links `](/path)` and component hrefs `href="/path"`

## Success Criteria

1. Initial baseline captured in `.planning/phases/03-link-validation-fixes/broken-links-initial.txt`
2. All `/docs/tools/*` links updated to `/docs/reference/tools/*` (bulk automated fix)
3. All component hrefs with broken links fixed (targeted search and fix)
4. All invalid anchors resolved (add missing headings or update links)
5. Final validation returns zero link errors
6. Requirements CONTENT-02 and CONTENT-03 verified complete

## Tasks

### Task 1: Establish Baseline
**Goal:** Capture current link validation state before fixes

**Actions:**
1. Run link validation and capture output:
   ```bash
   cd docs
   bun run lint:links 2>&1 | tee ../.planning/phases/03-link-validation-fixes/broken-links-initial.txt
   ```
2. Analyze output to categorize errors:
   - Tool path errors (`/tools/` → `/reference/tools/`)
   - Component href errors (Card, Callout, Tabs)
   - Invalid anchor errors
   - External link errors

**Files created:**
- `.planning/phases/03-link-validation-fixes/broken-links-initial.txt`

**Commit:** `docs(03-01): capture initial link validation baseline`

---

### Task 2: Bulk Fix Tool Paths
**Goal:** Automated replacement of all `/tools/` → `/reference/tools/` links

**Actions:**
1. Fix markdown links:
   ```bash
   find docs/content/docs -name "*.mdx" -type f -exec sed -i 's|](/tools/|](/reference/tools/|g' {} \;
   ```
2. Fix component hrefs:
   ```bash
   find docs/content/docs -name "*.mdx" -type f -exec sed -i 's|href="/tools/|href="/reference/tools/|g' {} \;
   ```
3. Verify changes with grep:
   ```bash
   # Should find zero instances
   grep -r "](/tools/" docs/content/docs
   grep -r 'href="/tools/' docs/content/docs
   ```

**Expected changes:** ~50-100 link updates across documentation files

**Commit:** `fix(03-01): bulk update tool paths to /reference/tools/`

---

### Task 3: Fix Component Hrefs
**Goal:** Identify and fix broken hrefs in Card, Callout, Tabs components

**Actions:**
1. Run link validation again to identify remaining component errors
2. For each broken href error:
   - Locate component (Card, Callout, or Tabs.Tab)
   - Update href to correct path based on migration map
   - Verify path exists in file structure
3. Test sample pages to verify components render correctly

**Search patterns:**
```bash
# Find Card components with hrefs
grep -r '<Card.*href=' docs/content/docs

# Find Callout components with hrefs
grep -r '<Callout.*href=' docs/content/docs

# Find Tabs.Tab components with hrefs
grep -r '<Tabs.Tab.*href=' docs/content/docs
```

**Expected changes:** 10-20 component href updates

**Commit:** `fix(03-01): update component hrefs after navigation restructuring`

---

### Task 4: Fix Invalid Anchors
**Goal:** Resolve all broken anchor links (#heading references)

**Actions:**
1. Run link validation to get list of invalid anchors
2. For each invalid anchor error:
   - **Option A:** Add missing heading to target page (if heading should exist)
   - **Option B:** Update link to correct anchor (if heading name changed)
   - **Option C:** Remove anchor if no longer valid
3. Document decision rationale for each fix

**Expected changes:** 5-15 anchor corrections

**Commit:** `fix(03-01): resolve invalid anchor links`

---

### Task 5: Verify External Links (Optional)
**Goal:** Validate all external links are accessible

**Actions:**
1. Extract list of external links from validation output
2. If external link errors exist:
   - Verify each URL is accessible
   - Update broken URLs to current locations
   - Remove dead links or mark as deprecated
3. If no external link errors, document in summary

**Expected changes:** 0-5 external link updates (most should be valid)

**Commit:** `fix(03-01): update broken external links` (if any changes)

---

### Task 6: Final Verification
**Goal:** Confirm zero link errors

**Actions:**
1. Run final link validation:
   ```bash
   cd docs
   bun run lint:links
   ```
2. Should output: `✓ All links validated successfully`
3. Create verification report comparing initial vs final state
4. Document requirements fulfillment

**Files created:**
- `.planning/phases/03-link-validation-fixes/03-VERIFICATION.md`

**Commit:** `docs(03-01): verify zero link errors after fixes`
