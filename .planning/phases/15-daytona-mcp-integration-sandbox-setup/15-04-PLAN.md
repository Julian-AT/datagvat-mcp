Create React component that fetches /api/mcp/health and displays connection status.

- useEffect hook fetches /api/mcp/health on mount

- Display connection indicator for each MCP server:

  - Red dot + "Disconnected" when status: 'unhealthy'

- Show error messages when unhealthy
- Clean up interval on unmount

  allHealthy: boolean;
}
