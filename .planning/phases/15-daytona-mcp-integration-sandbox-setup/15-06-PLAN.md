<task type="auto">
  <name>Create reconnection module with exponential backoff</name>
  <files>docs/lib/mcp/reconnection.ts</files>
  <action>
Create module implementing retry logic with exponential backoff and connection state management.

**Export function:**
```typescript
export function createResilientMCPClient(options: ResilientClientOptions): {
  getClient: () => Promise<any>;
  getState: () => ConnectionState;
  reconnect: () => Promise<void>;
}
```

**Implementation details:**

1. **State management:**
   - Track current ConnectionState internally
   - Call options.onStateChange when state transitions
   - Initial state: 'connecting'

2. **Exponential backoff calculation:**
   - delay = Math.min(initialDelayMs * (backoffMultiplier ** attemptNumber), maxDelayMs)
   - Example: 1s, 2s, 4s, 8s, 16s, 30s (capped)

3. **getClient() logic:**
   - If client exists and connected, return cached client
   - If disconnected, trigger reconnect attempt
   - If retrying, wait for current attempt to complete
   - Throw error if max retries exceeded

4. **reconnect() logic:**
   - Loop up to maxRetries times
   - Set state to 'retrying'
   - Try to create client via options.createClient()
   - On success: set state to 'connected', cache client, return
   - On failure: wait exponential backoff delay, increment attempt, retry
   - After maxRetries: set state to 'disconnected', throw error

5. **Logging:**
   - console.log('[MCP Reconnection] Attempting connection... (attempt X/Y)')
   - console.log('[MCP Reconnection] Connected successfully')
   - console.warn('[MCP Reconnection] Connection failed, retrying in Xs...')
   - console.error('[MCP Reconnection] Max retries exceeded, giving up')

**Error handling:**
- Catch errors from options.createClient()
- Log errors but continue retry loop (don't propagate until max retries)
- Clear cached client on error (force reconnection)

**Why separate module:**
- Reusable for any MCP client (data.gv.at, future MCP servers)
- Single responsibility: reconnection logic only
- Testable in isolation
