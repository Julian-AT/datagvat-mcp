Create module that performs health checks on app startup with console logging.

```typescript
export async function performStartupHealthCheck(): Promise<void>
```

**Implementation:**
- Import checkMCPHealth from @/lib/mcp/health-checker
- Import createDataGvatClient from @/lib/mcp/datagvat-client
- Import createE2BClient from @/lib/mcp/e2b-client
- Use Promise.allSettled to check both services in parallel (same pattern as /api/mcp/health/route.ts)
- Log results to console with clear formatting:
  - console.log('[MCP Startup] Checking MCP server health...')
  - For each service: console.log('[MCP Startup] data.gv.at: healthy (23ms, 5 tools)') or console.warn('[MCP Startup] E2B: unhealthy - {error}')
  - Final summary: console.log('[MCP Startup] Health check complete - 2/2 services healthy')

- Log errors but don't throw (startup should continue even if health check fails)
- Use console.error for unexpected failures

**Why separate from /api/mcp/health:**
- Health API route runs per HTTP request
- Startup check runs once during app initialization
- Startup logging goes to server console (not HTTP response)
