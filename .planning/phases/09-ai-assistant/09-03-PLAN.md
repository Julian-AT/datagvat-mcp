Create three chat UI components following research Pattern 1 (useChat Hook) and Pattern 4 (Message Parts Rendering).

**File 1: docs/components/chat/chat-interface.tsx**

Main chat component structure:
```typescript
'use client';

import { useChat, DefaultChatTransport } from '@ai-sdk/react';
import { MessageList } from './message-list';
import { ChatInput } from './chat-input';

export function ChatInterface() {
  const { messages, sendMessage, status, error, stop, clearError } = useChat({
    transport: DefaultChatTransport({ api: '/api/chat' }),
    onError: (err) => console.error('Chat error:', err),
  });

  // ... render logic
}
```

Requirements:
- Use useChat hook with DefaultChatTransport pointing to /api/chat
- Layout: Flex column, full height (h-screen), max width 4xl, centered
- Three sections:
  1. Message list (flex-1, scrollable)
  2. Error display (if error exists) with dismiss button
  3. Input form (bottom, sticky)
- Show "Thinking..." with loading spinner when status === 'streaming'
- Disable input when status !== 'ready'
- Show Stop button when streaming
- Error banner with red background, clearError on dismiss

**File 2: docs/components/chat/message-list.tsx**

Message rendering component:
```typescript
'use client';

import type { UIMessage, UIMessagePart } from '@ai-sdk/react';

export function MessageList({ messages }: { messages: UIMessage[] }) { ... }
```

Requirements:
- Map over messages array
- Each message: Flexbox layout, user messages right-aligned, assistant left-aligned
- User messages: Primary background, white text
- Assistant messages: Muted background
- For each message, map over message.parts:
  - type === 'text': Render in prose div
  - type === 'tool-call': Show tool name and args in blue/10 background with 🔧 icon
  - type === 'tool-result': Show result in green/10 background with ✅ icon
- Tool calls/results: Use <pre> with JSON.stringify(data, null, 2)
- Tool results: Max height 160px (max-h-40), scrollable
- Use Tailwind classes for styling

**File 3: docs/components/chat/chat-input.tsx**

Input form component:
```typescript
'use client';

export function ChatInput({
  onSend,
  disabled,
  onStop,
  isStreaming,
}: {
  onSend: (text: string) => void;
  disabled: boolean;
  onStop?: () => void;
  isStreaming?: boolean;
}) { ... }
```

Requirements:
- Form with text input and submit button
- Input: Full width, border, rounded, padding
- Placeholder: "Ask about Austrian datasets..."
- Submit button: Primary background, disabled when disabled prop true
- Button text: "Sending..." when isStreaming, "Send" otherwise
- Show Stop button (type="button") when isStreaming
- onSubmit: preventDefault, check input not empty, call onSend(text), clear input
- Focus management: Focus input after send

AVOID:
- Using message.content instead of message.parts (Pitfall - AI SDK v6)
- Not checking status before enabling input (Pitfall - double-send)
- Rendering massive tool results without size limits (Pitfall 7)

Follow research "Basic Chat Interface Component" and "Message Parts Rendering" examples closely.
