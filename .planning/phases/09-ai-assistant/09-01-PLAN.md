<task type="auto">
  <name>Task 3: Create MCP to AI SDK tool converter</name>
  <files>docs/lib/mcp/tools.ts</files>
  <action>
Create `docs/lib/mcp/tools.ts` implementing conversion from MCP tool format to Vercel AI SDK tool format.

Function signature:
```typescript
export function convertMCPTools(mcpTools: Tool[]): Record<string, CoreTool>
```

Conversion logic:
1. For each MCP tool:
   - Extract name, description, inputSchema (JSON Schema)
   - Convert inputSchema to Zod schema (use z.object with properties from JSON Schema)
   - Create AI SDK tool() wrapper with:
     - description from MCP tool
     - inputSchema as Zod type
     - execute function that calls mcpClient.callTool(name, args)
2. Return object mapping tool names to AI SDK tools

Error handling in execute function:
- Wrap mcpClient.callTool in try/catch
- Return {error: true, message: error.message} on failure
- Return tool result content on success

JSON Schema to Zod conversion:
- type: "string" -> z.string()
- type: "number" -> z.number()
- type: "boolean" -> z.boolean()
- type: "array" -> z.array()
- type: "object" -> z.object()
- Handle optional fields (not in required array) with .optional()
- Handle anyOf patterns for nullable types

AVOID:
- Throwing errors from execute (breaks streaming)
- Blocking synchronous tool calls
- Returning undefined on error (return structured error object)

Reference research Pattern 2 for tool() wrapper structure and API route integration pattern.
  </action>
