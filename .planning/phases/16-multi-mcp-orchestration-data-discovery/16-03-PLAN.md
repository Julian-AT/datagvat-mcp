Update chat route to save messages after AI response stream completes and load conversation history at request start.

**Integration requirements:**
1. Import message persistence functions from Phase 14:
   ```typescript
   import { createMessage, getMessages } from '@/app/actions/messages';
   ```

2. Load conversation history at request start:
   - Extract conversationId from request body
   - Call getMessages(conversationId) to load previous messages
   - Convert to AI SDK CoreMessage format using convertToCoreMessages
   - Include in streamText messages array

3. Save messages after stream completes:
   - Use onFinish callback in streamText config
   - Save both user message and assistant response
   - Include tool_calls and tool_results in parts array
   - Associate with conversationId

**Implementation pattern:**
```typescript
// Load conversation history
const { conversationId, messages: clientMessages } = await request.json();
const dbMessages = conversationId ? await getMessages(conversationId, 50) : [];
const coreMessages = convertToCoreMessages([...dbMessages, ...clientMessages]);

// Stream with persistence
const result = streamText({
  model: getLanguageModel(selectedChatModel),
  messages: coreMessages,
  tools: await getAvailableTools(),
  onFinish: async ({ response }) => {
    // Save user message and assistant response
    const userMessage = clientMessages[clientMessages.length - 1];
    await createMessage(conversationId, userMessage);
    await createMessage(conversationId, response);
  },
  // ... rest of config
});
```

**Notes from Phase 14 (14-03-SUMMARY.md):**
- Database stores messages with JSONB parts array (AI SDK 6 pattern)
- Parts include: text, tool_call, tool_result types
- Cursor pagination available (not needed for Phase 16 - 50 message limit sufficient)
- Session tracking via conversationId (guest sessions from Phase 14-02)

**Error handling:**
- Wrap createMessage in try/catch (don't fail stream if persistence fails)
- Log persistence errors for debugging
- Continue stream even if database unavailable
