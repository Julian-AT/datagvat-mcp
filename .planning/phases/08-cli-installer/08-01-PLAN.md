<task type="auto">
  <name>Implement platform-specific tool detection</name>
  <files>
    packages/cli/src/paths.ts
    packages/cli/src/detect.ts
    packages/cli/src/types.ts
  </files>
  <action>
    Create tool detection logic using filesystem checks:

    **src/types.ts:**
    - Export type ToolName = 'claude-desktop' | 'continue' | 'cline'
    - Export type Platform = 'darwin' | 'win32' | 'linux'
    - Export interface ToolInfo { name: ToolName; configPath: string; detected: boolean }
    - Export interface DetectionResult { tools: ToolInfo[]; platform: Platform }

    **src/paths.ts:**
    - Export function getToolPaths(platform: Platform): Record<ToolName, string>
    - Platform-specific paths:
      - macOS: Claude Desktop: ~/Library/Application Support/Claude/claude_desktop_config.json
      - macOS: Continue: ~/.continue/config.json
      - macOS: Cline: ~/Library/Application Support/Code/User/globalStorage/saoudrizwan.claude-dev/settings/cline_mcp_settings.json
      - Windows: Claude Desktop: %APPDATA%\Claude\claude_desktop_config.json
      - Windows: Continue: %USERPROFILE%\.continue\config.json
      - Windows: Cline: %APPDATA%\Code\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json
      - Linux: Claude Desktop: ~/.config/Claude/claude_desktop_config.json
      - Linux: Continue: ~/.config/continue/config.json
      - Linux: Cline: ~/.config/Code/User/globalStorage/saoudrizwan.claude-dev/settings/cline_mcp_settings.json
    - Use os.homedir() and process.env for path resolution

    **src/detect.ts:**
    - Import fs.existsSync, path, os.platform()
    - Import getToolPaths from './paths.ts'
    - Export async function detectTools(): Promise<DetectionResult>
    - For each tool path, check fs.existsSync(configPath) OR fs.existsSync(path.dirname(configPath))
    - Return array of ToolInfo objects with detection status
    - Handle errors gracefully (missing permissions, paths don't exist)

    Use @types/node for fs/path types, handle Windows environment variables properly
  </action>
  <verify>
    bun test (create simple test in src/detect.test.ts that checks detection returns array)
    bun src/index.ts (manually test detection output with console.log in init command)
  </verify>
  <done>
    detectTools() returns DetectionResult with correct platform-specific paths
    Detection accurately identifies at least one tool on development machine
    No errors when tools are not installed (graceful detection)
  </done>
