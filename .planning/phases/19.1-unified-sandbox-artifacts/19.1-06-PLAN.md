<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete unified sandbox artifact system:
- Database: SandboxState table with persistence
- Tool: openSandbox AI tool for creating sandboxes
- UI: Tabbed sandbox artifact (Code/Output tabs with CodeMirror editor)
- Execution: E2B integration with streaming output and visualization upload
- State: SWR-based management with DB persistence across refresh
- Approval: Inline approval UI for first execution
  </what-built>

  <how-to-verify>
**Test 1: Basic Sandbox Creation (SANDBOX-01, SANDBOX-02)**
1. Start dev server: `bun run dev`
2. Open browser to http://localhost:3000
3. Create new chat
4. Ask: "Write Python code to calculate 2+2"
5. Verify: Sandbox artifact opens with code editor
6. Verify: Code tab shows Python code, Run button visible
7. Verify: Output tab empty until first run

**Test 2: Code Editing & Execution (SANDBOX-03, SANDBOX-04)**
1. In same sandbox, edit code to print("Hello World")
2. Click Run button
3. Verify: Inline approval UI appears (first run only)
4. Click Approve
5. Verify: Tab auto-switches to Output
6. Verify: "Hello World" displays in output pane
7. Click Run again
8. Verify: NO approval UI (subsequent run auto-executes)
9. Verify: Output clears and shows new execution result

**Test 3: Visualization Rendering (SANDBOX-05)**
1. Create new chat
2. Ask: "Create a matplotlib bar chart of [1, 2, 3, 4]"
3. Verify: Sandbox opens with matplotlib code
4. Approve and run code
5. Verify: Output tab shows thumbnail image (~400px width)
6. Click on thumbnail
7. Verify: Fullscreen overlay opens with full-size image
8. Close fullscreen
9. Verify: Returns to sandbox with thumbnail

**Test 4: State Persistence (SANDBOX-06)**
1. In chat with sandbox, edit code to custom content
2. Run code and verify output displays
3. Refresh page (Cmd+R / Ctrl+R)
4. Verify: Sandbox artifact still visible
5. Verify: Code editor shows edited code (not initial code)
6. Verify: Output tab shows previous execution results
7. Click Run again
8. Verify: No approval needed (hasApprovedOnce persisted)

**Test 5: Multiple Sandboxes (CONTEXT.md decision)**
1. In same chat, ask: "Now calculate factorial of 5"
2. Verify: Second sandbox opens
3. Verify: Both sandboxes visible simultaneously
4. Switch between sandboxes
5. Verify: Each maintains independent state

**Test 6: Error Handling**
1. Create sandbox with intentionally broken code: `print(undefined_variable)`
2. Approve and run
3. Verify: Error displays in output tab with red background
4. Verify: Python traceback shows clearly
5. Verify: Sandbox remains open (doesn't crash)

**Test 7: Denial Flow (CONTEXT.md decision)**
1. Create new sandbox
2. Click Run button
3. In approval UI, click Deny
4. Verify: Sandbox closes completely
5. Verify: Chat message shows "Execution denied"

**Test 8: AI Sandbox Decision (SANDBOX-07)**
1. Ask: "What is the capital of France?" (non-code question)
2. Verify: Regular chat response, NO sandbox opens
3. Ask: "Calculate the sum of 1 to 100 using Python"
4. Verify: Sandbox opens (code-related question)

**Test 9: Legacy Artifacts Unaffected (SANDBOX-08)**
1. Ask: "Write a blog post about AI" (text content)
2. Verify: Text artifact opens (NOT sandbox)
3. Ask: "Create a spreadsheet of sample data" (if sheet artifact exists)
4. Verify: Sheet artifact opens (NOT sandbox)
