## Decisions Made

- **API route pattern for execution:** Created /api/sandbox/execute rather than using server actions. Isolates E2B SDK calls to server context, makes future streaming implementation easier.
- **Batch response vs streaming:** Current implementation returns full result at once (no SSE/WebSockets). Acceptable for MVP since 30-second timeout limits execution duration. Streaming can be added later if needed.
- **Sandbox.connect for reuse:** Use E2B's Sandbox.connect() to reconnect to existing sandboxes instead of always creating new ones. Follows RESEARCH.md Pitfall 3 recommendation for faster execution and persistent workspace.
