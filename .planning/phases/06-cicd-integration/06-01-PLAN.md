<task type="auto">
  <name>Configure simple-git-hooks pre-commit validation</name>
  <files>
    docs/package.json
  </files>
  <action>
Add `simple-git-hooks` configuration section to docs/package.json after `devDependencies`:

```json
"simple-git-hooks": {
  "pre-commit": "cd docs && biome check --staged --write"
}
```

This uses Biome's `--staged` flag to check only staged files (fast, typically <2 seconds). The `--write` flag applies safe fixes automatically.

After adding configuration, run `bun run prepare` from docs/ directory to install the hook to .git/hooks/pre-commit.

**Why not full validation:** Link validation may be slow, so start with Biome-only pre-commit. CI runs full validation (lint + links + build).

**Why cd docs:** Hook runs from repository root, but biome.json is in docs/ subdirectory. The `cd docs` ensures Biome finds its config.

Test the hook by making a deliberate linting error in a test file, staging it, and attempting to commit. Hook should block commit and auto-fix if possible.
  </action>

2. Verify hook installed: `cat .git/hooks/pre-commit | grep "biome check"`
3. Test hook by creating test file with linting error, staging, and committing
  </verify>

<task type="auto">
  <name>Enhance GitHub Actions CI workflow</name>
  <files>
    .github/workflows/ci.yml
  </files>
  <action>
Enhance the existing `docs` job in .github/workflows/ci.yml:

1. **Add path filters** to only trigger when docs files change:
```yaml
on:
  push:
    branches: [ main, develop ]
    paths:
      - 'docs/**'
      - '.github/workflows/ci.yml'
  pull_request:
    branches: [ main, develop ]
    paths:
      - 'docs/**'
      - '.github/workflows/ci.yml'
```

2. **Use frozen lockfile** for reproducible builds:
Change `bun install` to `bun ci` (equivalent to `bun install --frozen-lockfile`).

3. **Add artifact upload** for main branch builds (7-day retention):
```yaml
- name: Upload build artifacts
  if: github.ref == 'refs/heads/main'
  uses: actions/upload-artifact@v4
  with:
    name: next-build
    path: docs/.next
    retention-days: 7
```

4. **Add commented-out preview deployment template** at end of file:
```yaml
# Uncomment to enable PR preview deployments
# preview:
#   runs-on: ubuntu-latest
#   if: github.event_name == 'pull_request'
#   needs: docs
#   steps:
#     - uses: actions/checkout@v4
#     - name: Deploy to Vercel
#       run: echo "Configure your deployment service here"
#       # Vercel: npx vercel --token=${{ secrets.VERCEL_TOKEN }}
#       # Netlify: npx netlify deploy --dir=docs/.next --prod
```

**Why path filters:** Prevents wasting CI minutes when only Python code changes.

**Why frozen lockfile:** Ensures reproducible builds, catches version drift early.

**Why artifact upload on main only:** Helps debug production build issues without storing every PR build.

**Why preview template commented out:** Deployment platform not chosen yet, requires secrets configuration.
