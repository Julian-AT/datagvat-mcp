## FastMCP Client Library

Austria MCP uses FastMCP for both server and client. Using FastMCP client library simplifies custom integrations.

### Installation
```bash
pip install fastmcp>=2.14.0
```

### In-Memory Client Pattern
For testing or embedded usage:
```python
from fastmcp import FastMCP, Context
from fastmcp.client import Client

# Import Austria MCP server
from app.server import mcp

async def use_austria_mcp():
    # Connect to server without subprocess
    async with Client(mcp) as client:
        # List available tools
        tools = await client.list_tools()

        # Call tool
        result = await client.call_tool(
            "search_datasets",
            arguments={"query": "population", "limit": 10}
        )

        print(result)
```

**Benefits:**
- No subprocess management
- No stdio parsing
- Type-safe tool calls
- 10-100x faster than subprocess for testing

### Subprocess Client Pattern
For production use with isolation:
```python
from fastmcp.client import SubprocessClient

async def use_austria_mcp_isolated():
    client = SubprocessClient(
        command="python",
        args=["-m", "app.server"],
        cwd="/path/to/mcp",
        env={"AUSTRIA_MCP_LOG_LEVEL": "INFO"}
    )

    async with client:
        # Same API as in-memory client
        tools = await client.list_tools()
        result = await client.call_tool("list_catalogues", {"limit": 5})
```

**When to use:**
- Production deployments
- Process isolation needed
- Different Python environments

### HTTP Client Pattern (SSE)
For web applications:
```python
from fastmcp.client import HTTPClient

async def use_austria_mcp_remote():
    client = HTTPClient(url="http://localhost:8080/sse")

    async with client:
        # Same API as other clients
        result = await client.call_tool(
            "semantic_search_datasets",
            {"natural_query": "health data from Vienna"}
        )
```

**Starting SSE server:**
```bash
fastmcp dev app.server:mcp --host 0.0.0.0 --port 8080
```

### Error Handling
FastMCP client automatically handles:
- Connection failures → raises ConnectionError
- Tool errors → raises ToolError with message
- Timeouts → raises TimeoutError

```python
from fastmcp.exceptions import ToolError, ConnectionError

try:
    result = await client.call_tool("get_dataset", {"id": "nonexistent"})
except ToolError as e:
    print(f"Tool failed: {e.message}")
except ConnectionError:
    print("Server unavailable")
```

### Type-Safe Calls with Pydantic
For production code with type safety:
```python
from pydantic import BaseModel

class SearchParams(BaseModel):
    query: str
    limit: int = 20

class SearchResult(BaseModel):
    results: list[dict]
    count: int

async def typed_search(query: str):
    params = SearchParams(query=query, limit=10)
    result = await client.call_tool("search_datasets", params.model_dump())
    return SearchResult(**result)
```
