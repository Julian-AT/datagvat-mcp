```typescript
interface SearchQuery {
  category: string;
  query: string;
  expectedPages: string[];  // Top 3 expected page paths
}

interface SearchResult {
  query: string;
  category: string;
  topResults: string[];     // Top 3 actual page paths
  relevant: boolean;        // True if top 3 include expected pages
  score: number;           // 0-3 (how many top results match expected)
}
```

**Implementation:**
1. Define all 50-60 queries with expected top results
2. For each query:
   - Programmatically query fumadocs search index (via search API if available, or parse generated search index JSON)

   - Compare against expected pages
   - Score: 3 = all top 3 relevant, 2 = 2/3 relevant, 1 = 1/3 relevant, 0 = none relevant
3. Generate comprehensive report by category
