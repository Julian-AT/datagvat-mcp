Create TypeScript script for stratified random sampling of code examples:

**Sampling Strategy:**
```typescript
interface CodeExample {
  page: string;
  section: string;  // guides, workflows, tutorials, api, integration
  language: string;
  code: string;
  line: number;
  filename?: string;
}

const samplingStrata = {
  guides: { targetSamples: 5 },
  workflows: { targetSamples: 5 },
  tutorials: { targetSamples: 3 },
  api: { targetSamples: 4 },
  integration: { targetSamples: 3 }
};
```

**Classification Rules (explicit logic for stratified sampling):**
```typescript
function classifyPage(page: Page): string {
  const url = page.url;

  // Explicit classification by URL prefix
  if (url.startsWith('/docs/guides/')) return 'guides';
  if (url.startsWith('/docs/workflows/')) return 'workflows';
  if (url.startsWith('/docs/tutorials/')) return 'tutorials';
  if (url.startsWith('/docs/api/') || url.startsWith('/docs/tools/')) return 'api';
  if (url.startsWith('/docs/integration/')) return 'integration';

  // Fallback for Getting Started section
  if (url.startsWith('/docs/quickstart') || url.startsWith('/docs/installation')) return 'tutorials';

  // Default to guides for any uncategorized content
  return 'guides';
}
```

**Extraction Process:**
1. Load all pages via `source.getPages()`
2. Classify page by section using classifyPage function above
3. Extract code blocks using `remark().parse()` + `unist-util-visit`
4. Filter to testable languages: typescript, python, bash (exclude json, yaml as non-executable)
5. Apply stratified random sampling within each section
6. Output 20 sampled examples with metadata

**Output Format (JSON):**
```json
{
  "totalExamples": 150,
  "sampledExamples": 20,
  "strata": {
    "guides": 5,
    "workflows": 5,
    ...
  },
  "examples": [
    {
      "id": 1,
      "page": "/docs/guides/searching",
      "language": "typescript",
      "code": "...",
      "line": 45
    }
  ]
}
```

Save to `.planning/phases/24-final-polish-a-quality/sampled-examples.json`
