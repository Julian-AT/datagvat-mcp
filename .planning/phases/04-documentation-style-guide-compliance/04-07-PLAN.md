  <action>
Apply Microsoft/Google style guide conventions to final documentation sections:

**Prescriptive Guidance (Critical for Best Practices):**
- Be prescriptive, not just descriptive: "Use quality threshold ≥85 for research" not "Quality thresholds vary"
- Clear guidance on what to do: "Set cache TTL to 15 minutes for search results" not "Consider caching"
- Specific thresholds and values: "DQV score 90-100 = Excellent" not "high quality"

**Style Principles:**
- Active voice, second person: "You configure" not "Configuration is done"
- Present tense: "The integration requires" not "will require"
- Contractions allowed for natural tone
- Sentence case headings
- Short sentences (<25 words)
- Code examples before explanations

**Real Examples and Thresholds:**
- Integration pages: Show real Claude Desktop config paths, real MCP server names
- Best practices: Use specific numbers (cache TTL: 15min, quality threshold: 70)
- Optimization: Real performance metrics from actual usage
- Quality interpretation: Exact DQV score ranges (90-100, 70-89, 50-69, 0-49)

**Remove AI Buzzwords:**
- Delete: delve, leverage, utilize, harness, robust, comprehensive, seamless
- Replace with direct actionable language (configure, implement, set, use)

**Remove Generic Openers:**
- Delete: "In today's...", "In the realm of..."
- Start with specific action or context

**Index Page Special Attention:**
- Landing page sets tone for entire documentation
- Must demonstrate professional quality immediately
- Clear value proposition without marketing language
- Action-first: get users to quickstart quickly

**Why:** Integration and best practices are WHERE USERS CONFIGURE SYSTEMS. Vague guidance leads to misconfiguration. Prescriptive thresholds enable immediate correct usage. Landing page is first impression of documentation quality.

**Preserve:**
- Fumadocs component imports (Cards, Tabs, Callout)
- Decision tables (enhance clarity, don't remove)
- Internal links (verified in Phase 3)
- Frontmatter metadata
- German content structure in .de.mdx files
