  <action>
Apply Microsoft/Google style guide conventions to best practices pages with CRITICAL FOCUS on prescriptive guidance, following validated approach from Batch 1.

**File-by-file processing order:**
1. quality-interpretation.mdx (foundational - DQV score ranges)

6. optimization.de.mdx (German translation)

For each file, apply:

**Prescriptive Guidance (PRIORITY for Best Practices):**
- Be prescriptive, not descriptive: "Use quality threshold ≥85 for research" not "Quality thresholds vary"
- Clear guidance on what to do: "Set cache TTL to 15 minutes for search results" not "Consider caching"
- Specific thresholds and values: "DQV score 90-100 = Excellent" not "high quality"
- Decision tables with exact numbers: Quality score ranges, cache TTL recommendations, rate limits

**Specific Threshold Examples to Include:**
- Quality interpretation: 90-100 (Excellent), 70-89 (Good), 50-69 (Fair), 0-49 (Poor)
- Cache TTL: Search results 15min, catalog metadata 1 hour, dataset metadata 30min
- Rate limiting: 10 requests/second for search, 5 for download
- Optimization: Response time target <200ms for search, <500ms for preview

**Style Principles:**
- Active voice, second person: "You set" not "Settings are configured"
- Present tense: "This improves" not "will improve"
- Contractions allowed for natural tone
- Sentence case headings
- Short sentences (<25 words)
- Code/config examples before explanations

**Remove Vague Language (CRITICAL):**
- Delete: "consider", "may want to", "you might", "possibly", "generally", "typically"
- Replace with: "use", "set", "configure", "implement" + specific values

**Remove AI Buzzwords:**
- Delete: delve, leverage, utilize, harness, robust, comprehensive, seamless
- Replace with direct technical terms

**Remove Generic Openers:**
- Delete: "In today's...", "In the realm of..."
- Start with specific recommendation or context

**Why:** Best practices guide real-world configuration. Vague recommendations lead to misconfiguration and poor performance. Specific thresholds enable immediate correct implementation.

**Preserve:**
- Decision tables (enhance with exact values)
- Fumadocs components (Callout, Tabs)
- Internal links (verified in Phase 3)
- Frontmatter metadata
- German content structure in .de.mdx files
