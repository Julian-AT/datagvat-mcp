<task type="auto">
  <name>Task 1: Remove duplicate H1 headings from all MDX files</name>
  <files>docs/content/docs/**/*.mdx</files>
  <action>
Find and fix all MDX files with duplicate H1 headings:

**1. Find files with manual H1 after frontmatter:**
```bash
cd docs/content/docs
# Search for pattern: frontmatter closing --- followed by H1
grep -l "^---$" *.mdx **/*.mdx | while read file; do
  # Check if file has manual H1 after frontmatter
  awk '/^---$/{count++} count==2{flag=1} flag && /^# /{print FILENAME; exit}' "$file"
done
```

**2. For each file found, apply fix:**

**Pattern to remove:**
```mdx
---
title: Page Title
description: Page description
---

# Page Title  <-- REMOVE THIS LINE
```

**Fixed version:**
```mdx
---
title: Page Title
description: Page description
---

Content starts here directly (or with H2 if needed)
```

**Critical rules:**
- ONLY remove H1 (`# Heading`) that duplicates frontmatter title
- KEEP all H2 (`## Heading`) and below
- KEEP any content between frontmatter and first heading
- If H1 text differs from title, update frontmatter title to match H1, then remove H1

**Verification approach:**
After removing H1s, verify DocsPage renders title by checking:
- `docs/app/[lang]/docs/[[...slug]]/page.tsx` line 72 renders `page.data.title` as H1
- Fumadocs automatically converts this to proper heading with styling

**Estimated files:** ~112 MDX files based on v2.0 metrics. Use scripted approach:
```bash
# Create temporary script
cat > /tmp/fix-h1.sh << 'EOF'
#!/bin/bash
for file in $(find docs/content/docs -name "*.mdx" -type f); do
  # Use sed to remove H1 line that comes after frontmatter closing
  sed -i '/^---$/,/^# /{/^# /d;}' "$file"
done
EOF
chmod +x /tmp/fix-h1.sh
./tmp/fix-h1.sh
```

**Why scripted:** Manual editing of 112 files is error-prone. Sed pattern removes H1 only in frontmatter-to-content region.

**Fallback if sed fails:** Use ripgrep to list files, then manually edit high-traffic pages (getting-started, quickstart, installation, guides).
  </action>
