```ini
root = true

[*.{json,yml,yaml}]

# Python files
[*.py]
indent_size = 4
max_line_length = 88

# Shell scripts
[*.sh]
indent_size = 2
```

**Mapping to Biome (docs/biome.json):**
- `indent_style = space` ← `"indentStyle": "space"`
- `indent_size = 2` ← `"indentWidth": 2`
- `max_line_length = 100` ← `"lineWidth": 100`
- `end_of_line = lf` (Git handles CRLF → LF conversion)
- `charset = utf-8` (default for modern editors)

**Why EditorConfig:**
- Works across ALL editors (VSCode, Vim, IntelliJ, Sublime, etc.) without extension install
- Biome requires VSCode extension or CLI run
- EditorConfig provides baseline, Biome provides enforcement

**Testing:**
After creating file, open any .ts or .tsx file in VSCode and verify:
- Tab key inserts 2 spaces
- Cursor position shows "Spaces: 2" in status bar
- Files save with LF line endings (not CRLF)

  <action>
Audit documentation dependencies for unused packages and outdated versions:

**1. Check for unused dependencies:**
```bash
cd docs
bunx depcheck
```

Expected output shows any unused dependencies in:
- `dependencies` section (runtime)
- `devDependencies` section (development)

**2. Review depcheck output:**

For each unused dependency:
- If genuinely unused (no imports found): Remove with `bun remove package-name`
- If used indirectly (peer dependency): Keep and document in comment
- If used in scripts (package.json scripts): Keep (depcheck can't detect this)

**Common false positives to KEEP:**
- `@types/*` packages (TypeScript types, may not show imports)
- `eslint-*` or `biome` configs (used by tools, not imported)
- `fumadocs-*` packages (may use internal dynamic imports)
- Build tools (`bun`, framework packages)

**3. Check for outdated dependencies:**
```bash
cd docs
bun outdated
```

**Update strategy:**
- Patch versions (1.2.3 → 1.2.4): Update automatically
- Minor versions (1.2.3 → 1.3.0): Update if compatible
- Major versions (1.2.3 → 2.0.0): Review breaking changes first, defer to later phase if complex

**4. Safe update commands:**
```bash
# Update patch and minor versions
bun update

# For specific package
bun update package-name@latest
```

**Critical packages to verify after updates:**
- `next` (must match Fumadocs compatibility)
- `fumadocs-*` (all should be same minor version)
- `react` (must match Next.js requirements)

**5. Verify build after dependency changes:**
```bash
bun install
bun run build
```

If build fails after update, rollback that specific package:
```bash
bun remove package-name
bun add package-name@previous-version
```
