# Dataset Discovery Workflow

Find, evaluate, and download datasets matching your requirements.

## Use This Workflow When

- You're starting from scratch (no specific dataset in mind)
- You need to verify data quality before downloading
- You want to preview data structure before committing
- You need citation-quality data for research

## Prerequisites

- [ ] Austria MCP connected in Claude Desktop
- [ ] Clear understanding of data requirements (topic, format, quality threshold)

## Time Estimate

15-20 minutes for complete workflow

## Workflow Overview

<Tabs items={['Complete Example', 'Step by Step']} persist groupId="workflow-detail">
  <Tab value="Complete Example">
    ### All-in-One Script

    Complete workflow in one code block for quick execution:

    ```python
    # 1. Search for datasets
    results = semantic_search_datasets(
        natural_query="health data from Vienna",
        formats=["CSV"],
        boost_quality=True
    )

    # 2. Get top result details
    dataset_id = results['results'][0]['id']
    dataset = get_dataset(dataset_id=dataset_id)

    # 3. Analyze quality
    quality = analyze_dataset_quality(dataset_id=dataset_id)
    if quality['metrics']['overall_score'] < 70:
        print("⚠️ Quality below threshold")
        # Fall back to second result or adjust criteria

    # 4. Get download URL
    distributions = get_dataset_distributions(dataset_id=dataset_id)
    csv_url = next(d['downloadURL'] for d in distributions
                   if d.get('format') == 'CSV')

    # 5. Preview schema
    schema = preview_schema(url=csv_url, format="csv")

    # 6. Verify required columns
    required_columns = ["year", "region", "cases"]
    actual_columns = [c['name'] for c in schema['columns']]

    if all(col in actual_columns for col in required_columns):
        print("✓ Schema validated - ready to download")
        print(f"Download URL: {csv_url}")
        # Proceed with download using your preferred method
    else:
        print("✗ Missing required columns")
    ```

**Solutions:**

- Try German keywords (data is Austria-focused)
- Remove restrictive filters
- Check autocomplete_suggestions for correct theme codes

### All Results Have Low Quality Scores

**Solutions:**
- Lower quality threshold (70→60)
- Review quality breakdown (maybe missing non-critical fields)
- Check if domain has sparse metadata
- Prioritize completeness over other metrics

### Schema Missing Required Columns

**Solutions:**
- Check column naming (may differ from expectations)
- Try related datasets
- Preview actual data to verify structure
- Contact publisher if critical data expected

        ```python
        from datetime import datetime, timedelta

        modified = datetime.fromisoformat(dataset['modified'])

        if age_days > 365:
        ```

        ```python
        distributions = get_dataset_distributions(dataset_id)

                import requests
                response = requests.head(dist['downloadURL'])
                if response.status_code != 200:
                    print(f"⚠️ {dist['format']} URL inaccessible")
        ```
      </Step>

        approval_checklist = {
