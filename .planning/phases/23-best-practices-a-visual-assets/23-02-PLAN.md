<task type="auto">
  <name>Task 2: Create Screenshot Optimization Script</name>
  <files>scripts/optimize-screenshots.mjs</files>
  <action>
Create Sharp-based optimization script at docs/scripts/optimize-screenshots.mjs:

**Script functionality:**
- Read PNG/JPG files from public/screenshots/
- Resize to max 1920px width (maintain aspect ratio, no upscaling)
- Convert to WebP at quality 85 (balance quality vs size)
- Compression effort 6 (higher = better compression, slower)
- Output to public/optimized/screenshots/
- Log each optimization with file size reduction percentage

**Based on research pattern:**
```javascript
import sharp from 'sharp';
import { readdir, mkdir } from 'fs/promises';
import { join, basename, extname } from 'path';

const SCREENSHOTS_DIR = './public/screenshots';
const OUTPUT_DIR = './public/optimized/screenshots';
const MAX_WIDTH = 1920;
const WEBP_QUALITY = 85;

async function optimizeScreenshot(inputPath, outputPath) {
  const stats = await sharp(inputPath)
    .resize(MAX_WIDTH, null, {
      withoutEnlargement: true,
      fit: 'inside'
    })
    .webp({
      quality: WEBP_QUALITY,
      effort: 6
    })
    .toFile(outputPath);

  return stats;
}

// Main function: iterate screenshots, optimize, log results
// Handle errors gracefully (skip non-image files)
```

**Constants at top of file:**
- SOURCE_DIR: './public/screenshots'
- OUTPUT_DIR: './public/optimized/screenshots'
- MAX_WIDTH: 1920
- WEBP_QUALITY: 85

**Error handling:**
- Skip non-image files (check extension)
- Continue on single file failure (log error, don't crash)
- Create output directory if missing (mkdir recursive)

**Output format:**
```
Optimizing 5 screenshots...
✓ search-workflow.png → search-workflow.webp (76.3% reduction)
✓ quality-metrics.png → quality-metrics.webp (81.2% reduction)
...
Optimization complete!
```

Create directory structure for screenshot workflow:

```bash
cd docs

touch public/screenshots/.gitkeep
touch public/optimized/screenshots/.gitkeep
```

**Purpose:**
- public/screenshots/: Source PNG screenshots from Claude Desktop (tracked in git)
- public/optimized/screenshots/: Generated WebP files (can be gitignored or tracked)

**Decision: Track optimized images in git**
Rationale: Optimized screenshots are build artifacts but should be tracked for:
1. Consistent deployment (no build-time optimization needed)
2. Reproducible builds (same output every deploy)
3. Fast deploys (no Sharp processing during Vercel build)

Add .gitkeep files to preserve empty directories in git.

**Add optimization script to package.json scripts:**
```json
{
  "scripts": {
    "optimize-images": "node scripts/optimize-screenshots.mjs",
    "build": "next build",
    ...
  }
}
```

This allows running: `npm run optimize-images` to process screenshots.
