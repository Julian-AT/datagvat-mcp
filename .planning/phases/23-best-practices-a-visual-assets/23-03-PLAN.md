**Preparation:**

1. Ensure Austria MCP server is running in Claude Desktop
2. Have Claude Desktop window visible and ready for screenshots
3. Review Phase 20 workflows to identify screenshot opportunities

**Screenshots to Capture (5-7 total):**

**Required (5):**

1. **Search Workflow** (search_datasets with results)
   - Show: Tool name, query parameter, quality_boost parameter, results with titles and quality scores
   - Example query: "health data Vienna"
   - File name: `search-workflow.png`

2. **Quality Metrics** (get_dataset_metrics with DQV breakdown)
   - Show: Tool name, dataset_id parameter, quality score breakdown by component
   - File name: `quality-metrics.png`

3. **Data Preview** (preview_data showing schema and sample rows)
   - Show: Tool name, URL parameter, format parameter, returned schema and data preview
   - File name: `data-preview.png`

4. **Semantic Search** (search_semantic with natural language query)
   - Show: Tool name, natural_query parameter, expanded themes, results
   - Example query: "datasets about public health in Austrian cities"
   - File name: `semantic-search.png`

5. **Related Datasets** (find_similar_datasets showing recommendations)
   - Show: Tool name, dataset_id parameter, similarity scores, related datasets
   - File name: `related-datasets.png`

**Optional (2 additional):**

6. **Workflow Combination** (multi-step workflow showing tool sequence)
   - Show: search → get_dataset → preview_data in sequence
   - File name: `workflow-sequence.png`

7. **Error Handling** (tool error with actionable message)
   - Show: ToolError with clear error message and retry suggestion
   - File name: `error-handling.png`

**Screenshot Guidelines:**

- **Window size:** Full Claude Desktop window (recommended ~1920x1080 or similar)
- **Tool visibility:** Ensure tool name, parameters, and results are clearly visible
- **No sensitive data:** Use public datasets only, no personal information
- **Clean interface:** Close unnecessary windows/tabs for clarity
- **Zoom level:** Default zoom (not too zoomed in/out)
- **Format:** PNG (will be optimized to WebP in next step)

**Capture Process:**

1. Invoke Austria MCP tool in Claude Desktop
2. Wait for results to display completely
3. Take screenshot (Windows: Win+Shift+S, macOS: Cmd+Shift+4)
4. Save to `docs/public/screenshots/` with descriptive filename
5. Repeat for each required screenshot

**File Naming Convention:**
- Use kebab-case: `search-workflow.png`, not `Search Workflow.png`
- Be descriptive: filename should indicate what's shown
- Use `.png` extension (will convert to WebP later)

**Verification:**

After capturing, verify you have:
- [ ] 5-7 PNG files in `docs/public/screenshots/`
- [ ] Each screenshot clearly shows tool name, parameters, and results
- [ ] File sizes reasonable (typically 500KB-2MB per PNG)
- [ ] File names follow convention (kebab-case, descriptive)
- [ ] All required workflows covered (search, quality, preview, semantic, related)

**Example file listing:**
