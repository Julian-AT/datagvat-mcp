<task type="auto">
  <name>Create RAG API route with streaming and citation enforcement</name>
  <files>
    docs/app/api/rag/route.ts

  <action>
    Create `docs/app/api/rag/route.ts` following /api/chat pattern:

    **Rate limiting** (copy from /api/chat):
    - Same in-memory rate limiter (Map<string, { count, resetAt }>)
    - Same limits: 5 requests/minute per IP
    - Same getClientIP helper (x-forwarded-for extraction)
    - Same 429 error response format

    **Request validation**:
    - Parse JSON body for messages array
    - Validate messages structure (400 if invalid)
    - Extract last user message for RAG retrieval

    **RAG pipeline**:
    1. Retrieve context: `const chunks = await retrieveContext(userMessage, { topK: 5, threshold: 0.75 })`
    2. Check if chunks empty: respond "I don't have information about that in the documentation."
    3. Format context: `const context = formatContextForPrompt(chunks)`
    4. Build system prompt with context and rules

    **System prompt template**:
    ```typescript
    const systemPrompt = `You are a documentation assistant for the Austria MCP server.

Context from documentation:
${context}

Rules:
- Answer questions using ONLY the provided context above
- Cite sources using [1], [2] etc. matching the context numbering
- If the context doesn't contain the answer, say "I don't have information about that in the documentation."
- DO NOT make up information not in the context
- Provide code examples from context when relevant
- Focus on Austrian data (data.gv.at) and MCP server features
- Redirect off-topic questions: "This chat is for Austria MCP documentation. Please visit [relevant section] for that topic."

Format responses with:
- Clear, concise answers
- Code examples when applicable
- Citation numbers [1], [2] after relevant statements
- Links to documentation sections for deeper reading`;
    ```

    **Model configuration**:
    - Use createOpenAICompatible from '@ai-sdk/openai-compatible'
    - Model: claude-3-5-sonnet-20241022
    - Use ANTHROPIC_API_KEY environment variable
    - Same baseURL and headers pattern as /api/chat

    **Streaming**:
    - Use streamText() from 'ai' package with data stream protocol
    - Pass system prompt, messages, model
    - maxSteps: 1 (no tool calling for RAG endpoint, unlike /api/chat)
    - onFinish callback logs usage and finish reason
    - **Return retrieved chunk metadata for client-side citation rendering**:
      ```typescript
      // Create data stream with sources metadata
      const result = streamText({
        model,
        system: systemPrompt,
        messages,
        maxSteps: 1,
        onFinish: ({ usage, finishReason }) => {
          console.log(`[RAG] usage=${JSON.stringify(usage)} finishReason=${finishReason}`);
        },
      });

      // Attach sources metadata as initial data event
      return result.toDataStreamResponse({
        data: {
          sources: chunks.map((chunk, idx) => ({
            number: idx + 1,
            url: chunk.url,
            title: chunk.title,
            section: chunk.section,
          })),
        },
      });
      ```
    - This enables client to map [1], [2] citations → clickable URLs using useChat's data property

    **Error handling**:
    - 500 if ANTHROPIC_API_KEY missing
    - 500 if vector store fails to load
    - 429 if rate limited
    - 400 if invalid request
    - Catch-all try/catch with JSON error response

    **Export**:
    ```typescript
    export const maxDuration = 30;
    export async function POST(req: Request) { ... }
    ```

    DO NOT include tools parameter (unlike /api/chat which uses MCP tools). This is pure RAG.
