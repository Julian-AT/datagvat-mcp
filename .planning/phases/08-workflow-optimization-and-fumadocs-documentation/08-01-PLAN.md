<task type="auto">
  <name>Task 2: Add comprehensive docstrings</name>
  <files>app/**/*.py</files>
  <action>
    1. Audit all public functions, classes, and modules for docstrings
    2. Add Google-style docstrings to any missing:
       ```python

           """Brief description.

           Longer description if needed.

           Args:
               param: Description of param

           Returns:
               Description of return value

           Raises:
               ValueError: When param is invalid
           """
       ```
    3. Ensure all MCP tools have docstrings explaining parameters and returns
    4. Add module-level docstrings to all Python files
  </action>
  <verify>grep -r "^def " app/ shows all public functions have docstrings</verify>
  <done>All public functions, classes, modules have Google-style docstrings</done>

<task type="auto">
  <name>Task 3: Set up CI/CD pipeline</name>
  <files>.github/workflows/ci.yml</files>
  <action>
    Create GitHub Actions workflow that runs on push and pull request:
    ```yaml
    name: CI

    on: [push, pull_request]

    jobs:
      test:
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: actions/setup-python@v5
            with:
              python-version: '3.11'
          - run: pip install -e ".[dev]"
          - run: ruff check app/ tests/
          - run: mypy app/ --strict
          - run: pytest tests/ --cov=app --cov-report=term-missing
    ```

    Ensure pyproject.toml has [project.optional-dependencies] dev group with mypy, ruff, pytest, pytest-cov
  </action>
  <verify>git push triggers CI workflow, all checks pass</verify>
  <done>CI pipeline runs type checking, linting, and tests on every push</done>
</task>
