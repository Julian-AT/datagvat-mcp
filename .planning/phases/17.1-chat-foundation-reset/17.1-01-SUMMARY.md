## Decisions Made

**1. GIN Index Pattern for JSONB**
- **Decision:** Use GIN index on messages.parts for efficient queries like `WHERE parts @> '[{"type": "visualization"}]'::jsonb`
- **Rationale:** Enables fast lookups of messages containing specific part types (visualization, tool-result, file) without full table scan
- **Alternative considered:** BTREE index - rejected because can't query JSONB structure efficiently

**2. Custom Visualization Part Type**
- **Decision:** Extend MessagePart union with custom `type: "visualization"` variant instead of reusing `type: "file"`
- **Rationale:** Semantic clarity - distinguishes AI-generated visualizations from user-uploaded files for different rendering/handling
- **Comparison:** vercel/ai-chatbot uses `type: "file"` for all attachments - both approaches valid, ours provides better type discrimination

**3. Defer Migration Execution to Plan 05**
- **Decision:** Create migration file now but execute in final verification phase (Plan 05)
- **Rationale:** Allows testing all schema changes together, ensures database ready before refactoring routes
- **Safety:** IF NOT EXISTS makes migration idempotent and safe to rerun

## Architecture Analysis Summary

### Key Patterns from vercel/ai-chatbot

**1. Upload-First File Handling**
- Files uploaded to Vercel Blob BEFORE message sent
- Message only contains URLs (never base64 or binary data)
- Eliminates context window explosion and WebSocket payload errors

**2. Immediate Persistence**
- User message saved BEFORE streaming starts (not just in onFinish)
- Prevents data loss if stream fails
- Conversation created automatically on first message

**3. Parts-Based Rendering**
- Messages stored as arrays of typed parts (text, tool-call, tool-result, file)
- Map through parts array, render different component per type
- Clean separation of content types

**4. Data Stream Annotations**
- Use `type: "data-*"` for custom events (chat title updates, progress)
- No experimental_transform needed - use SDK's built-in pattern
- Consumed via DataStreamHandler component
