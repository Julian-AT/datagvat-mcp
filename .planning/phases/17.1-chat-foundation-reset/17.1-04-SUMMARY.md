## Decisions Made

**1. Remove visualizationCache entirely**
- **Rationale:** Caching added complexity and race conditions. Upload-first pattern is simpler and eliminates failure modes.

**2. Upload happens BEFORE sandbox.kill() in try block**
- **Rationale:** Ensures upload completes before sandbox cleanup. If upload fails, tool fails fast with clear error.

**3. Fail fast if conversationId missing**
- **Rationale:** conversationId required for blob upload folder organization. Better to fail immediately than proceed without it.

**4. Parallel format upload via Promise.all**
- **Rationale:** Visualizations often have multiple formats (PNG, SVG, HTML). Upload all in parallel for speed.

**5. Return clean URL objects: { format: 'png', url: 'https://...' }**
- **Rationale:** Simple structure for client rendering. No metadata needed - URL is sufficient.
