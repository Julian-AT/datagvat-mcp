## Decisions Made

**1. File size limit: 5MB**
- Rationale: Matplotlib and Plotly visualizations can be large (1-3MB). 5MB provides headroom while preventing abuse.

**2. Accepted mime types: JPEG, PNG, SVG, HTML**
- Rationale: Covers user-uploaded images (JPEG/PNG) and generated visualizations (SVG/HTML).
- SVG for vector graphics, HTML for interactive Plotly charts.

**3. No authentication checks**
- Rationale: v2.2 is guest mode only. Authentication deferred to v3.0.

**4. addRandomSuffix: true**
- Rationale: Prevents filename collisions when multiple users upload files with same name.
