## Decisions Made

**Replace serial ID with UUID patterns:**
All query functions now use UUID-based chat/message tables instead of serial ID conversations/messages tables. This aligns with Vercel ai-chatbot proven architecture and enables better scalability.

**convertToUIMessages as critical fix:**
From 17.1-RESEARCH.md, the missing convertToUIMessages function was identified as the root cause of Issue 1 (chat memory not working). This function converts DB messages with parts array to AI SDK UIMessage format. Without it, the LLM only sees the new message, not conversation history. This is the key fix for proper conversation memory.

**DBMessage type for insertion:**
Created DBMessage type with required fields (id, chatId, role, parts, attachments, createdAt) to ensure type safety when inserting messages into database.
