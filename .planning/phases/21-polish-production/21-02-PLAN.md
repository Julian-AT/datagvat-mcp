# Plan 21-02: React/Node Support with E2B Templates

**Goal:** Enable React web application development in sandboxes using E2B templates.

**Stack:** React 18, TypeScript, Vite, Parcel, Tailwind CSS, shadcn/ui.

**Files to Modify/Create:**
1.  **Create:** `docs/mcp/templates/react/e2b.Dockerfile` (Documentation/Source).
2.  **Modify:** `docs/lib/e2b/sandbox-executor.ts`
    *   Add specific handling for `template === 'react'`.
    *   If no custom template ID is available, attempt to bootstrap the environment using `npm create vite` dynamically (fallback strategy).
    *   Or better, assume the standard Node image and run a setup script.
    *   Implement logic to expose port 3000 (React dev server) or 5173 (Vite default).
3.  **Modify:** `docs/lib/ai/prompts.ts`
    *   Update `regularPrompt` and `artifactsPrompt` to explain the new `react` and `node` capabilities.
    *   Instruct the model to use `openSandbox({ template: 'react' })` for web apps.
    *   Instruct the model to write the *main application code* (e.g., App.tsx) in the code editor.

**Implementation Details:**

*   **Executor Logic (`react` template):**
    *   **Setup:** On first run (or if directory empty), run `npm create vite@latest . -- --template react-ts` (or similar) + `npm install`.
    *   **Dependencies:** `npm install -D tailwindcss postcss autoprefixer`, `npx tailwindcss init -p`.
    *   **UI Libs:** `npm install lucide-react class-variance-authority clsx tailwind-merge` (shadcn deps).
    *   **File Writing:** The `code` passed to `executeSandboxCode` is treated as the content of `src/App.tsx`.
    *   **Execution:** Run `npm run dev -- --host` (to expose to E2B network).
    *   **Output:** Return `https://<hostname>` as a visualization/preview.

*   **System Prompt Updates:**
    *   "When asked to create a web app, dashboard, or React component, use `openSandbox({ template: 'react' })`."
    *   "The sandbox provides a pre-configured React + Vite + Tailwind environment."
    *   "Write the `App.tsx` component code in the editor."

**Constraint:** Since I cannot build the docker image myself, I will write the Dockerfile for documentation, but implement the *runtime bootstrapping* logic in `sandbox-executor.ts` to make it work immediately with standard E2B Node sandboxes.

**Note:** Vite uses port 5173 by default. We need to ensure it binds to `0.0.0.0` (`--host`) to be accessible via E2B URL.

**Step-by-Step:**
1.  Create `docs/mcp/templates/react/e2b.Dockerfile`.
2.  Update `docs/lib/e2b/sandbox-executor.ts` to handle `template === 'react'`:
    *   Check if initialized. If not, run setup commands.
    *   Write `code` to `src/App.tsx`.
    *   Start dev server if not running.
    *   Return preview URL.
3.  Update `docs/lib/ai/prompts.ts` with new instructions.
