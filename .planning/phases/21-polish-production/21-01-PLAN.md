# Plan 21-01: Template Infrastructure & React Support

**Goal:** Enable multi-runtime sandboxes by adding support for E2B templates (specifically React/Node.js) and exposing dev server ports.

**Research Reference:** `.planning/phases/21-polish-production/RESEARCH.md`

**Key Changes:**
1.  **Database:** Add `template` and `type` columns to `SandboxState` to track environment type.
2.  **Tools:** Update `openSandbox` to allow template selection (default: 'python-data').
3.  **Executor:** Refactor `sandbox-executor.ts` to support:
    *   Dynamic `templateId` selection.
    *   `getHostname(port)` for exposing webapps.
    *   Background process execution (for `npm run dev`).
4.  **UI:** Add "Preview" tab to `SandboxArtifact` for rendering iframes.

**Files to Modify:**
1.  `docs/lib/db/schema.ts` - Add `template` column.
2.  `docs/lib/ai/tools/open-sandbox.ts` - Add `template` parameter to schema.
3.  `docs/lib/e2b/sandbox-executor.ts` - Add template logic & port exposure.
4.  `docs/components/sandbox-artifact.tsx` - Add Preview tab.
5.  `docs/components/sandbox-output-tab.tsx` - Implement Preview UI.

**Detailed Steps:**

1.  **Schema Update:**
    *   Add `template: varchar('template').default('base')` to `sandboxState`.
    *   Add `type: varchar('type').default('python')` (enum: python, react).
    *   Run migration.

2.  **Tool Update:**
    *   Update `openSandbox` Zod schema to include `template` (enum: 'python', 'react').
    *   Pass this info to `saveSandboxState`.

3.  **Executor Refactor:**
    *   If `type === 'react'`, use a Node-based template (or standard sandbox if compatible).
    *   Add `exposePort(port)` function to getting public URL.
    *   *Note:* For MVP, we might use the default sandbox and just install Node, OR use a custom template. E2B default sandbox usually has Node installed. We'll verify this.

4.  **UI Implementation:**
    *   If `sandbox.type === 'react'`, show "Preview" tab by default.
    *   In Preview tab, fetch the hostname for port 3000.
    *   Render `<iframe src={hostname} />`.

**Verification:**
*   Create a "React" sandbox via chat.
*   Verify `npm run dev` starts.
*   Verify iframe shows the content.
