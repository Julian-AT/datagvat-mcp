Extend existing .github/workflows/ci.yml to add docs validation job alongside Python tests.

Current workflow has "test" job for Python. Add new "docs" job using RESEARCH.md Pattern 6:

```yaml
name: CI

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main, develop ]

jobs:
  test:
    # Existing Python test job - KEEP AS-IS
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ['3.11', '3.12']
    steps:
      # ... existing Python test steps ...

  docs:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Bun
        uses: oven-sh/setup-bun@v2
        with:
          bun-version: latest

      - name: Install dependencies
        run: |
          cd docs
          bun install

      - name: Run validation checks
        run: |
          cd docs
          bun run validate

      - name: Build documentation
        run: |
          cd docs
          bun run build
```

Key implementation details:
- Separate "docs" job runs in parallel with "test" job (faster CI)
- oven-sh/setup-bun@v2 is official Bun action, caches Bun binary automatically
- "bun install" in docs/ directory (where package.json lives)
- "bun run validate" runs Biome + links + types (from Plan 02)
- "bun run build" includes prebuild + next build + postbuild (from Plan 02)
- Both test and docs jobs must pass for PR to merge

DO NOT modify existing test job - only add docs job.
