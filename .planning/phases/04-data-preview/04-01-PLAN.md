  <action>
Create app/preview.py with:

1. **Constants:**
   - DEFAULT_PREVIEW_BYTES = 64 * 1024 (64KB - enough for ~1000 CSV rows typically)
   - MAX_PREVIEW_BYTES = 512 * 1024 (512KB hard limit)
   - DEFAULT_PREVIEW_ROWS = 20
   - MAX_PREVIEW_ROWS = 100
   - SUPPORTED_FORMATS = {"csv", "json", "text/csv", "application/json"}

2. **PreviewError exception class:**
   - Subclass of Exception
   - Fields: message, reason (e.g., "unsupported_format", "fetch_failed", "parse_failed", "size_exceeded")

3. **async def fetch_preview_bytes(url: str, max_bytes: int = DEFAULT_PREVIEW_BYTES, timeout: int = 30) -> tuple[bytes, bool]:**
   - Use httpx.AsyncClient (create new instance, don't reuse PiveauClient - preview fetches external URLs)
   - Set headers={'Range': f'bytes=0-{max_bytes-1}'} for partial content
   - Set User-Agent to match config pattern
   - Handle responses:
     - 206 Partial Content: Return (content, True) - partial data received
     - 200 OK: Return (content[:max_bytes], False) - server doesn't support Range, truncate
     - 404: Raise PreviewError("Resource not found", "fetch_failed")
     - Other errors: Raise PreviewError with status code info
   - Timeout: Raise PreviewError("Request timed out", "fetch_failed")
   - Connection error: Raise PreviewError("Could not connect to URL", "fetch_failed")

4. **def detect_format(url: str, content_type: str | None = None) -> str | None:**
   - Check content_type first if provided (normalize: "text/csv" -> "csv", "application/json" -> "json")
   - Fall back to URL extension (.csv, .json)
   - Return None if format unknown

Example structure:
```python
import csv
import io
import json
import logging
from typing import Any

import httpx

logger = logging.getLogger(__name__)

DEFAULT_PREVIEW_BYTES = 64 * 1024
MAX_PREVIEW_BYTES = 512 * 1024
DEFAULT_PREVIEW_ROWS = 20
MAX_PREVIEW_ROWS = 100
SUPPORTED_FORMATS = {"csv", "json", "text/csv", "application/json"}

class PreviewError(Exception):
    def __init__(self, message: str, reason: str = "unknown"):
        super().__init__(message)
        self.reason = reason
```

IMPORTANT: Use httpx.AsyncClient context manager to ensure proper cleanup. Do NOT share client with PiveauClient.

<task type="auto">
  <name>Task 2: Implement CSV schema extraction and row preview</name>
  <files>app/preview.py</files>
  <action>
Add CSV parsing functions to app/preview.py:

1. **def infer_column_type(values: list[str]) -> str:**
   - Sample up to 10 non-empty values from the column
   - Check patterns in order:
     - integer: all values match r'^-?\d+$'
     - float: all values match r'^-?\d+\.?\d*$' or r'^-?\d*\.?\d+$'
     - boolean: all values in {"true", "false", "yes", "no", "1", "0"} (case-insensitive)
     - date: values contain "-" and match YYYY-MM-DD or similar patterns
     - string: default fallback
   - Return the inferred type as string

2. **def parse_csv_schema(content: bytes, encoding: str = "utf-8") -> dict[str, Any]:**
   - Decode bytes to string (handle encoding errors with 'replace')
   - Use csv.reader with io.StringIO
   - Read header row (first row)
   - Read up to 10 data rows for type inference
   - For each column, call infer_column_type on its values
   - Return:
     ```python
     {
         "columns": [
             {"name": "col1", "type": "string"},
             {"name": "col2", "type": "integer"},
             ...
         ],
         "row_count_sampled": 10,  # How many rows used for inference
     }
     ```
   - Handle errors: Raise PreviewError("Failed to parse CSV: {detail}", "parse_failed")

3. **def parse_csv_rows(content: bytes, max_rows: int = DEFAULT_PREVIEW_ROWS, encoding: str = "utf-8") -> dict[str, Any]:**
   - Decode bytes to string
   - Use csv.reader
   - Read header row
   - Read up to max_rows data rows
   - Return:
     ```python
     {
         "columns": ["col1", "col2", ...],  # Header names
         "rows": [
             ["val1", "val2", ...],  # Row as list of strings
             ...
         ],
         "row_count": 15,  # Actual rows returned
         "truncated": True/False,  # True if more rows available
     }
     ```
   - If content is truncated mid-row (partial fetch), discard the incomplete last row
   - Handle errors gracefully

IMPORTANT: CSV parsing should handle:
- Various delimiters (detect with csv.Sniffer if standard comma fails)
- Quoted fields
- Empty values
- UTF-8 BOM (skip if present)
  </action>

<task type="auto">
  <name>Task 3: Implement JSON array schema extraction and row preview</name>
  <files>app/preview.py</files>
  <action>
Add JSON parsing functions to app/preview.py:

1. **def infer_json_type(value: Any) -> str:**
   - None -> "null"
   - bool -> "boolean"
   - int -> "integer"
   - float -> "number"
   - str -> "string"
   - list -> "array"
   - dict -> "object"

2. **def parse_json_schema(content: bytes, encoding: str = "utf-8") -> dict[str, Any]:**
   - Decode and parse JSON
   - Handle two common patterns:
     a) Array of objects: `[{"col1": val, "col2": val}, ...]`
     b) Object with data array: `{"data": [...], ...}` - look for common keys like "data", "results", "items", "records"
   - For array of objects:
     - Collect all unique keys from first 10 objects
     - Infer type for each key based on values seen
     - Return:
       ```python
       {
           "columns": [
               {"name": "field1", "type": "string"},
               {"name": "field2", "type": "integer"},
               ...
           ],
           "row_count_sampled": 10,
           "structure": "array_of_objects"  # or "nested_data_array"
       }
       ```
   - If not array-like, return:
     ```python
     {
         "columns": [],
         "structure": "single_object",  # or "primitive"
         "note": "JSON is not tabular (array of objects)"
     }
     ```
   - Handle parse errors: Raise PreviewError("Invalid JSON: {detail}", "parse_failed")
   - Handle truncated JSON (from partial fetch): Try to parse what we have, note truncation

3. **def parse_json_rows(content: bytes, max_rows: int = DEFAULT_PREVIEW_ROWS, encoding: str = "utf-8") -> dict[str, Any]:**
   - Parse JSON and find array (same logic as schema)
   - Extract up to max_rows items
   - Return:
     ```python
     {
         "columns": ["field1", "field2", ...],  # Union of all keys
         "rows": [
             {"field1": val1, "field2": val2},  # Original objects
             ...
         ],
         "row_count": 15,
         "truncated": True/False,
     }
     ```
   - For non-tabular JSON, return empty rows with note

IMPORTANT:
- JSON from partial fetch may be truncated. Use try/except for json.loads.
- If JSON is truncated, try to recover by finding valid prefix (e.g., complete array items before truncation).
- Log warnings for parse issues but don't fail entirely.
