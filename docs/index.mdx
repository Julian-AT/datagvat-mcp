## What is data.gv.at MCP Server?

data.gv.at MCP Server is a Model Context Protocol server that provides AI assistants with seamless access to thousands of Austrian government datasets. It enables natural language queries, quality-aware ranking, and data previews.

## What is MCP?

<Callout>
  The Model Context Protocol (MCP) is an open protocol that standardizes how applications provide context to LLMs. data.gv.at MCP Server implements this protocol to give AI assistants seamless access to Austrian government datasets.
</Callout>

MCP enables:

- **Standardized Communication**: Consistent interface for AI assistants
- **Rich Context**: Structured data access for better AI responses
- **Tool Integration**: Seamless function calling capabilities
- **Extensibility**: Easy to extend with custom functionality

## Architecture Overview

The data.gv.at MCP Server server connects Claude Desktop to Austrian government datasets through a robust, layered architecture:

```
┌─────────────────────────────────────────────────────────────┐
│                      Claude Desktop                         │
│                      (MCP Client)                          │
└────────────────────┬────────────────────────────────────────┘
                     │ MCP Protocol (stdio)
                     ▼
┌─────────────────────────────────────────────────────────────┐
│                  data.gv.at MCP Server Server                         │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐  │
│  │              FastMCP Framework                       │  │
│  │     (Protocol handling & standard MCP features)      │  │
│  └─────────────────────────────────────────────────────┘  │
│                           │                                 │
│  ┌─────────────────────────────────────────────────────┐  │
│  │             Middleware Stack                         │  │
│  │  ┌────────────────────────────────────────────┐    │  │
│  │  │ Logging → Error → Retry → RateLimit        │    │  │
│  │  │        → Audit → Auth                      │    │  │
│  │  └────────────────────────────────────────────┘    │  │
│  └─────────────────────────────────────────────────────┘  │
│                           │                                 │
│  ┌─────────────────────────────────────────────────────┐  │
│  │               Tool Categories                        │  │
│  │  • Discovery (search, list catalogues)              │  │
│  │  • Management (create, update, delete datasets)     │  │
│  │  • Analysis (quality scoring, find related)         │  │
│  │  • Vocabularies (EU themes, formats, terms)         │  │
│  │  • Preview (CSV, JSON data samples)                 │  │
│  └─────────────────────────────────────────────────────┘  │
│                           │                                 │
│  ┌─────────────────────────────────────────────────────┐  │
│  │            Piveau API Client                         │  │
│  │   (Connection pooling, request optimization)         │  │
│  └─────────────────────────────────────────────────────┘  │
└────────────────────┬────────────────────────────────────────┘
                     │ HTTPS
                     ▼
┌─────────────────────────────────────────────────────────────┐
│               Piveau API (data.gv.at)                       │
│        Austrian Open Government Data Catalog               │
└─────────────────────────────────────────────────────────────┘
```

This architecture provides:

- **Clean separation** between MCP protocol handling (FastMCP) and business logic (tools)
- **Layered middleware** for logging, error handling, retries, rate limiting, and auth
- **Organized tools** by functional category for easy discovery
- **Efficient API client** with connection pooling and request optimization

Learn more in the [Architecture Guide](/advanced/architecture).

## Common Use Cases

### Research & Academia

Find datasets for academic research:

```
semantic_search_datasets(
    natural_query="environmental data for climate research",
    formats=["CSV", "JSON"],
    boost_quality=True
)
```

**Learn more:** [Searching Guide](/guides/searching)

### Data Journalism

Discover government spending data:

```
search_datasets(
    query="budget OR spending",
    themes=["GOVE", "ECON"],
    sort_by="modified_desc"
)
```

**Learn more:** [Quality Metrics](/guides/quality-metrics)

### Application Development

Preview data before integration:

```python
# 1. Search for datasets
results = search_datasets(query="population", formats=["CSV"])

# 2. Preview structure
schema = preview_schema(results[0]["downloadURL"])

# 3. Check quality
quality = analyze_dataset_quality(results[0]["id"])
```

**Learn more:** [Data Preview Guide](/guides/data-preview)

### Tourism & Public Information

Natural language queries for tourists:

```
Find transport schedules and maps for Vienna
```
