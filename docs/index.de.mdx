# data.gv.at MCP Server Dokumentation

Der maßgebliche MCP Server für österreichische Open Government Data – Entdecken, Analysieren und Zugriff auf Tausende Datensätze über KI-Assistenten.

<Callout title="Schnellstart">
  Neu bei data.gv.at MCP Server? Schau dir die [Installationsanleitung](/guides/setup) an und starte in wenigen Minuten.
</Callout>

## Was ist data.gv.at MCP Server?

data.gv.at MCP Server ist ein Model Context Protocol Server, der KI-Assistenten nahtlosen Zugriff auf Tausende österreichische Regierungsdatensätze bietet. Er ermöglicht Abfragen in natürlicher Sprache, qualitätsbewusstes Ranking und Datenvorschauen.

## Was ist MCP?

<Callout>
  Das Model Context Protocol (MCP) ist ein offenes Protokoll, das standardisiert, wie Anwendungen Kontext für LLMs bereitstellen. data.gv.at MCP Server implementiert dieses Protokoll und gibt KI-Assistenten nahtlosen Zugriff auf österreichische Regierungsdatensätze.
</Callout>

MCP ermöglicht:

- **Standardisierte Kommunikation**: Konsistente Schnittstelle für KI-Assistenten
- **Reicher Kontext**: Strukturierter Datenzugriff für bessere KI-Antworten
- **Tool-Integration**: Nahtlose Function-Calling-Funktionen
- **Erweiterbarkeit**: Einfach mit eigenen Funktionen erweiterbar

## Architektur-Überblick

Der data.gv.at MCP Server Server verbindet Claude Desktop mit österreichischen Regierungsdatensätzen durch eine robuste, geschichtete Architektur:

```
┌─────────────────────────────────────────────────────────────┐
│                      Claude Desktop                         │
│                      (MCP Client)                          │
└────────────────────┬────────────────────────────────────────┘
                     │ MCP Protocol (stdio)
                     ▼
┌─────────────────────────────────────────────────────────────┐
│                  data.gv.at MCP Server Server                         │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐  │
│  │              FastMCP Framework                       │  │
│  │  (Protokoll-Handling & Standard MCP-Features)       │  │
│  └─────────────────────────────────────────────────────┘  │
│                           │                                 │
│  ┌─────────────────────────────────────────────────────┐  │
│  │             Middleware Stack                         │  │
│  │  ┌────────────────────────────────────────────┐    │  │
│  │  │ Logging → Error → Retry → RateLimit        │    │  │
│  │  │        → Audit → Auth                      │    │  │
│  │  └────────────────────────────────────────────┘    │  │
│  └─────────────────────────────────────────────────────┘  │
│                           │                                 │
│  ┌─────────────────────────────────────────────────────┐  │
│  │               Tool-Kategorien                        │  │
│  │  • Discovery (search, list catalogues)              │  │
│  │  • Management (create, update, delete datasets)     │  │
│  │  • Analysis (quality scoring, find related)         │  │
│  │  • Vocabularies (EU themes, formats, terms)         │  │
│  │  • Preview (CSV, JSON, XML data samples)            │  │
│  └─────────────────────────────────────────────────────┘  │
│                           │                                 │
│  ┌─────────────────────────────────────────────────────┐  │
│  │            Piveau API Client                         │  │
│  │   (Connection Pooling, Request Optimization)         │  │
│  └─────────────────────────────────────────────────────┘  │
└────────────────────┬────────────────────────────────────────┘
                     │ HTTPS
                     ▼
┌─────────────────────────────────────────────────────────────┐
│               Piveau API (data.gv.at)                       │
│        Österreichischer Open Government Data Katalog       │
└─────────────────────────────────────────────────────────────┘
```

Diese Architektur bietet:

- **Klare Trennung** zwischen MCP-Protokoll-Handling (FastMCP) und Business-Logik (Tools)
- **Geschichtete Middleware** für Logging, Error Handling, Retries, Rate Limiting und Auth
- **Organisierte Tools** nach funktionalen Kategorien für einfache Auffindbarkeit
- **Effizienter API-Client** mit Connection Pooling und Request-Optimierung
