  <Accordion title="search_datasets" id="search-datasets">
    Search for datasets with text queries and faceted filtering. Supports full-text search with fuzzy matching, theme/format/publisher filters, date range filtering, and multiple sort options.

    **Parameters:**

    <TypeTable type={{
      query: {
        type: "string",
        description: "Search query for titles, descriptions, keywords. Supports fuzzy search (e.g., 'health~'), wildcards (e.g., 'europ*'), phrases (e.g., '\"open data\"'), and boolean operators (AND, OR, NOT)",
        default: "None"
      },
      themes: {
        type: "string[]",
        description: "Filter by EU data theme codes: AGRI, ECON, EDUC, ENER, ENVI, GOVE, HEAL, INTR, JUST, REGI, SOCI, TECH, TRAN",
        default: "None"
      },
      formats: {
        type: "string[]",
        description: "Filter by file format (CSV, JSON, XML, PDF, GeoJSON, etc.)",
        default: "None"
      },
      publishers: {
        type: "string[]",
        description: "Filter by publisher/organization ID",
        default: "None"
      },
      min_date: {
        type: "string",
        description: "Filter datasets modified/issued after this date (YYYY-MM-DD or ISO 8601)",
        default: "None"
      },
      max_date: {
        type: "string",
        description: "Filter datasets modified/issued before this date (YYYY-MM-DD or ISO 8601)",
        default: "None"
      },
      sort_by: {
        type: "string",
        description: "Sort order: relevance, modified_desc, modified_asc, title_asc, title_desc, issued_desc, issued_asc",
        default: "relevance"
      },
      boost_quality: {
        type: "boolean",
        description: "Boost high-quality datasets in search results (uses completeness, freshness, compliance metrics)",
        default: false
      },
      limit: {
        type: "integer",
        description: "Results per page (1-100)",
        default: 20
      },
      page: {
        type: "integer",
        description: "Page number for pagination (0-based)",
        default: 0
      },
      catalogue_id: {
        type: "string",
        description: "Restrict search to specific catalogue",
        default: "None"
      }
    }} />

    **Advanced Search Patterns:**

    - **Fuzzy matching:** `query="health~"` matches health, heath, healh (1 edit distance)
    - **Wildcards:** `query="europ*"` matches europe, european, europa
    - **Phrases:** `query='"open data"'` searches exact phrase
    - **Boolean operators:** `query="health AND (data OR dataset)"` for explicit logic
    - **Filter logic:** Multiple themes use OR within facet, AND between different facets

    **Returns:**

    ```json
    {
      "results": [
        {
          "id": "dataset-123",
          "title": "Population Statistics 2024",
          "description": "Annual population data...",
          "themes": ["SOCI"],
          "formats": ["CSV", "JSON"]
        }
      ],
      "count": 1234,
      "facets": {
        "categories": {...},
        "format": {...}
      }
    }
    ```

    **Example:**

    ```python
    # Basic search
    search_datasets(query="population", limit=10)

    # Advanced filtering
    search_datasets(
        query="health",
        themes=["HEAL", "SOCI"],
        formats=["CSV"],
        min_date="2024-01-01",
        boost_quality=True,
        limit=20
    )
    ```
  </Accordion>

  <Accordion title="find_related_datasets" id="find-related-datasets">
    Find datasets related to a source dataset based on shared themes and keywords. Returns similar datasets ranked by a similarity score (0-100).

    **Parameters:**

    <TypeTable type={{
      dataset_id: {
        type: "string",
        description: "Source dataset identifier"
      },
      limit: {
        type: "integer",
        description: "Maximum related datasets to return (1-50)",
        default: 10
      },
      min_score: {
        type: "number",
        description: "Minimum similarity score to include (0-100)",
        default: 20.0
      }
    }} />

    **Similarity Scoring:**

    - Theme matches: 30 points per shared theme (max 60)
    - Keyword matches: 10 points per shared keyword (max 30)
    - Same publisher bonus: 15 points
    - Total score capped at 100

    **Returns:**

    ```json
    {
      "source": {
        "id": "dataset-123",
        "title": "Population Statistics"
      },
      "related": [
        {
          "dataset": {...},
          "score": 85.0,
          "shared_themes": ["SOCI"],
          "shared_keywords": ["population", "statistics"]
        }
      ]
    }
    ```

    **Example:**

    ```python
    find_related_datasets(
        dataset_id="dataset-123",
        limit=10,
        min_score=30.0
    )
    ```
  </Accordion>

  <Accordion title="semantic_search_datasets" id="semantic-search-datasets">
    Search for datasets using natural language queries in English or German. The system uses AI to understand your intent and find relevant datasets.

    **Parameters:**

    <TypeTable type={{
      natural_query: {
        type: "string",
        description: "Natural language query (e.g., 'health data from Vienna', 'Umweltdaten für die Forschung')"
      },
      themes: {
        type: "string[]",
        description: "Additional theme filters (combined with AI-detected themes)",
        default: "None"
      },
      formats: {
        type: "string[]",
        description: "Additional format filters",
        default: "None"
      },
      publishers: {
        type: "string[]",
        description: "Additional publisher filters",
        default: "None"
      },
      min_date: {
        type: "string",
        description: "Filter by modification/issue date (YYYY-MM-DD)",
        default: "None"
      },
      max_date: {
        type: "string",
        description: "Filter by modification/issue date (YYYY-MM-DD)",
        default: "None"
      },
      sort_by: {
        type: "string",
        description: "Sort order",
        default: "relevance"
      },
      boost_quality: {
        type: "boolean",
        description: "Boost high-quality datasets (default true for semantic search)",
        default: true
      },
      limit: {
        type: "integer",
        description: "Results per page (1-100)",
        default: 20
      },
      page: {
        type: "integer",
        description: "Page number",
        default: 0
      }
    }} />

    **How It Works:**

    1. AI detects language (German/English) using linguistic heuristics
    2. Expands query into themes, keywords, and filters
    3. Merges with your explicit filters
    4. Returns results with expansion information

    **Returns:**

    ```json
    {
      "results": [...],
      "count": 42,
      "facets": {...},
      "expansion_info": {
        "detected_language": "de",
        "semantic_themes": ["HEAL"],
        "expanded_keywords": ["gesundheit", "medizin"],
        "confidence": "high"
      }
    }
    ```

    **Example:**

    ```python
    # English query
    semantic_search_datasets(
        natural_query="health data from Vienna for research"
    )

    # German query
    semantic_search_datasets(
        natural_query="Umweltdaten aus Wien",
        formats=["CSV", "JSON"]
    )

    # Tourist use case
    semantic_search_datasets(
        natural_query="transport information for tourists",
        limit=15
    )
    ```

## Preview Tools

<Accordions type="single" collapsible>
  <Accordion title="preview_schema" id="preview-schema">
    Get the schema (column names and types) of a CSV or JSON dataset. Fetches only the first portion of the file to infer structure efficiently.

    **Parameters:**

    <TypeTable type={{
      url: {
        type: "string",
        description: "Direct download URL (get from get_dataset_distributions)"
      },
      format: {
        type: "string",
        description: "File format: 'csv' or 'json' (auto-detected if not specified)",
        default: "Auto-detected"
      }
    }} />

    **Returns:**

    ```json
    {
      "url": "https://example.com/data.csv",
      "format": "csv",
      "partial_fetch": true,
      "columns": [
        {
          "name": "population",
          "type": "integer",
          "sample_values": [100000, 150000, 200000]
        },
        {
          "name": "city",
          "type": "string",
          "sample_values": ["Vienna", "Graz", "Linz"]
        }
      ]
    }
    ```

    **Type Detection:**

    - Infers types from first 10 sample rows
    - Supports integers, floats, booleans, dates, strings
    - CSV: Handles multiple delimiters via csv.Sniffer
    - JSON: Detects nested data arrays

    **Example:**

    ```python
    preview_schema(
        url="https://example.com/population.csv",
        format="csv"
    )
    ```
  </Accordion>

  <Accordion title="preview_data" id="preview-data">
    Preview the first rows of a CSV or JSON dataset. Fetches only enough data to return the requested number of rows.

    **Parameters:**

    <TypeTable type={{
      url: {
        type: "string",
        description: "Direct download URL"
      },
      max_rows: {
        type: "integer",
        description: "Maximum rows to return (1-100)",
        default: 20
      },
      format: {
        type: "string",
        description: "File format: 'csv' or 'json'",
        default: "Auto-detected"
      }
    }} />

    **Returns:**

    ```json
    {
      "url": "https://example.com/data.csv",
      "format": "csv",
      "partial_fetch": true,
      "rows": [
        {"city": "Vienna", "population": 1900000},
        {"city": "Graz", "population": 291000}
      ],
      "row_count": 2,
      "estimated_total_rows": 100
    }
    ```

    **Fetch Optimization:**

    - Default: 64KB preview (enough for ~1000 CSV rows)
    - Maximum: 512KB to prevent memory issues
    - Estimates bytes needed based on format and max_rows

    **Example:**

    ```python
    preview_data(
        url="https://example.com/population.csv",
        max_rows=50
    )
    ```
  </Accordion>
</Accordions>

  <Accordion title="get_autocomplete_suggestions" id="get-autocomplete-suggestions">
    Get autocomplete suggestions for search queries. Returns vocabulary terms and common patterns matching the query prefix. Useful for search-as-you-type functionality.

    **Parameters:**

    <TypeTable type={{
      query: {
        type: "string",
        description: "Query prefix (minimum 1 character)"
      },
      limit: {
        type: "integer",
        description: "Maximum suggestions (1-20)",
        default: 10
      },
      language: {
        type: "string",
        description: "Language code (de, en)",
        default: "de"
      }
    }} />

    **Suggestion Sources:**

    1. **EU data themes** (13 themes): AGRI, ECON, EDUC, ENER, ENVI, GOVE, HEAL, INTR, JUST, REGI, SOCI, TECH, TRAN
    2. **File formats**: CSV, JSON, XML, PDF, GeoJSON, RDF, XLSX, ZIP, HTML, TXT
    3. **Common terms**: open data, statistics, geodata, verkehr, umwelt, gesundheit, etc.

    **Scoring:**

    - Prefix matches: 100 points
    - Substring matches: 50 points
    - Results sorted by score, then alphabetically

    **Returns:**

    ```json
    {
      "suggestions": [
        {
          "text": "Gesundheit",
          "category": "theme",
          "code": "HEAL",
    ```
