# MCP Tools

Der data.gv.at MCP Server bietet Tools zum Entdecken, Analysieren und Verwalten von österreichischen Open Data Datensätzen.

  <Accordion title="search_datasets" id="search-datasets">
    Durchsucht Datensätze mit Textsuche und Filtern. Unterstützt Volltextsuche mit Fuzzy-Matching, Theme/Format/Publisher-Filtern, Datumsbereichsfilterung und mehreren Sortieroptionen.

    **Parameter:**

    <TypeTable type={{
      query: {
        type: "string",
        description: "Suchanfrage für Titel, Beschreibungen, Schlagwörter. Unterstützt Fuzzy-Suche (z.B. 'gesundheit~'), Wildcards (z.B. 'europ*'), Phrasen (z.B. '\"open data\"') und boolesche Operatoren (AND, OR, NOT)",
        default: "None"
      },
      themes: {
        type: "string[]",
        description: "Filtern nach EU-Datenkategorie-Codes: AGRI, ECON, EDUC, ENER, ENVI, GOVE, HEAL, INTR, JUST, REGI, SOCI, TECH, TRAN",
        default: "None"
      },
      formats: {
        type: "string[]",
        description: "Filtern nach Dateiformat (CSV, JSON, XML, PDF, GeoJSON, etc.)",
        default: "None"
      },
      publishers: {
        type: "string[]",
        description: "Filtern nach Herausgeber oder Organisations-ID",
        default: "None"
      },
      min_date: {
        type: "string",
        description: "Filtert Datensätze, die nach diesem Datum geändert oder veröffentlicht wurden (YYYY-MM-DD oder ISO 8601)",
        default: "None"
      },
      max_date: {
        type: "string",
        description: "Filtert Datensätze, die vor diesem Datum geändert oder veröffentlicht wurden (YYYY-MM-DD oder ISO 8601)",
        default: "None"
      },
      sort_by: {
        type: "string",
        description: "Sortierreihenfolge: relevance, modified_desc, modified_asc, title_asc, title_desc, issued_desc, issued_asc",
        default: "relevance"
      },
      boost_quality: {
        type: "boolean",
        description: "Bevorzugt hochwertige Datensätze in Suchergebnissen mit Vollständigkeits-, Aktualitäts- und Compliance-Metriken",
        default: false
      },
      limit: {
        type: "integer",
        description: "Ergebnisse pro Seite (1-100)",
        default: 20
      },
      page: {
        type: "integer",
        description: "Seitenzahl für Paginierung (0-basiert)",
        default: 0
      },
      catalogue_id: {
        type: "string",
        description: "Beschränkt Suche auf bestimmten Katalog",
        default: "None"
      }
    }} />

    **Erweiterte Suchmuster:**

    - **Fuzzy-Matching:** `query="gesundheit~"` findet gesundheit, gesundeit, gesundhet (1 Editierdistanz)
    - **Wildcards:** `query="europ*"` findet europe, european, europa
    - **Phrasen:** `query='"open data"'` sucht exakte Phrase
    - **Boolesche Operatoren:** `query="gesundheit AND (daten OR dataset)"` für explizite Logik
    - **Filterlogik:** Mehrere Themes nutzen OR innerhalb der Facette, AND zwischen verschiedenen Facetten

    **Rückgabewert:**

    ```json
    {
      "results": [
        {
          "id": "bev-stat-wien-2024",
          "title": "Bevölkerung Wien 2020-2024",
          "description": "Jährliche Bevölkerungsdaten für Wiener Bezirke...",
          "themes": ["SOCI"],
          "formats": ["CSV", "JSON"]
        }
      ],
      "count": 1234,
      "facets": {
        "categories": {...},
        "format": {...}
      }
    }
    ```

    **Beispiel:**

    ```python
    # Einfache Suche
    search_datasets(query="bevölkerung", limit=10)

    # Erweiterte Filterung
    search_datasets(
        query="gesundheit",
        themes=["HEAL", "SOCI"],
        formats=["CSV"],
        min_date="2024-01-01",
        boost_quality=True,
        limit=20
    )
    ```

  <Accordion title="find_related_datasets" id="find-related-datasets">
    Findet Datensätze, die mit einem Quelldatensatz verwandt sind, basierend auf gemeinsamen Kategorien und Schlagwörtern. Gibt ähnliche Datensätze mit einem Ähnlichkeitswert (0-100) zurück.

    **Parameter:**

    <TypeTable type={{
      dataset_id: {
        type: "string",
        description: "Quelldatensatz-ID"
      },
      limit: {
        type: "integer",
        description: "Maximale Anzahl verwandter Datensätze (1-50)",
        default: 10
      },
      min_score: {
        type: "number",
        description: "Mindest-Ähnlichkeitswert (0-100)",
        default: 20.0
      }
    }} />

    **Ähnlichkeitsbewertung:**

    - Kategorieübereinstimmungen: 30 Punkte pro gemeinsamer Kategorie (max 60)
    - Schlagwortübereinstimmungen: 10 Punkte pro gemeinsamem Schlagwort (max 30)
    - Gleicher Herausgeber-Bonus: 15 Punkte
    - Gesamtwert auf 100 begrenzt

    **Rückgabewert:**

    ```json
    {
      "source": {
        "id": "bev-stat-wien-2024",
        "title": "Bevölkerung Wien 2020-2024"
      },
      "related": [
        {
          "dataset": {...},
          "score": 85.0,
          "shared_themes": ["SOCI"],
          "shared_keywords": ["bevölkerung", "statistik"]
        }
      ]
    }
    ```

    **Beispiel:**

    ```python
    find_related_datasets(
        dataset_id="bev-stat-wien-2024",
        limit=10,
        min_score=30.0
    )
    ```
  </Accordion>

  <Accordion title="semantic_search_datasets" id="semantic-search-datasets">
    Sucht nach Datensätzen mit natürlichsprachlichen Abfragen auf Deutsch oder Englisch. Das System nutzt KI, um Ihre Absicht zu verstehen und relevante Datensätze zu finden.

    **Parameter:**

    <TypeTable type={{
      natural_query: {
        type: "string",
        description: "Natürlichsprachliche Abfrage (z.B. 'Gesundheitsdaten aus Wien', 'environmental data for research')"
      },
      themes: {
        type: "string[]",
        description: "Zusätzliche Kategoriefilter (kombiniert mit KI-erkannten Kategorien)",
        default: "None"
      },
      formats: {
        type: "string[]",
        description: "Zusätzliche Formatfilter",
        default: "None"
      },
      publishers: {
        type: "string[]",
        description: "Zusätzliche Herausgeberfilter",
        default: "None"
      },
      min_date: {
        type: "string",
        description: "Filtern nach Änderungs- oder Veröffentlichungsdatum (YYYY-MM-DD)",
        default: "None"
      },
      max_date: {
        type: "string",
        description: "Filtern nach Änderungs- oder Veröffentlichungsdatum (YYYY-MM-DD)",
        default: "None"
      },
      sort_by: {
        type: "string",
        description: "Sortierreihenfolge",
        default: "relevance"
      },
      boost_quality: {
        type: "boolean",
        description: "Bevorzugt hochwertige Datensätze (Standard true für semantische Suche)",
        default: true
      },
      limit: {
        type: "integer",
        description: "Ergebnisse pro Seite (1-100)",
        default: 20
      },
      page: {
        type: "integer",
        description: "Seitenzahl",
        default: 0
      }
    }} />

    **Funktionsweise:**

    1. KI erkennt Sprache (Deutsch/Englisch) mittels linguistischer Heuristiken
    2. Erweitert Abfrage in Kategorien, Schlagwörter und Filter
    3. Kombiniert mit Ihren expliziten Filtern
    4. Gibt Ergebnisse mit Erweiterungsinformationen zurück

    **Rückgabewert:**

    ```json
    {
      "results": [...],
      "count": 42,
      "facets": {...},
      "expansion_info": {
        "detected_language": "de",
        "semantic_themes": ["HEAL"],
        "expanded_keywords": ["gesundheit", "medizin"],
        "confidence": "high"
      }
    }
    ```

    **Beispiel:**

    ```python
    # Deutsche Abfrage
    semantic_search_datasets(
        natural_query="Gesundheitsdaten aus Wien für Forschung"
    )

    # Englische Abfrage
    semantic_search_datasets(
        natural_query="environmental data from Vienna",
        formats=["CSV", "JSON"]
    )

    # Tourismus-Anwendungsfall
    semantic_search_datasets(
        natural_query="Verkehrsinformationen für Touristen",
        limit=15
    )
    ```
  </Accordion>

## Preview Tools

<Accordions type="single" collapsible>
  <Accordion title="preview_schema" id="preview-schema">
    Ruft das Schema (Spaltennamen und Typen) eines CSV- oder JSON-Datensatzes ab. Lädt nur den ersten Teil der Datei, um die Struktur effizient abzuleiten.

    **Parameter:**

    <TypeTable type={{
      url: {
        type: "string",
        description: "Direkte Download-URL (aus get_dataset_distributions)"
      },
      format: {
        type: "string",
        description: "Dateiformat: 'csv' oder 'json' (automatisch erkannt, falls nicht angegeben)",
        default: "Automatisch erkannt"
      }
    }} />

    **Rückgabewert:**

    ```json
    {
      "url": "https://example.com/data.csv",
      "format": "csv",
      "partial_fetch": true,
      "columns": [
        {
          "name": "bevölkerung",
          "type": "integer",
          "sample_values": [100000, 150000, 200000]
        },
        {
          "name": "stadt",
          "type": "string",
          "sample_values": ["Wien", "Graz", "Linz"]
        }
      ]
    }
    ```

    **Typerkennung:**

    - Leitet Typen aus ersten 10 Beispielzeilen ab
    - Unterstützt Ganzzahlen, Fließkommazahlen, Booleans, Daten, Zeichenketten
    - CSV: Verarbeitet mehrere Trennzeichen via csv.Sniffer
    - JSON: Erkennt verschachtelte Datenarrays

    **Beispiel:**

    ```python
    preview_schema(
        url="https://example.com/bevoelkerung.csv",
        format="csv"
    )
    ```
  </Accordion>

  <Accordion title="preview_data" id="preview-data">
    Zeigt die ersten Zeilen eines CSV- oder JSON-Datensatzes an. Lädt nur genug Daten, um die angeforderte Anzahl von Zeilen zurückzugeben.

    **Parameter:**

    <TypeTable type={{
      url: {
        type: "string",
        description: "Direkte Download-URL"
      },
      max_rows: {
        type: "integer",
        description: "Maximale Anzahl zurückzugebender Zeilen (1-100)",
        default: 20
      },
      format: {
        type: "string",
        description: "Dateiformat: 'csv' oder 'json'",
        default: "Automatisch erkannt"
      }
    }} />

    **Rückgabewert:**

    ```json
    {
      "url": "https://example.com/data.csv",
      "format": "csv",
      "partial_fetch": true,
      "rows": [
        {"stadt": "Wien", "bevölkerung": 1900000},
        {"stadt": "Graz", "bevölkerung": 291000}
      ],
      "row_count": 2,
      "estimated_total_rows": 100
    }
    ```

    **Abruf-Optimierung:**

    - Standard: 64KB Vorschau (ausreichend für ~1000 CSV-Zeilen)
    - Maximum: 512KB zur Vermeidung von Speicherproblemen
    - Schätzt benötigte Bytes basierend auf Format und max_rows

    **Beispiel:**

    ```python
    preview_data(
        url="https://example.com/bevoelkerung.csv",
        max_rows=50
    )
    ```
  </Accordion>
</Accordions>
