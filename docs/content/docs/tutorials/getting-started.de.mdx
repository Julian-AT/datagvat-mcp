# Erste Schritte

Lernen Sie, wie Sie in 5 Minuten nach österreichischen Open Data suchen.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

- Einen KI-Assistenten, der MCP unterstützt (z.B. Claude Desktop, Cline oder kompatible Tools)
- Den Austria MCP Server installiert und konfiguriert
- Grundlegendes Verständnis für die Interaktion mit Ihrem KI-Assistenten

## 1. Nach Datensätzen suchen

Die häufigste Operation ist die Suche nach Datensätzen. Verwenden Sie `search_datasets`, um Daten über Schlüsselwörter zu finden:

```python
search_datasets(query="Bevölkerung", limit=10)
```

Dies gibt bis zu 10 Datensätze zum Thema Bevölkerung zurück. Die Ergebnisse umfassen:
- Datensatz-ID und Titel
- Beschreibung
- Kategorien (Themen)
- Verfügbare Formate
- Informationen zum Herausgeber
- Datum der letzten Änderung

## 2. Nach Kategorie filtern

Grenzen Sie Ihre Suchergebnisse mithilfe von Themenfiltern ein. Österreich verwendet EU DCAT-AP Themencodes:

```python
search_datasets(
  query="Gesundheit",
  themes=["HEAL"],
  formats=["CSV"]
)
```

**Häufige Themencodes:**
- `HEAL` - Gesundheit
- `SOCI` - Bevölkerung und Gesellschaft
- `ENVI` - Umwelt
- `TRAN` - Verkehr
- `ECON` - Wirtschaft und Finanzen
- `GOVE` - Regierung und öffentlicher Sektor

Siehe [API-Referenz](/api/tools) für die vollständige Liste der 13 EU-Themencodes.

## 3. Datensatz-Details abrufen

Sobald Sie einen Datensatz gefunden haben, rufen Sie seine vollständigen Metadaten ab:

```python
get_dataset(dataset_id="17f04f16-1c02-4f94-90e3-e27e92535a83")
```

Dies gibt umfassende Informationen zurück, einschließlich:
- Vollständige Beschreibung auf Deutsch
- Alle verfügbaren Distributionen (herunterladbare Dateien)
- Schlüsselwörter und Kategorien
- Details zum Herausgeber
- Lizenzinformationen
- Zeitliche und räumliche Abdeckung

## 4. Daten-Vorschau

Überprüfen Sie den Inhalt des Datensatzes vor dem Herunterladen mit dem zweistufigen Vorschau-Workflow:

```python
# Schritt 1: Datensatz-Distributionen abrufen, um Download-URLs zu finden
distributions = get_dataset_distributions(
  dataset_id="17f04f16-1c02-4f94-90e3-e27e92535a83"
)

# Schritt 2: Vorschau der Daten von einer Distributions-URL
preview_data(
  url="https://www.data.gv.at/katalog/dataset/beispiel.csv",
  max_rows=20,
  format="CSV"
)
```

Die Vorschau zeigt:
- Erste 20 Datenzeilen (konfigurierbar)
- Spaltennamen und abgeleitete Typen
- Zusammenfassende Statistiken
- Datenqualitätsindikatoren

**Unterstützte Formate:** CSV, JSON

## 5. Semantische Suche verwenden

Für natürlichsprachige Abfragen verwenden Sie die semantische Suche, die Ihre Abfrage automatisch um verwandte Begriffe erweitert:

```python
semantic_search_datasets(
  natural_query="Gesundheitsdaten aus Wien",
  limit=10
)
```

Semantische Suche:
- Erkennt automatisch Deutsch und Englisch
- Erweitert Abfragen um Synonyme und verwandte Begriffe
- Wendet standardmäßig Qualitätsverstärkung an
- Gibt hochrelevante Ergebnisse zurück

## 6. Verwandte Datensätze finden

Entdecken Sie Datensätze, die einem interessanten Datensatz ähnlich sind:

```python
find_related_datasets(
  dataset_id="17f04f16-1c02-4f94-90e3-e27e92535a83",
  limit=5,
  min_score=20
)
```

Das System bewertet Beziehungen basierend auf:
- Gemeinsamen Themen (höchste Gewichtung)
- Gemeinsamen Schlüsselwörtern
- Gleichem Herausgeber
- Mindestpunktzahl filtert schwache Übereinstimmungen

## Häufige Workflows

### Discovery-Workflow
1. `search_datasets` oder `semantic_search_datasets` - Datensätze finden
2. `get_dataset` - Vollständige Metadaten abrufen
3. `find_related_datasets` - Ähnliche Daten entdecken

### Vorschau-Workflow
1. `search_datasets` - Datensatz finden
2. `get_dataset_distributions` - Download-URLs abrufen
3. `preview_schema` - Struktur prüfen
4. `preview_data` - Beispielzeilen anzeigen

### Qualitätsanalyse-Workflow
1. `search_datasets` mit `quality_boost=true` - Hochwertige Daten finden
2. `analyze_dataset_quality` - Qualitätsmetriken abrufen
3. `get_dataset_metrics` - DQV-Metadatenqualität anzeigen

Bereit für mehr Details? Schauen Sie sich die [Beispiel-Workflows](/examples/workflows) für vollständige End-to-End-Szenarien an.
