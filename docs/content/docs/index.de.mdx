# Willkommen bei Austria MCP

Der definitive MCP-Server zum Entdecken, Analysieren und Zugreifen auf österreichische Open Government Data durch KI-Assistenten.

## Funktionen

- Intelligente Datenset-Suche mit natürlicher Sprache
- Qualitätsbewusste Rangfolge und Empfehlungen
- Datenvorschau-Funktionen
- Semantische Suche mit Deutsch/Englisch-Unterstützung

## Was ist MCP?

Das Model Context Protocol (MCP) ist ein offenes Protokoll, das standardisiert, wie Anwendungen Kontext für LLMs bereitstellen. Austria MCP implementiert dieses Protokoll, um KI-Assistenten nahtlosen Zugriff auf österreichische Regierungsdatensätze zu geben.

## Erste Schritte

Installieren Sie den Austria MCP-Server und beginnen Sie, Tausende von österreichischen Datensätzen durch Ihren KI-Assistenten zu erkunden.
