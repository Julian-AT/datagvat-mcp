# Willkommen bei Austria MCP

Dein MCP Server für österreichische Open Government Data – Entdecken, Analysieren, Zugreifen auf Tausende Datensätze über deinen KI-Assistenten.

## Funktionen

- Intelligente Suche mit natürlicher Sprache
- Automatische Bewertung nach Datenqualität
- Datenvorschau für CSV und JSON
- Semantische Suche mit Deutsch/Englisch-Unterstützung

## Was ist MCP?

Das Model Context Protocol (MCP) ist ein offenes Protokoll, das standardisiert, wie Anwendungen Kontext für LLMs bereitstellen. Austria MCP implementiert dieses Protokoll und gibt KI-Assistenten direkten Zugriff auf österreichische Regierungsdatensätze.

## Erste Schritte

Installiere den Austria MCP Server und starte durch – Tausende österreichische Datensätze warten auf dich.
