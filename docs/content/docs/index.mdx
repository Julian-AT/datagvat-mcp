# Austria MCP Documentation

The definitive MCP server for discovering, analyzing, and accessing Austrian Open Government Data through AI assistants.

## What is Austria MCP?

Austria MCP is a Model Context Protocol server that provides AI assistants with seamless access to thousands of Austrian government datasets. It enables natural language queries, quality-aware ranking, and data previews.

## What is MCP?

<Callout>
  The Model Context Protocol (MCP) is an open protocol that standardizes how applications provide context to LLMs. Austria MCP implements this protocol to give AI assistants seamless access to Austrian government datasets.
</Callout>

MCP enables:

- **Standardized Communication**: Consistent interface for AI assistants
- **Rich Context**: Structured data access for better AI responses
- **Tool Integration**: Seamless function calling capabilities
- **Extensibility**: Easy to extend with custom functionality
