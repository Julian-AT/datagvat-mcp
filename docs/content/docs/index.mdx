# data.gv.at MCP Server documentation

The data.gv.at MCP Server connects AI assistants like Claude to Austria's open government data catalog. You can search datasets, analyze quality, preview data, and build workflows—all through natural language.

## What you can do

Search 30,000+ Austrian government datasets by keywords, themes, or natural language queries. Get instant quality scores based on metadata completeness. Preview CSV and JSON data without downloading. Find related datasets by topic or publisher.

## Features

**Search and discovery**
Find datasets using keyword search, category filters, or semantic search with automatic query expansion.

**Data preview**
Inspect CSV and JSON data before downloading. View structure, types, and sample rows.

**Quality analysis**
Get quality scores (0-100) based on metadata completeness using DQV standards.

**Related datasets**
Discover similar datasets by shared themes, keywords, or publisher.

## Example queries

Ask Claude in natural language:

- "Find health datasets from Vienna published in 2024"
- "Show me the top 5 quality datasets about population statistics"
- "Preview the first 20 rows of dataset abc-123"
- "What datasets are related to Bevölkerung Wien 2020-2024?"

## Technology

Built with FastMCP (Python) for the Model Context Protocol. Uses the Piveau API to access Austria's data.gv.at catalog. Provides 12 tools and resource access through MCP 1.0.
