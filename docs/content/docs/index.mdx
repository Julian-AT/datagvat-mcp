# Austria MCP Documentation

The definitive MCP server for discovering, analyzing, and accessing Austrian Open Government Data through AI assistants.

## What is Austria MCP?

Austria MCP is a Model Context Protocol server that provides AI assistants with seamless access to thousands of Austrian government datasets. It enables natural language queries, quality-aware ranking, and data previews.

## What is MCP?

<Callout>
  The Model Context Protocol (MCP) is an open protocol that standardizes how applications provide context to LLMs. Austria MCP implements this protocol to give AI assistants seamless access to Austrian government datasets.
</Callout>

MCP enables:

- **Standardized Communication**: Consistent interface for AI assistants
- **Rich Context**: Structured data access for better AI responses
- **Tool Integration**: Seamless function calling capabilities
- **Extensibility**: Easy to extend with custom functionality

## Architecture Overview

The Austria MCP server connects Claude Desktop to Austrian government datasets through a robust, layered architecture:

```
┌─────────────────────────────────────────────────────────────┐
│                      Claude Desktop                         │
│                      (MCP Client)                          │
└────────────────────┬────────────────────────────────────────┘
                     │ MCP Protocol (stdio)
                     ▼
┌─────────────────────────────────────────────────────────────┐
│                  Austria MCP Server                         │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐  │
│  │              FastMCP Framework                       │  │
│  │     (Protocol handling & standard MCP features)      │  │
│  └─────────────────────────────────────────────────────┘  │
│                           │                                 │
│  ┌─────────────────────────────────────────────────────┐  │
│  │             Middleware Stack                         │  │
│  │  ┌────────────────────────────────────────────┐    │  │
│  │  │ Logging → Error → Retry → RateLimit        │    │  │
│  │  │        → Audit → Auth                      │    │  │
│  │  └────────────────────────────────────────────┘    │  │
│  └─────────────────────────────────────────────────────┘  │
│                           │                                 │
│  ┌─────────────────────────────────────────────────────┐  │
│  │               Tool Categories                        │  │
│  │  • Discovery (search, list catalogues)              │  │
│  │  • Management (create, update, delete datasets)     │  │
│  │  • Analysis (quality scoring, find related)         │  │
│  │  • Vocabularies (EU themes, formats, terms)         │  │
│  │  • Preview (CSV, JSON, XML data samples)            │  │
│  └─────────────────────────────────────────────────────┘  │
│                           │                                 │
│  ┌─────────────────────────────────────────────────────┐  │
│  │            Piveau API Client                         │  │
│  │   (Connection pooling, request optimization)         │  │
│  └─────────────────────────────────────────────────────┘  │
└────────────────────┬────────────────────────────────────────┘
                     │ HTTPS
                     ▼
┌─────────────────────────────────────────────────────────────┐
│               Piveau API (data.gv.at)                       │
│        Austrian Open Government Data Catalog               │
└─────────────────────────────────────────────────────────────┘
```

This architecture provides:

- **Clean separation** between MCP protocol handling (FastMCP) and business logic (tools)
- **Layered middleware** for logging, error handling, retries, rate limiting, and auth
- **Organized tools** by functional category for easy discovery
- **Efficient API client** with connection pooling and request optimization
