# Performance Optimization

Maximize performance and efficiency when working with Austria MCP.

## Search Optimization

### Use Specific Filters

Narrow searches early to reduce result sets:

```python
# ✗ Slow: Retrieve everything then filter
all_results = search_datasets(query="", limit=1000)
csv_only = [d for d in all_results['results'] if has_csv_format(d)]

# ✓ Fast: Filter at API level
csv_results = search_datasets(query="", formats=["CSV"], limit=100)
```

**Performance gain:** 10-50x faster for filtered searches

### Limit Result Sets

Only request what you need:

```python
# ✗ Wasteful: Request more than needed
results = search_datasets(query="health", limit=100)
top_5 = results['results'][:5]

# ✓ Efficient: Request exactly what's needed
results = search_datasets(query="health", limit=5)
```

**Impact:** Smaller payloads, faster network transfer, reduced parsing time

### Use Quality Boost Wisely

Enable quality boost only when quality matters:

```python
# ✓ Good: Quality matters for production use
production_data = search_datasets(
  query="economic indicators",
  quality_boost=True,
  limit=10
)

# ✓ Good: Speed matters for exploration
quick_browse = search_datasets(
  query="economic indicators",
  quality_boost=False,  # Faster
  limit=50
)
```

**Quality boost overhead:** ~10-20% slower due to scoring computation

## Preview Optimization

### Schema First, Data Second

Check structure before downloading data:

```python
# ✓ Optimal: Check schema first (minimal data transfer)
schema = preview_schema(url=download_url, format="CSV")

if is_structure_valid(schema):
  # Only then preview data
  preview = preview_data(url=download_url, max_rows=20, format="CSV")
```

**Data transfer savings:**
- `preview_schema`: ~5-10 KB
- `preview_data`: ~20-50 KB (20 rows)
- Full download: 1+ MB

### Appropriate Sample Sizes

Match sample size to use case:

```python
# Quick validation (fastest)
preview_data(url=url, max_rows=10)  # ~5 KB

# Standard preview (balanced)
preview_data(url=url, max_rows=20)  # ~10 KB

# Detailed inspection (slower)
preview_data(url=url, max_rows=100)  # ~50 KB

# Maximum sample (slowest)
preview_data(url=url, max_rows=1000)  # ~500 KB
```

**Rule of thumb:** Use smallest sample that meets your needs

### Avoid Repeated Previews

Cache preview results:

```python
# ✗ Inefficient: Preview same URL multiple times
for analysis_type in ['structure', 'quality', 'content']:
  preview = preview_data(url=url, max_rows=20)
  analyze(preview, analysis_type)

# ✓ Efficient: Preview once, analyze multiple times
preview = preview_data(url=url, max_rows=20)
for analysis_type in ['structure', 'quality', 'content']:
  analyze(preview, analysis_type)
```

## Caching Strategies

### Cache Dataset Metadata

Avoid repeated API calls for same datasets:

```python
metadata_cache = {}

def get_dataset_cached(dataset_id):
  """Get dataset with caching."""
  if dataset_id not in metadata_cache:
    metadata_cache[dataset_id] = get_dataset(dataset_id=dataset_id)
  return metadata_cache[dataset_id]

# Use cached version
dataset = get_dataset_cached(dataset_id)
```

**Performance gain:** Near-instant retrieval for cached items

### Cache Quality Analysis

Quality analysis is expensive - cache results:

```python
quality_cache = {}

def analyze_quality_cached(dataset_id):
  """Analyze quality with caching."""
  if dataset_id not in quality_cache:
    quality_cache[dataset_id] = analyze_dataset_quality(
      dataset_id=dataset_id
    )
  return quality_cache[dataset_id]
```

### Time-Based Cache Invalidation

Invalidate cache after reasonable period:

```python
from datetime import datetime, timedelta

cache = {}
cache_times = {}
CACHE_TTL = timedelta(hours=1)

def get_with_ttl_cache(dataset_id):
  """Get dataset with time-to-live cache."""
  now = datetime.now()

  # Check if cached and not expired
  if dataset_id in cache:
    if now - cache_times[dataset_id] < CACHE_TTL:
      return cache[dataset_id]

  # Fetch fresh data
  data = get_dataset(dataset_id=dataset_id)
  cache[dataset_id] = data
  cache_times[dataset_id] = now

  return data
```

## Pagination Best Practices

### Iterate Efficiently

Use generator pattern for large result sets:

```python
def iterate_all_datasets(query, **kwargs):
  """Generator that yields all matching datasets."""
  limit = 50  # Reasonable page size
  offset = 0

  while True:
    page = search_datasets(
      query=query,
      limit=limit,
      offset=offset,
      **kwargs
    )

    # Yield each result
    for dataset in page['results']:
      yield dataset

    # Check if more pages
    if offset + limit >= page['count']:
      break

    offset += limit

# Use generator
for dataset in iterate_all_datasets("health", themes=["HEAL"]):
  process(dataset)
```

**Memory efficiency:** Processes one page at a time

### Parallel Page Fetching

For read-only analysis, fetch pages in parallel:

```python
import asyncio

async def fetch_page(query, offset, limit):
  """Fetch single page (async)."""
  return search_datasets(
    query=query,
    limit=limit,
    offset=offset
  )

async def fetch_all_pages_parallel(query, total_count, page_size=50):
  """Fetch all pages in parallel."""
  offsets = range(0, total_count, page_size)

  tasks = [
    fetch_page(query, offset, page_size)
    for offset in offsets
  ]

  pages = await asyncio.gather(*tasks)

  # Flatten results
  all_results = []
  for page in pages:
    all_results.extend(page['results'])

  return all_results
```

**Performance gain:** 5-10x faster for large result sets

## Semantic Search Optimization

### Pre-expand Queries When Possible

For repeated queries, expand once:

```python
# ✗ Inefficient: Semantic expansion on every call
for user in users:
  results = semantic_search_datasets(
    natural_query="health data Vienna",
    limit=10
  )
  send_results(user, results)

# ✓ Efficient: Expand once, search multiple times
# First call expands query
expanded_results = semantic_search_datasets(
  natural_query="health data Vienna",
  limit=100
)

# Distribute to users without re-expanding
for user in users:
  user_results = expanded_results['results'][:10]
  send_results(user, user_results)
```

### Fall Back to Regular Search

For simple queries, regular search is faster:

```python
def smart_search(query, **kwargs):
  """Choose optimal search method."""
  # Simple keyword? Use regular search
  if len(query.split()) <= 2:
    return search_datasets(query=query, **kwargs)

  # Complex natural language? Use semantic search
  return semantic_search_datasets(natural_query=query, **kwargs)
```

## Error Handling Optimization

### Fail Fast

Validate inputs before expensive operations:

```python
# ✓ Efficient: Validate early
def preview_with_validation(url, format):
  # Quick validation (no network call)
  if not url.startswith(('http://', 'https://')):
    raise ValueError("Invalid URL")

  if format not in ['CSV', 'JSON']:
    raise ValueError("Unsupported format")

  # Only then make expensive preview call
  return preview_data(url=url, format=format)
```

### Graceful Degradation

Handle failures without breaking workflow:

```python
def get_dataset_safe(dataset_id, default=None):
  """Get dataset with graceful fallback."""
  try:
    return get_dataset(dataset_id=dataset_id)
  except ToolError:
    return default

# Use in workflows
dataset = get_dataset_safe(dataset_id)
if dataset:
  process(dataset)
else:
  log_warning(f"Dataset {dataset_id} unavailable")
```

## Batch Processing

### Group Related Operations

Minimize round trips by batching:

```python
# ✗ Inefficient: One-by-one processing
for dataset_id in dataset_ids:
  dataset = get_dataset(dataset_id=dataset_id)
  quality = analyze_dataset_quality(dataset_id=dataset_id)
  process(dataset, quality)

# ✓ Efficient: Batch by operation type
datasets = [get_dataset(dataset_id=id) for id in dataset_ids]
qualities = [analyze_dataset_quality(dataset_id=id) for id in dataset_ids]

for dataset, quality in zip(datasets, qualities):
  process(dataset, quality)
```

## Network Optimization

### Minimize API Calls

Fetch what you need in one call:

```python
# ✗ Multiple calls for same dataset
dataset = get_dataset(dataset_id=dataset_id)
distributions = get_dataset_distributions(dataset_id=dataset_id)

# ✓ Single call includes distributions
dataset = get_dataset(dataset_id=dataset_id)
distributions = dataset.get('distributions', [])
```

### Connection Reuse

The Austria MCP client reuses connections automatically, but ensure you're not recreating clients:

```python
# ✗ Inefficient: New client each time
def search_many_times(queries):
  results = []
  for query in queries:
    # Implicit client creation per search
    results.append(search_datasets(query=query))
  return results

# ✓ Efficient: Client reused across calls
def search_many_times(queries):
  # MCP server maintains single client
  results = []
  for query in queries:
    results.append(search_datasets(query=query))
  return results
```

## Memory Optimization

### Stream Large Results

Don't load everything into memory:

```python
# ✗ Memory-intensive: Load all at once
all_datasets = search_datasets(query="", limit=10000)
for dataset in all_datasets['results']:
  process(dataset)

# ✓ Memory-efficient: Process in pages
limit = 50
offset = 0

while True:
  page = search_datasets(query="", limit=limit, offset=offset)

  for dataset in page['results']:
    process(dataset)  # Process one at a time

  if offset + limit >= page['count']:
    break

  offset += limit
```

### Clean Up Caches

Prevent unbounded cache growth:

```python
from collections import OrderedDict

class LRUCache:
  """Simple LRU cache with size limit."""

  def __init__(self, max_size=100):
    self.cache = OrderedDict()
    self.max_size = max_size

  def get(self, key):
    if key not in self.cache:
      return None
    # Move to end (most recently used)
    self.cache.move_to_end(key)
    return self.cache[key]

  def set(self, key, value):
    self.cache[key] = value
    self.cache.move_to_end(key)

    # Evict oldest if over size
    if len(self.cache) > self.max_size:
      self.cache.popitem(last=False)

# Use for dataset caching
dataset_cache = LRUCache(max_size=100)
```

## Performance Monitoring

### Measure Operation Times

Track performance to identify bottlenecks:

```python
import time

def timed_search(query, **kwargs):
  """Search with timing."""
  start = time.time()

  results = search_datasets(query=query, **kwargs)

  elapsed = time.time() - start
  print(f"Search took {elapsed:.2f}s, found {results['count']} results")

  return results
```

### Log Slow Operations

Identify optimization opportunities:

```python
def search_with_logging(query, **kwargs):
  """Search with performance logging."""
  start = time.time()
  results = search_datasets(query=query, **kwargs)
  elapsed = time.time() - start

  # Log slow searches
  if elapsed > 2.0:
    print(f"SLOW: Search '{query}' took {elapsed:.2f}s")

  return results
```

## Summary: Quick Wins

**Top 5 optimization techniques:**

1. **Filter early**: Use API filters instead of client-side filtering
2. **Limit results**: Request only what you need
3. **Cache aggressively**: Cache metadata and quality analysis
4. **Schema first**: Check structure before downloading data
5. **Batch operations**: Group related API calls together

**Expected improvements:**
- Search: 10-50x faster with proper filtering
- Preview: 5-10x faster with schema-first approach
- Repeated operations: 100x faster with caching
- Large datasets: 5-10x faster with pagination
- Memory usage: 10-20x reduction with streaming
