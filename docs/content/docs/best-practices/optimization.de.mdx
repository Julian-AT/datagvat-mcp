# Performance-Optimierung

Maximieren Sie Leistung und Effizienz bei der Arbeit mit Austria MCP.

## Such-Optimierung

### Verwenden Sie spezifische Filter

Grenzen Sie Suchen früh ein, um Ergebnismengen zu reduzieren:

```python
# ✗ Langsam: Alles abrufen und dann filtern
all_results = search_datasets(query="", limit=1000)
csv_only = [d for d in all_results['results'] if has_csv_format(d)]

# ✓ Schnell: Auf API-Ebene filtern
csv_results = search_datasets(query="", formats=["CSV"], limit=100)
```

**Leistungsgewinn:** 10-50x schneller für gefilterte Suchen

### Begrenzen Sie Ergebnismengen

Fordern Sie nur an, was Sie benötigen:

```python
# ✗ Verschwenderisch: Mehr anfordern als benötigt
results = search_datasets(query="Gesundheit", limit=100)
top_5 = results['results'][:5]

# ✓ Effizient: Genau das anfordern, was benötigt wird
results = search_datasets(query="Gesundheit", limit=5)
```

**Auswirkung:** Kleinere Nutzlasten, schnellere Netzwerkübertragung, reduzierte Parsing-Zeit

### Verwenden Sie Quality Boost gezielt

Aktivieren Sie Quality Boost nur, wenn Qualität wichtig ist:

```python
# ✓ Gut: Qualität ist wichtig für Produktionsdaten
production_data = search_datasets(
  query="Wirtschaftsindikatoren",
  quality_boost=True,
  limit=10
)

# ✓ Gut: Geschwindigkeit ist wichtig für Erkundung
quick_browse = search_datasets(
  query="Wirtschaftsindikatoren",
  quality_boost=False,  # Schneller
  limit=50
)
```

**Quality Boost Overhead:** ~10-20% langsamer aufgrund der Bewertungsberechnung

## Preview-Optimierung

### Erst Schema, dann Daten

Überprüfen Sie die Struktur vor dem Herunterladen der Daten:

```python
# ✓ Optimal: Zuerst Schema prüfen (minimale Datenübertragung)
schema = preview_schema(url=download_url, format="CSV")

if is_structure_valid(schema):
  # Erst dann Daten vorschauen
  preview = preview_data(url=download_url, max_rows=20, format="CSV")
```

**Datenübertragungs-Einsparungen:**
- `preview_schema`: ~5-10 KB
- `preview_data`: ~20-50 KB (20 Zeilen)
- Vollständiger Download: 1+ MB

### Angemessene Stichprobengrößen

Passen Sie die Stichprobengröße an den Anwendungsfall an:

```python
# Schnelle Validierung (am schnellsten)
preview_data(url=url, max_rows=10)  # ~5 KB

# Standard-Vorschau (ausgewogen)
preview_data(url=url, max_rows=20)  # ~10 KB

# Detaillierte Inspektion (langsamer)
preview_data(url=url, max_rows=100)  # ~50 KB

# Maximale Stichprobe (am langsamsten)
preview_data(url=url, max_rows=1000)  # ~500 KB
```

**Faustregel:** Verwenden Sie die kleinste Stichprobe, die Ihren Anforderungen entspricht

### Vermeiden Sie wiederholte Vorschauen

Cachen Sie Vorschau-Ergebnisse:

```python
# ✗ Ineffizient: Mehrmals dieselbe URL vorschauen
for analysis_type in ['structure', 'quality', 'content']:
  preview = preview_data(url=url, max_rows=20)
  analyze(preview, analysis_type)

# ✓ Effizient: Einmal vorschauen, mehrmals analysieren
preview = preview_data(url=url, max_rows=20)
for analysis_type in ['structure', 'quality', 'content']:
  analyze(preview, analysis_type)
```

## Caching-Strategien

### Datensatz-Metadaten cachen

Vermeiden Sie wiederholte API-Aufrufe für dieselben Datensätze:

```python
metadata_cache = {}

def get_dataset_cached(dataset_id):
  """Datensatz mit Caching abrufen."""
  if dataset_id not in metadata_cache:
    metadata_cache[dataset_id] = get_dataset(dataset_id=dataset_id)
  return metadata_cache[dataset_id]

# Verwenden Sie die gecachte Version
dataset = get_dataset_cached(dataset_id)
```

**Leistungsgewinn:** Nahezu sofortiger Abruf für gecachte Elemente

### Qualitätsanalyse cachen

Qualitätsanalyse ist teuer - cachen Sie die Ergebnisse:

```python
quality_cache = {}

def analyze_quality_cached(dataset_id):
  """Qualität mit Caching analysieren."""
  if dataset_id not in quality_cache:
    quality_cache[dataset_id] = analyze_dataset_quality(
      dataset_id=dataset_id
    )
  return quality_cache[dataset_id]
```

### Zeitbasierte Cache-Invalidierung

Invalidieren Sie den Cache nach angemessener Zeit:

```python
from datetime import datetime, timedelta

cache = {}
cache_times = {}
CACHE_TTL = timedelta(hours=1)

def get_with_ttl_cache(dataset_id):
  """Datensatz mit Time-to-Live-Cache abrufen."""
  now = datetime.now()

  # Prüfen, ob gecacht und nicht abgelaufen
  if dataset_id in cache:
    if now - cache_times[dataset_id] < CACHE_TTL:
      return cache[dataset_id]

  # Frische Daten abrufen
  data = get_dataset(dataset_id=dataset_id)
  cache[dataset_id] = data
  cache_times[dataset_id] = now

  return data
```

## Best Practices für Paginierung

### Effizient iterieren

Verwenden Sie das Generator-Muster für große Ergebnismengen:

```python
def iterate_all_datasets(query, **kwargs):
  """Generator, der alle passenden Datensätze liefert."""
  limit = 50  # Vernünftige Seitengröße
  offset = 0

  while True:
    page = search_datasets(
      query=query,
      limit=limit,
      offset=offset,
      **kwargs
    )

    # Jedes Ergebnis liefern
    for dataset in page['results']:
      yield dataset

    # Prüfen, ob weitere Seiten vorhanden sind
    if offset + limit >= page['count']:
      break

    offset += limit

# Generator verwenden
for dataset in iterate_all_datasets("Gesundheit", themes=["HEAL"]):
  process(dataset)
```

**Speicher-Effizienz:** Verarbeitet jeweils eine Seite

### Paralleles Abrufen von Seiten

Für reine Lesevorgänge, Seiten parallel abrufen:

```python
import asyncio

async def fetch_page(query, offset, limit):
  """Einzelne Seite abrufen (async)."""
  return search_datasets(
    query=query,
    limit=limit,
    offset=offset
  )

async def fetch_all_pages_parallel(query, total_count, page_size=50):
  """Alle Seiten parallel abrufen."""
  offsets = range(0, total_count, page_size)

  tasks = [
    fetch_page(query, offset, page_size)
    for offset in offsets
  ]

  pages = await asyncio.gather(*tasks)

  # Ergebnisse zusammenführen
  all_results = []
  for page in pages:
    all_results.extend(page['results'])

  return all_results
```

**Leistungsgewinn:** 5-10x schneller für große Ergebnismengen

## Optimierung der semantischen Suche

### Abfragen bei Möglichkeit vorab erweitern

Für wiederholte Abfragen, einmal erweitern:

```python
# ✗ Ineffizient: Semantische Erweiterung bei jedem Aufruf
for user in users:
  results = semantic_search_datasets(
    natural_query="Gesundheitsdaten Wien",
    limit=10
  )
  send_results(user, results)

# ✓ Effizient: Einmal erweitern, mehrmals suchen
# Erster Aufruf erweitert Abfrage
expanded_results = semantic_search_datasets(
  natural_query="Gesundheitsdaten Wien",
  limit=100
)

# An Benutzer verteilen ohne erneute Erweiterung
for user in users:
  user_results = expanded_results['results'][:10]
  send_results(user, user_results)
```

### Auf reguläre Suche zurückgreifen

Für einfache Abfragen ist die reguläre Suche schneller:

```python
def smart_search(query, **kwargs):
  """Optimale Suchmethode wählen."""
  # Einfaches Schlüsselwort? Reguläre Suche verwenden
  if len(query.split()) <= 2:
    return search_datasets(query=query, **kwargs)

  # Komplexe natürliche Sprache? Semantische Suche verwenden
  return semantic_search_datasets(natural_query=query, **kwargs)
```

## Optimierung der Fehlerbehandlung

### Schnell scheitern

Validieren Sie Eingaben vor teuren Operationen:

```python
# ✓ Effizient: Frühe Validierung
def preview_with_validation(url, format):
  # Schnelle Validierung (kein Netzwerkaufruf)
  if not url.startswith(('http://', 'https://')):
    raise ValueError("Ungültige URL")

  if format not in ['CSV', 'JSON']:
    raise ValueError("Nicht unterstütztes Format")

  # Erst dann teuren Preview-Aufruf durchführen
  return preview_data(url=url, format=format)
```

### Graziöse Degradierung

Behandeln Sie Fehler, ohne den Workflow zu unterbrechen:

```python
def get_dataset_safe(dataset_id, default=None):
  """Datensatz mit graziosem Fallback abrufen."""
  try:
    return get_dataset(dataset_id=dataset_id)
  except ToolError:
    return default

# In Workflows verwenden
dataset = get_dataset_safe(dataset_id)
if dataset:
  process(dataset)
else:
  log_warning(f"Datensatz {dataset_id} nicht verfügbar")
```

## Batch-Verarbeitung

### Verwandte Operationen gruppieren

Minimieren Sie Roundtrips durch Batching:

```python
# ✗ Ineffizient: Einzelne Verarbeitung
for dataset_id in dataset_ids:
  dataset = get_dataset(dataset_id=dataset_id)
  quality = analyze_dataset_quality(dataset_id=dataset_id)
  process(dataset, quality)

# ✓ Effizient: Batch nach Operationstyp
datasets = [get_dataset(dataset_id=id) for id in dataset_ids]
qualities = [analyze_dataset_quality(dataset_id=id) for id in dataset_ids]

for dataset, quality in zip(datasets, qualities):
  process(dataset, quality)
```

## Netzwerk-Optimierung

### API-Aufrufe minimieren

Holen Sie, was Sie benötigen, in einem Aufruf:

```python
# ✗ Mehrere Aufrufe für denselben Datensatz
dataset = get_dataset(dataset_id=dataset_id)
distributions = get_dataset_distributions(dataset_id=dataset_id)

# ✓ Einzelner Aufruf enthält Distributionen
dataset = get_dataset(dataset_id=dataset_id)
distributions = dataset.get('distributions', [])
```

### Verbindungswiederverwendung

Der Austria MCP-Client verwendet Verbindungen automatisch wieder, aber stellen Sie sicher, dass Sie keine Clients neu erstellen:

```python
# ✗ Ineffizient: Jedes Mal neuer Client
def search_many_times(queries):
  results = []
  for query in queries:
    # Implizite Client-Erstellung pro Suche
    results.append(search_datasets(query=query))
  return results

# ✓ Effizient: Client wird über Aufrufe hinweg wiederverwendet
def search_many_times(queries):
  # MCP-Server hält einen einzigen Client
  results = []
  for query in queries:
    results.append(search_datasets(query=query))
  return results
```

## Speicher-Optimierung

### Große Ergebnisse streamen

Laden Sie nicht alles in den Speicher:

```python
# ✗ Speicherintensiv: Alles auf einmal laden
all_datasets = search_datasets(query="", limit=10000)
for dataset in all_datasets['results']:
  process(dataset)

# ✓ Speicher-effizient: In Seiten verarbeiten
limit = 50
offset = 0

while True:
  page = search_datasets(query="", limit=limit, offset=offset)

  for dataset in page['results']:
    process(dataset)  # Einzeln verarbeiten

  if offset + limit >= page['count']:
    break

  offset += limit
```

### Caches aufräumen

Verhindern Sie unbegrenztes Cache-Wachstum:

```python
from collections import OrderedDict

class LRUCache:
  """Einfacher LRU-Cache mit Größenbeschränkung."""

  def __init__(self, max_size=100):
    self.cache = OrderedDict()
    self.max_size = max_size

  def get(self, key):
    if key not in self.cache:
      return None
    # An das Ende verschieben (zuletzt verwendet)
    self.cache.move_to_end(key)
    return self.cache[key]

  def set(self, key, value):
    self.cache[key] = value
    self.cache.move_to_end(key)

    # Ältestes entfernen, wenn über Größe
    if len(self.cache) > self.max_size:
      self.cache.popitem(last=False)

# Für Datensatz-Caching verwenden
dataset_cache = LRUCache(max_size=100)
```

## Leistungsüberwachung

### Operationszeiten messen

Verfolgen Sie die Leistung, um Engpässe zu identifizieren:

```python
import time

def timed_search(query, **kwargs):
  """Suche mit Zeitmessung."""
  start = time.time()

  results = search_datasets(query=query, **kwargs)

  elapsed = time.time() - start
  print(f"Suche dauerte {elapsed:.2f}s, {results['count']} Ergebnisse gefunden")

  return results
```

### Langsame Operationen protokollieren

Identifizieren Sie Optimierungsmöglichkeiten:

```python
def search_with_logging(query, **kwargs):
  """Suche mit Leistungsprotokollierung."""
  start = time.time()
  results = search_datasets(query=query, **kwargs)
  elapsed = time.time() - start

  # Langsame Suchen protokollieren
  if elapsed > 2.0:
    print(f"LANGSAM: Suche '{query}' dauerte {elapsed:.2f}s")

  return results
```

## Zusammenfassung: Schnelle Erfolge

**Top 5 Optimierungstechniken:**

1. **Früh filtern**: Verwenden Sie API-Filter statt clientseitiger Filterung
2. **Ergebnisse begrenzen**: Fordern Sie nur an, was Sie benötigen
3. **Aggressiv cachen**: Cachen Sie Metadaten und Qualitätsanalysen
4. **Erst Schema**: Überprüfen Sie die Struktur vor dem Herunterladen von Daten
5. **Batch-Operationen**: Gruppieren Sie verwandte API-Aufrufe

**Erwartete Verbesserungen:**
- Suche: 10-50x schneller mit korrekter Filterung
- Vorschau: 5-10x schneller mit Schema-First-Ansatz
- Wiederholte Operationen: 100x schneller mit Caching
- Große Datensätze: 5-10x schneller mit Paginierung
- Speichernutzung: 10-20x Reduktion durch Streaming
