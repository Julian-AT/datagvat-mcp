## Workflow 1: Suchen → Vorschau → Download

<Tabs items={['Vollständiges Beispiel', 'Schritt für Schritt']} persist groupId="workflow-style">
  <Tab value="Vollständiges Beispiel">
    Vollständige Reise von der Suche bis zum Datenzugriff:

    ```python
    # All-in-One-Entdeckungs-Workflow
    # 1. Nach Datensätzen suchen
    ergebnisse = search_datasets(
      query="Gesundheitsstatistiken",
      themes=["HEAL"],
      formats=["CSV"],
      publishers=["Stadt Wien"],
      quality_boost=True,
      limit=10
    )

    # 2. Datensatzdetails abrufen
    dataset_id = ergebnisse['results'][0]['id']
    dataset = get_dataset(dataset_id=dataset_id)

    # 3. Download-URL abrufen
    distributionen = get_dataset_distributions(dataset_id=dataset_id)
    csv_dist = next((d for d in distributionen if d.get('format', {}).get('id') == 'CSV'), None)
    download_url = csv_dist['access_url']

    # 4. Schema und Daten in Vorschau anzeigen
    schema = preview_schema(url=download_url, format="CSV")
    vorschau = preview_data(url=download_url, max_rows=20, format="CSV")

    # 5. Validieren und fortfahren
    erwartete_spalten = ["jahr", "region", "faelle"]
    tatsaechliche_spalten = [c['name'] for c in schema['columns']]

    if all(col in tatsaechliche_spalten for col in erwartete_spalten):
      print("✓ Schema validiert - bereit zum Herunterladen")
      # Mit download_url fortfahren
    ```
  </Tab>

  <Tab value="Schritt für Schritt">
    <Steps>
      <Step>
        ### Nach Datensätzen suchen
        Relevante Datensätze mit Filtern finden:

      <Step>
        ### Datensatz auswählen und untersuchen
        Vollständige Metadaten für ausgewählten Datensatz abrufen:

        ```python
        # Vollständige Metadaten abrufen
        dataset = get_dataset(dataset_id=dataset_id)

        # Wichtige Informationen überprüfen
        print(f"Titel: {dataset['title']['de']}")
        print(f"Beschreibung: {dataset['description']['de'][:200]}...")
        print(f"Geändert: {dataset['modified']}")
        print(f"Herausgeber: {dataset['publisher']['name']}")
        print(f"Lizenz: {dataset.get('license', 'Nicht angegeben')}")
        ```
      </Step>

      <Step>
        ### Download-URLs abrufen
        Distributionsinformationen abrufen:

        ```python

          (d for d in distributionen
           if d.get('format', {}).get('id') == 'CSV'),
          None
        )

        if csv_dist:
          download_url = csv_dist['access_url']
          datei_groesse = csv_dist.get('byte_size', 'Unbekannt')

          print(f"Dateigröße: {datei_groesse} Bytes")
        ```

      </Step>

      <Step>
        ### Vorschau vor Download
        Schema und Beispieldaten prüfen:

        ```python
        # Schema zuerst prüfen

        print("Spalten:")
        for col in schema['columns']:
          print(f"  - {col['name']}: {col['type']}")

        # Beispieldaten in Vorschau anzeigen
        vorschau = preview_data(url=download_url, max_rows=20, format="CSV")

        print(f"\nZeige {vorschau['row_count']} Beispielzeilen:")
        for row in vorschau['data'][:5]:
          print(row)
        ```

      </Step>

      <Step>
        ### Verifizieren und Herunterladen
        Struktur vor dem Fortfahren validieren:

        ```python
        if all(col in tatsaechliche_spalten for col in erwartete_spalten):
          print("✓ Schema validiert")
          # Mit vollständigem Download über download_url fortfahren
          # (Download-Implementierung abhängig von Ihrer Umgebung)
        else:
          print("✗ Schema-Diskrepanz, Datensatz prüfen")
        ```
      </Step>
    </Steps>

## Workflow 2: Semantische Suche → Verwandte Datensätze

<Tabs items={['Vollständiges Beispiel', 'Schritt für Schritt']} persist groupId="workflow-style">
  <Tab value="Vollständiges Beispiel">
    Verwandte Daten durch intelligente Suche entdecken:

    ```python
    # All-in-One-Semantik-Entdeckungs-Workflow
    # 1. Semantische Suche
    ergebnisse = semantic_search_datasets(
      natural_query="Klimawandeldaten für österreichische Städte",
      limit=5
    )

    # 2. Qualität analysieren
    dataset_id = ergebnisse['results'][0]['id']
    qualitaet = analyze_dataset_quality(dataset_id=dataset_id)

    # 3. Verwandte Datensätze finden
    verwandt = find_related_datasets(
      dataset_id=dataset_id,
      limit=5,
      min_score=30
    )

    # 4. Datensätze vergleichen
    original = get_dataset(dataset_id=dataset_id)
    verwandter_dataset = get_dataset(dataset_id=verwandt['results'][0]['id'])

    original_themen = {c['id'] for c in original.get('categories', [])}
    verwandte_themen = {c['id'] for c in verwandter_dataset.get('categories', [])}
    gemeinsame_themen = original_themen & verwandte_themen

    print(f"Original: {original['title']['de']}")
    print(f"Verwandt: {verwandter_dataset['title']['de']}")
    print(f"Gemeinsame Themen: {', '.join(gemeinsame_themen)}")
    print(f"Qualitätsbewertung: {qualitaet['score']}/100")
    ```
  </Tab>

  <Tab value="Schritt für Schritt">
    <Steps>
      <Step>
        ### Natürlichsprachige Abfrage

      </Step>

      <Step>
        ### Qualität analysieren
        Umfassende Qualitätsmetriken abrufen:

        ```python

        # Umfassende Qualitätsanalyse abrufen

        print(f"Qualitätsbewertung: {qualitaet['score']}/100")
        ```

        Ähnliche Datensätze basierend auf Themen und Schlüsselwörtern entdecken:

        ```python
          dataset_id=dataset_id,
          limit=5,
          min_score=30
        )

        print(f"\n{len(verwandt['results'])} verwandte Datensätze gefunden:")

        for dataset in verwandt['results']:
          titel = dataset.get('title', {}).get('de', 'Kein Titel')
          bewertung = dataset.get('match_score', 0)
          themen = [t.get('id') for t in dataset.get('themes', [])]

          print(f"Bewertung {bewertung}: {titel}")
          print(f"  Gemeinsame Themen: {', '.join(themen)}")
        ```
      </Step>

      <Step>
        ### Datensätze vergleichen
        Ähnlichkeiten zwischen Datensätzen analysieren:

        ```python

        original_themen = {c['id'] for c in original.get('categories', [])}
        verwandte_themen = {c['id'] for c in verwandter_dataset.get('categories', [])}
        gemeinsame_themen = original_themen & verwandte_themen

        print(f"Gemeinsame Themen: {', '.join(gemeinsame_themen)}")
        ```

## Workflow 3: Qualitätsgefilterte Suche

<Tabs items={['Vollständiges Beispiel', 'Schritt für Schritt']} persist groupId="workflow-style">
  <Tab value="Vollständiges Beispiel">
    Hochwertige Datensätze für den Produktionseinsatz finden:

    ```python
    # Qualitätsfokussierter Entdeckungs-Workflow
    # 1. Qualitätsbewusste Suche
    ergebnisse = search_datasets(
      query="",
      themes=["ECON"],
      formats=["CSV", "JSON"],
      quality_boost=True,
      sort_by="modified_desc",
      limit=20
    )

    # 2. Nach Qualitätsmetriken filtern
    hochwertig = []
    for dataset in ergebnisse['results'][:10]:
      qualitaet = analyze_dataset_quality(dataset_id=dataset['id'])

      if qualitaet['score'] > 70:
        kritisch_ok = all([
          qualitaet['components']['has_title'],
          qualitaet['components']['has_description'],
          qualitaet['components']['has_publisher'],
          qualitaet['components']['has_license']
        ])

        if kritisch_ok:
          hochwertig.append({
            'id': dataset['id'],
            'titel': dataset.get('title', {}).get('de'),
            'bewertung': qualitaet['score']
          })

    # 3. Datenzugänglichkeit verifizieren
    zugaenglich = []
    for dataset in hochwertig:
      distributionen = get_dataset_distributions(dataset_id=dataset['id'])
      hat_csv = any(d.get('format', {}).get('id') == 'CSV' and d.get('access_url') for d in distributionen)

      if hat_csv:
        csv_url = next(d['access_url'] for d in distributionen if d.get('format', {}).get('id') == 'CSV')
        try:
          schema = preview_schema(url=csv_url, format="CSV")
          zugaenglich.append({**dataset, 'url': csv_url, 'spalten': len(schema['columns'])})
        except Exception:
          pass

    print(f"{len(zugaenglich)} hochwertige, zugängliche Datensätze gefunden")
    ```
  </Tab>

  <Tab value="Schritt für Schritt">
    <Steps>
      <Step>
        ### Qualitätsbewusste Suche
        Suche mit aktivierter Qualitätsverstärkung:

        ```python
        # Suche mit aktivierter Qualitätsverstärkung
        ergebnisse = search_datasets(
          query="",
          themes=["ECON"],
          formats=["CSV", "JSON"],
          quality_boost=True,
          sort_by="modified_desc",
          limit=20
        )

        print(f"{ergebnisse['count']} Datensätze gefunden")
        ```
      </Step>

      <Step>
        ### Nach Qualitätsmetriken filtern
        Jeden Datensatz auf Qualität analysieren:

        ```python

        for dataset in ergebnisse['results'][:10]:
          dataset_id = dataset['id']

          # Qualitätsanalyse abrufen
          qualitaet = analyze_dataset_quality(dataset_id=dataset_id)

          # Filter: Bewertung > 70 und alle kritischen Komponenten vorhanden
          if qualitaet['score'] > 70:
            kritisch_ok = all([
              qualitaet['components']['has_title'],
              qualitaet['components']['has_description'],
              qualitaet['components']['has_publisher'],
              qualitaet['components']['has_license']
            ])

            if kritisch_ok:
              hochwertige_datensaetze.append({
                'id': dataset_id,
                'titel': dataset.get('title', {}).get('de', 'Kein Titel'),
                'bewertung': qualitaet['score'],
                'geaendert': dataset.get('modified')
              })

        print(f"{len(hochwertige_datensaetze)} hochwertige Datensätze gefunden")
        ```
      </Step>

      <Step>
        ### Datenzugänglichkeit verifizieren
        Sicherstellen, dass Daten tatsächlich zugänglich sind:

        ```python
        # Sicherstellen, dass Daten tatsächlich zugänglich sind
        zugaengliche_datensaetze = []

        for dataset in hochwertige_datensaetze:
          # Distributionen abrufen
          distributionen = get_dataset_distributions(dataset_id=dataset['id'])

          # Auf gültige Download-URLs prüfen
          hat_csv = any(
            d.get('format', {}).get('id') == 'CSV' and d.get('access_url')
            for d in distributionen
          )

          if hat_csv:
            # URL-Zugänglichkeit durch Schema-Prüfung verifizieren
            csv_url = next(
              d['access_url'] for d in distributionen
              if d.get('format', {}).get('id') == 'CSV'
            )

            try:
              schema = preview_schema(url=csv_url, format="CSV")

              zugaengliche_datensaetze.append({
                **dataset,
                'url': csv_url,
                'spalten': len(schema['columns'])
              })

              print(f"✓ {dataset['titel']}")
              print(f"  Bewertung: {dataset['bewertung']}, Spalten: {len(schema['columns'])}")

            except Exception as e:
              print(f"✗ {dataset['titel']} - URL nicht zugänglich")

        print(f"\n{len(zugaengliche_datensaetze)} Datensätze einsatzbereit")
        ```
      </Step>
    </Steps>

## Best Practices

### Fehlerbehandlung

Workflows immer in try-except-Blöcke einbetten:

```python
try:
  ergebnisse = search_datasets(query="Daten", limit=10)
  # Ergebnisse verarbeiten...
except ToolError as e:
  print(f"Fehler: {e}")
  # Elegant behandeln
```

### Paginierung

Für große Ergebnismengen durch Ergebnisse paginieren:

```python
limit = 20
offset = 0
alle_ergebnisse = []

while True:
  seite = search_datasets(
    query="Umwelt",
    limit=limit,
    offset=offset
  )

  alle_ergebnisse.extend(seite['results'])

  # Prüfen, ob weitere Seiten existieren
  if offset + limit >= seite['count']:
    break

  offset += limit

print(f"{len(alle_ergebnisse)} Datensätze insgesamt abgerufen")
```

### Ergebnisse zwischenspeichern

Teure Operationen zwischenspeichern:

```python
# Qualitätsanalyseergebnisse zwischenspeichern
qualitaets_cache = {}

def qualitaet_zwischengespeichert_abrufen(dataset_id):
  if dataset_id not in qualitaets_cache:
    qualitaets_cache[dataset_id] = analyze_dataset_quality(
      dataset_id=dataset_id
    )
  return qualitaets_cache[dataset_id]
```
