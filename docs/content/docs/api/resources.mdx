# MCP Resources

MCP Resources provide direct data access without requiring tool calls. They use a URI-based system for instant data retrieval.

## What are Resources?

Resources are read-only data endpoints that Claude can access directly. Unlike tools (which require function calls), resources are fetched via URIs like `piveau://catalogues` or `piveau://datasets/dataset-123`.

**Benefits:**

- **Faster access** - No tool call overhead
- **Simplified syntax** - Just reference the URI
- **Contextual data** - Ideal for loading reference data into context
- **Efficient** - Claude can cache resource data

## Available Resources

### Catalogues

#### List all catalogues

**URI:** `piveau://catalogues`

**Returns:** Array of all available data catalogues (up to 1000)

**Example usage in Claude:**
```
Load the catalogues resource to see what's available
```

**Response format:**
```json
[
  {
    "id": "stadt-wien",
    "title": "Stadt Wien Open Data",
    "description": "Open data from the City of Vienna"
  },
  {
    "id": "data-gv-at",
    "title": "data.gv.at"
  }
]
```

---

#### Get specific catalogue

**URI:** `piveau://catalogues/{catalogue_id}`

**Parameters:**
- `catalogue_id` - Unique catalogue identifier

**Returns:** Complete metadata for the catalogue

**Example usage:**
```
Show me details from resource piveau://catalogues/stadt-wien
```

**Response format:**
```json
{
  "id": "stadt-wien",
  "title": "Stadt Wien Open Data",
  "description": "Comprehensive open data portal...",
  "publisher": {
    "name": "City of Vienna",
    "type": "Municipality"
  },
  "datasets_count": 500
}
```

---

#### List catalogue datasets

**URI:** `piveau://catalogues/{catalogue_id}/datasets`

**Parameters:**
- `catalogue_id` - Unique catalogue identifier

**Returns:** Array of datasets within the catalogue (up to 100)

**Example usage:**
```
Load datasets from resource piveau://catalogues/stadt-wien/datasets
```

---

### Datasets

#### Get dataset metadata

**URI:** `piveau://datasets/{dataset_id}`

**Parameters:**
- `dataset_id` - Unique dataset identifier

**Returns:** Complete dataset metadata including title, description, publisher, themes, keywords, and more

**Example usage:**
```
Get dataset details from resource piveau://datasets/dataset-123
```

**Response format:**
```json
{
  "id": "dataset-123",
  "title": "Population Statistics 2024",
  "description": "Annual population data for Austrian municipalities",
  "publisher": {...},
  "themes": ["SOCI"],
  "keywords": ["population", "statistics", "demographics"],
  "distributions": [...]
}
```

---

#### Get dataset distributions

**URI:** `piveau://datasets/{dataset_id}/distributions`

**Parameters:**
- `dataset_id` - Unique dataset identifier

**Returns:** Array of downloadable file distributions (up to 100)

**Example usage:**
```
Show me distributions from resource piveau://datasets/dataset-123/distributions
```

**Response format:**
```json
[
  {
    "id": "dist-1",
    "title": "Population CSV",
    "format": "CSV",
    "downloadURL": "https://example.com/population.csv",
    "byteSize": 1048576,
    "mediaType": "text/csv"
  },
  {
    "id": "dist-2",
    "title": "Population JSON",
    "format": "JSON",
    "downloadURL": "https://example.com/population.json",
    "byteSize": 524288,
    "mediaType": "application/json"
  }
]
```

---

#### Get dataset quality metrics

**URI:** `piveau://datasets/{dataset_id}/metrics`

**Parameters:**
- `dataset_id` - Unique dataset identifier

**Returns:** Data Quality Vocabulary (DQV) metrics

**Example usage:**
```
Check quality metrics from resource piveau://datasets/dataset-123/metrics
```

**Response format:**
```json
{
  "completeness": 0.95,
  "accuracy": 0.88,
  "consistency": 0.92,
  "availability": 1.0,
  "overall_score": 0.91
}
```


## Usage Patterns

### Loading Reference Data

Resources are ideal for loading reference data into Claude's context:

```
Load the catalogues resource and the EU themes vocabulary,
then help me find health datasets
```

Claude can use the resource data to:
1. Know which catalogues exist
2. Understand theme codes
3. Make better search recommendations

### Combining Resources with Tools

Use resources to inform tool calls:

```
1. Load resource piveau://catalogues
2. For each catalogue, use search_datasets to find CSV datasets
3. Create a summary table
```

### Efficient Data Access

Resources avoid repeated tool calls:

```
# Instead of calling get_dataset multiple times:
load resources:
  - piveau://datasets/dataset-1
  - piveau://datasets/dataset-2
  - piveau://datasets/dataset-3

Then compare their quality metrics
```

## Resource vs Tool - When to Use Each

### Use Resources When:

- **Loading reference data** - Catalogues, vocabularies
- **Fetching single items** - Specific dataset, catalogue
- **Context building** - Loading multiple items for comparison
- **Static data** - Data that won't change during conversation

### Use Tools When:

- **Searching** - Need filtering, sorting, pagination
- **Complex operations** - Quality analysis, semantic search
- **Write operations** - Creating drafts, publishing
- **Dynamic parameters** - User-specified filters, date ranges

## Best Practices

### 1. Batch Resource Loads

Load multiple resources at once:

```
Load these resources:
  - piveau://catalogues
  - piveau://vocabularies/eu-themes
  - piveau://datasets/dataset-123
```

### 2. Use for Context

Load resources before tool calls for better results:

```
1. Load resource piveau://catalogues
2. Use search_datasets with catalogue_id from step 1
```

### 3. Cache Awareness

Resources are cached by Claude, so repeated access is fast:

```
# First access - fetches data
Load piveau://catalogues

# Later in conversation - uses cache
Reference the catalogues resource again
```

### 4. Combine with Tools

Use resources for data, tools for operations:

```
1. Load piveau://datasets/dataset-123 (resource)
2. Use preview_data on distribution URL (tool)
3. Use analyze_dataset_quality (tool)
```

## Error Handling

Resources may fail if:

- **Invalid URI** - Typo in resource path
- **Non-existent ID** - Dataset or catalogue doesn't exist
- **API unavailable** - Piveau API is down

Claude will report resource errors and suggest alternatives:

```
Resource piveau://datasets/invalid-id not found.
Try using search_datasets to find the correct ID.
```

## Performance Notes

- **Catalogue list:** ~100ms (up to 1000 catalogues)
- **Single dataset:** ~50ms
- **Distributions:** ~100ms (up to 100 files)
- **Vocabularies:** ~200ms (with all terms)

Resources are optimized for fast access with reasonable limits to prevent overwhelming responses.
