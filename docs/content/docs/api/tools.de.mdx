# MCP Tools

Der Austria MCP Server bietet umfassende Tools zum Entdecken, Analysieren und Verwalten von österreichischen Open Data Datensätzen.

## Discovery Tools

### list_catalogues

Listet verfügbare Datenkataloge im österreichischen Open Data Portal auf.

**Parameter:**

| Name | Typ | Erforderlich | Standard | Beschreibung |
|------|-----|--------------|----------|--------------|
| limit | integer | Nein | 100 | Maximale Anzahl zurückzugebender Kataloge (1-5000) |
| offset | integer | Nein | 0 | Anzahl zu überspringender Kataloge für Paginierung |
| value_type | string | Nein | "metadata" | Rückgabeformat: "metadata", "id" oder "uri" |

**Rückgabewert:**

```json
[
  {
    "id": "stadt-wien",
    "title": "Stadt Wien Open Data",
    "description": "Open Data der Stadt Wien"
  }
]
```

**Beispiel:**

```python
# In Claude Desktop
list_catalogues(limit=10)
```

### search_datasets

Sucht nach Datensätzen mit Textabfragen und facettierter Filterung. Unterstützt Volltextsuche mit Fuzzy-Matching, Theme/Format/Publisher-Filtern, Datumsbereichsfilterung und mehreren Sortieroptionen.

**Parameter:**

| Name | Typ | Erforderlich | Standard | Beschreibung |
|------|-----|--------------|----------|--------------|
| query | string | Nein | None | Suchanfrage für Titel, Beschreibungen, Schlagwörter. Unterstützt Fuzzy-Suche (z.B. "gesundheit~"), Wildcards (z.B. "europ*"), Phrasen (z.B. "\"open data\"") und boolesche Operatoren (AND, OR, NOT) |
| themes | string[] | Nein | None | Filtern nach EU-Datenkategorie-Codes: AGRI, ECON, EDUC, ENER, ENVI, GOVE, HEAL, INTR, JUST, REGI, SOCI, TECH, TRAN |
| formats | string[] | Nein | None | Filtern nach Dateiformat (CSV, JSON, XML, PDF, GeoJSON, etc.) |
| publishers | string[] | Nein | None | Filtern nach Herausgeber/Organisations-ID |
| min_date | string | Nein | None | Filtert Datensätze, die nach diesem Datum geändert/veröffentlicht wurden (YYYY-MM-DD oder ISO 8601) |
| max_date | string | Nein | None | Filtert Datensätze, die vor diesem Datum geändert/veröffentlicht wurden (YYYY-MM-DD oder ISO 8601) |
| sort_by | string | Nein | "relevance" | Sortierreihenfolge: relevance, modified_desc, modified_asc, title_asc, title_desc, issued_desc, issued_asc |
| boost_quality | boolean | Nein | false | Bevorzugt hochwertige Datensätze in Suchergebnissen (nutzt Vollständigkeits-, Aktualitäts- und Compliance-Metriken) |
| limit | integer | Nein | 20 | Ergebnisse pro Seite (1-100) |
| page | integer | Nein | 0 | Seitenzahl für Paginierung (0-basiert) |
| catalogue_id | string | Nein | None | Beschränkt Suche auf bestimmten Katalog |

**Erweiterte Suchmuster:**

- **Fuzzy-Matching:** `query="gesundheit~"` findet gesundheit, gesundeit, gesundhet (1 Editierdistanz)
- **Wildcards:** `query="europ*"` findet europe, european, europa
- **Phrasen:** `query='"open data"'` sucht exakte Phrase
- **Boolesche Operatoren:** `query="gesundheit AND (daten OR dataset)"` für explizite Logik
- **Filterlogik:** Mehrere Themes nutzen OR innerhalb der Facette, AND zwischen verschiedenen Facetten

**Rückgabewert:**

```json
{
  "results": [
    {
      "id": "dataset-123",
      "title": "Bevölkerungsstatistik 2024",
      "description": "Jährliche Bevölkerungsdaten...",
      "themes": ["SOCI"],
      "formats": ["CSV", "JSON"]
    }
  ],
  "count": 1234,
  "facets": {
    "categories": {...},
    "format": {...}
  }
}
```

**Beispiel:**

```python
# Einfache Suche
search_datasets(query="bevölkerung", limit=10)

# Erweiterte Filterung
search_datasets(
    query="gesundheit",
    themes=["HEAL", "SOCI"],
    formats=["CSV"],
    min_date="2024-01-01",
    boost_quality=True,
    limit=20
)
```

### find_related_datasets

Findet Datensätze, die mit einem Quelldatensatz verwandt sind, basierend auf gemeinsamen Kategorien und Schlagwörtern. Gibt ähnliche Datensätze mit einem Ähnlichkeitswert (0-100) zurück.

**Parameter:**

| Name | Typ | Erforderlich | Standard | Beschreibung |
|------|-----|--------------|----------|--------------|
| dataset_id | string | Ja | - | Quelldatensatz-ID |
| limit | integer | Nein | 10 | Maximale Anzahl verwandter Datensätze (1-50) |
| min_score | float | Nein | 20.0 | Mindest-Ähnlichkeitswert (0-100) |

**Ähnlichkeitsbewertung:**

- Kategorieübereinstimmungen: 30 Punkte pro gemeinsamer Kategorie (max 60)
- Schlagwortübereinstimmungen: 10 Punkte pro gemeinsamem Schlagwort (max 30)
- Gleicher Herausgeber-Bonus: 15 Punkte
- Gesamtwert auf 100 begrenzt

**Rückgabewert:**

```json
{
  "source": {
    "id": "dataset-123",
    "title": "Bevölkerungsstatistik"
  },
  "related": [
    {
      "dataset": {...},
      "score": 85.0,
      "shared_themes": ["SOCI"],
      "shared_keywords": ["bevölkerung", "statistik"]
    }
  ]
}
```

**Beispiel:**

```python
find_related_datasets(
    dataset_id="dataset-123",
    limit=10,
    min_score=30.0
)
```

### semantic_search_datasets

Sucht nach Datensätzen mit natürlichsprachlichen Abfragen auf Deutsch oder Englisch. Das System nutzt KI, um Ihre Absicht zu verstehen und relevante Datensätze zu finden.

**Parameter:**

| Name | Typ | Erforderlich | Standard | Beschreibung |
|------|-----|--------------|----------|--------------|
| natural_query | string | Ja | - | Natürlichsprachliche Abfrage (z.B. "Gesundheitsdaten aus Wien", "environmental data for research") |
| themes | string[] | Nein | None | Zusätzliche Kategoriefilter (kombiniert mit KI-erkannten Kategorien) |
| formats | string[] | Nein | None | Zusätzliche Formatfilter |
| publishers | string[] | Nein | None | Zusätzliche Herausgeberfilter |
| min_date | string | Nein | None | Filtern nach Änderungs-/Veröffentlichungsdatum (YYYY-MM-DD) |
| max_date | string | Nein | None | Filtern nach Änderungs-/Veröffentlichungsdatum (YYYY-MM-DD) |
| sort_by | string | Nein | "relevance" | Sortierreihenfolge |
| boost_quality | boolean | Nein | true | Bevorzugt hochwertige Datensätze (Standard true für semantische Suche) |
| limit | integer | Nein | 20 | Ergebnisse pro Seite (1-100) |
| page | integer | Nein | 0 | Seitenzahl |

**Funktionsweise:**

1. KI erkennt Sprache (Deutsch/Englisch) mittels linguistischer Heuristiken
2. Erweitert Abfrage in Kategorien, Schlagwörter und Filter
3. Kombiniert mit Ihren expliziten Filtern
4. Gibt Ergebnisse mit Erweiterungsinformationen zurück

**Rückgabewert:**

```json
{
  "results": [...],
  "count": 42,
  "facets": {...},
  "expansion_info": {
    "detected_language": "de",
    "semantic_themes": ["HEAL"],
    "expanded_keywords": ["gesundheit", "medizin"],
    "confidence": "high"
  }
}
```

**Beispiel:**

```python
# Deutsche Abfrage
semantic_search_datasets(
    natural_query="Gesundheitsdaten aus Wien für Forschung"
)

# Englische Abfrage
semantic_search_datasets(
    natural_query="environmental data from Vienna",
    formats=["CSV", "JSON"]
)

# Tourismus-Anwendungsfall
semantic_search_datasets(
    natural_query="Verkehrsinformationen für Touristen",
    limit=15
)
```

## Preview Tools

### preview_schema

Ruft das Schema (Spaltennamen und Typen) eines CSV- oder JSON-Datensatzes ab. Lädt nur den ersten Teil der Datei, um die Struktur effizient abzuleiten.

**Parameter:**

| Name | Typ | Erforderlich | Beschreibung |
|------|-----|--------------|--------------|
| url | string | Ja | Direkte Download-URL (aus get_dataset_distributions) |
| format | string | Nein | Dateiformat: "csv" oder "json" (automatisch erkannt, falls nicht angegeben) |

**Rückgabewert:**

```json
{
  "url": "https://example.com/data.csv",
  "format": "csv",
  "partial_fetch": true,
  "columns": [
    {
      "name": "bevölkerung",
      "type": "integer",
      "sample_values": [100000, 150000, 200000]
    },
    {
      "name": "stadt",
      "type": "string",
      "sample_values": ["Wien", "Graz", "Linz"]
    }
  ]
}
```

**Typerkennung:**

- Leitet Typen aus ersten 10 Beispielzeilen ab
- Unterstützt Ganzzahlen, Fließkommazahlen, Booleans, Daten, Zeichenketten
- CSV: Verarbeitet mehrere Trennzeichen via csv.Sniffer
- JSON: Erkennt verschachtelte Datenarrays

**Beispiel:**

```python
preview_schema(
    url="https://example.com/bevoelkerung.csv",
    format="csv"
)
```

---

### preview_data

Zeigt die ersten Zeilen eines CSV- oder JSON-Datensatzes an. Lädt nur genug Daten, um die angeforderte Anzahl von Zeilen zurückzugeben.

**Parameter:**

| Name | Typ | Erforderlich | Standard | Beschreibung |
|------|-----|--------------|----------|--------------|
| url | string | Ja | - | Direkte Download-URL |
| max_rows | integer | Nein | 20 | Maximale Anzahl zurückzugebender Zeilen (1-100) |
| format | string | Nein | Automatisch | Dateiformat: "csv" oder "json" |

**Rückgabewert:**

```json
{
  "url": "https://example.com/data.csv",
  "format": "csv",
  "partial_fetch": true,
  "rows": [
    {"stadt": "Wien", "bevölkerung": 1900000},
    {"stadt": "Graz", "bevölkerung": 291000}
  ],
  "row_count": 2,
  "estimated_total_rows": 100
}
```

**Abruf-Optimierung:**

- Standard: 64KB Vorschau (ausreichend für ~1000 CSV-Zeilen)
- Maximum: 512KB zur Vermeidung von Speicherproblemen
- Schätzt benötigte Bytes basierend auf Format und max_rows

**Beispiel:**

```python
preview_data(
    url="https://example.com/bevoelkerung.csv",
    max_rows=50
)
```

### get_autocomplete_suggestions

Liefert Autocomplete-Vorschläge für Suchabfragen. Gibt Vokabularbegriffe und gängige Muster zurück, die dem Abfrage-Präfix entsprechen. Nützlich für Search-as-you-type Funktionalität.

**Parameter:**

| Name | Typ | Erforderlich | Standard | Beschreibung |
|------|-----|--------------|----------|--------------|
| query | string | Ja | - | Abfrage-Präfix (mindestens 1 Zeichen) |
| limit | integer | Nein | 10 | Maximale Vorschläge (1-20) |
| language | string | Nein | "de" | Sprachcode (de, en) |

**Vorschlagsquellen:**

1. **EU Datenkategorien** (13 Kategorien): AGRI, ECON, EDUC, ENER, ENVI, GOVE, HEAL, INTR, JUST, REGI, SOCI, TECH, TRAN
2. **Dateiformate**: CSV, JSON, XML, PDF, GeoJSON, RDF, XLSX, ZIP, HTML, TXT
3. **Gängige Begriffe**: open data, statistik, geodaten, verkehr, umwelt, gesundheit, etc.

**Bewertung:**

- Präfix-Übereinstimmungen: 100 Punkte
- Teilstring-Übereinstimmungen: 50 Punkte
- Ergebnisse sortiert nach Punktzahl, dann alphabetisch

**Rückgabewert:**

```json
{
  "suggestions": [
    {
      "text": "Umwelt",
      "category": "theme",
      "code": "ENVI",
      "score": 100
    },
    {
      "text": "umwelt",
      "category": "common",
      "score": 100
    }
  ],
  "count": 2,
  "query": "umw"
}
```

**Beispiel:**

get_autocomplete_suggestions(

)
