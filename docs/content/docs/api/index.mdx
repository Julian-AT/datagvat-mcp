## About the API

The data.gv.at MCP Server provides 25 specialized tools for interacting with Austria's official open data platform. These tools are organized by functionality:

- **Search & Discovery**: Find datasets across Austria's data catalog
- **Data Access**: Preview, download, and analyze dataset contents
- **Metadata & Quality**: Assess data quality and completeness
- **Workflow Support**: Advanced features for research and analysis

For detailed tool specifications, see the [Tools Reference](/docs/api/tools) section.
