Konfiguriere den data.gv.at MCP Server Server für deine Anforderungen.

## Konfigurationsdateien

data.gv.at MCP Server verwendet diese Konfigurationsdateien:

<Files>
  <Folder name="Projektstamm">
    <File name=".env" />
    <File name=".env.example" />
    <Folder name=".mcp">
      <File name="config.json" />
    </Folder>
  </Folder>
  <Folder name="Claude Desktop" defaultOpen>
    <Folder name="AppData/Roaming/Claude">
      <File name="claude_desktop_config.json" />
    </Folder>
  </Folder>
</Files>

**Speicherorte der Konfigurationsdateien:**
- **`.env`** - Projektstamm, Umgebungsvariablen
- **`.mcp/config.json`** - Projektstamm, MCP-Server-Einstellungen
- **`claude_desktop_config.json`** - Claude Desktop Anwendungsverzeichnis

## Umgebungsvariablen

Serververhalten mit Umgebungsvariablen in einer `.env` Datei oder deiner Systemumgebung steuern.

### API-Konfiguration

```bash
# Piveau API Basis-URL
AUSTRIA_MCP_PIVEAU_API_BASE=https://www.data.gv.at/api/hub/search

# Request-Timeout in Sekunden (Standard: 30)
AUSTRIA_MCP_REQUEST_TIMEOUT=30

# Maximale Wiederholungsversuche für fehlgeschlagene Anfragen (Standard: 3)
AUSTRIA_MCP_MAX_RETRIES=3

# Retry Backoff Multiplikator (Standard: 1 Sekunde, exponentiell)
AUSTRIA_MCP_RETRY_BACKOFF=1
```

### Rate Limiting

Der Server enthält eingebautes Rate Limiting zum Schutz der Piveau API:

```bash
# Anfragen pro Sekunde (Standard: 10)
AUSTRIA_MCP_RATE_LIMIT=10

# Burst-Kapazität (Standard: 20)
AUSTRIA_MCP_RATE_BURST=20
```

**Hinweis:** Diese Standardwerte sind konservativ. Du kannst sie erhöhen, wenn du höhere Rate Limits hast oder eine lokale Piveau-Instanz betreibst.

### Logging-Konfiguration

```bash
# Protokollierungsstufe: DEBUG, INFO, WARNING, ERROR, CRITICAL
AUSTRIA_MCP_LOG_LEVEL=INFO

# Protokollformat: json oder text
# json wird für Produktion empfohlen, text für Entwicklung
AUSTRIA_MCP_LOG_FORMAT=json

# Protokolldateipfad (optional, Standard ist stdout)
AUSTRIA_MCP_LOG_FILE=/var/log/datagvat-mcp.log

# Request/Response-Protokollierung aktivieren (Standard: false)
AUSTRIA_MCP_LOG_REQUESTS=false
```

### Entwicklungsmodus

```bash
# Entwicklungsfunktionen aktivieren (Standard: false)
AUSTRIA_MCP_DEV_MODE=true

# Wenn aktiviert:
# - Ausführlichere Fehlermeldungen
# - Request/Response-Debugging
# - Gelockerte Validierung
```

## Claude Desktop Konfiguration

### Mehrere Server-Instanzen

Du kannst mehrere Instanzen mit unterschiedlichen Konfigurationen betreiben:

```json
{
  "mcpServers": {
    "datagvat-produktion": {
      "command": "uv",
      "args": ["--directory", "/pfad/zu/datagvat-mcp", "run", "datagvat-mcp"],
      "env": {
        "AUSTRIA_MCP_LOG_LEVEL": "WARNING",
        "AUSTRIA_MCP_LOG_FORMAT": "json"
      }
    },
    "datagvat-entwicklung": {
      "command": "uv",
      "args": ["--directory", "/pfad/zu/datagvat-mcp-dev", "run", "datagvat-mcp"],
      "env": {
        "AUSTRIA_MCP_DEV_MODE": "true",
        "AUSTRIA_MCP_LOG_LEVEL": "DEBUG"
      }
    }
  }
}
```

### Benutzerdefinierter API-Endpunkt

Falls du eine lokale Piveau-Instanz oder benutzerdefinierte API betreibst:

```json
{
  "mcpServers": {
    "datagvat-lokale-api": {
      "command": "uv",
      "args": ["--directory", "/pfad/zu/datagvat-mcp", "run", "datagvat-mcp"],
      "env": {
        "AUSTRIA_MCP_PIVEAU_API_BASE": "http://localhost:8080/api/hub/search",
        "AUSTRIA_MCP_REQUEST_TIMEOUT": "60"
      }
    }
  }
}
```

## Performance-Optimierung

### Request-Timeout

Passe basierend auf deinen Netzwerkbedingungen an:

```bash
# Schnelles Netzwerk
AUSTRIA_MCP_REQUEST_TIMEOUT=10

# Langsames Netzwerk oder große Datensätze
AUSTRIA_MCP_REQUEST_TIMEOUT=60

# Sehr langsames Netzwerk
AUSTRIA_MCP_REQUEST_TIMEOUT=120
```

### Datenvorschau-Limits

Konfiguriere das Datenvorschau-Verhalten (im Code festgelegt, nicht als Umgebungsvariablen - dies dient als Referenz):

- **Standard-Vorschau:** 64KB (geeignet für ~1000 CSV-Zeilen)
- **Maximale Vorschau:** 512KB (verhindert Speicherprobleme)
- **Zeilenlimit:** Maximal 100 Zeilen pro Vorschau

Zum Ändern bearbeiten Sie `app/preview.py`:

```python
DEFAULT_PREVIEW_BYTES = 65536  # 64KB
MAX_PREVIEW_BYTES = 524288     # 512KB
MAX_PREVIEW_ROWS = 100
```

### Suchergebnis-Limits

Der Server erzwingt Limits, um überwältigende Antworten zu verhindern:

- **Standard-Limit:** 20 Datensätze pro Seite
- **Maximales Limit:** 100 Datensätze pro Seite
- **Paginierung:** Verwenden Sie den `page`-Parameter für zusätzliche Ergebnisse

## Sicherheit

### API-Schlüssel-Verwaltung (Zukünftig)

Wenn API-Schlüssel für Schreiboperationen erforderlich sind:

```bash
# Piveau API-Schlüssel für Datensatzverwaltung
AUSTRIA_MCP_API_KEY=ihr-api-schluessel-hier

# Committen Sie niemals API-Schlüssel in die Versionskontrolle
# Verwenden Sie .env-Dateien (von Git ausgeschlossen)
```

### Netzwerksicherheit

HTTPS-Einstellungen konfigurieren:

```bash
# SSL-Zertifikate verifizieren (Standard: true)
AUSTRIA_MCP_VERIFY_SSL=true

# In der Entwicklung können Sie SSL-Verifizierung deaktivieren
# WARNUNG: Nur in vertrauenswürdigen Entwicklungsumgebungen verwenden
AUSTRIA_MCP_VERIFY_SSL=false
```

## Überwachung

### Health Checks

Der Server bietet Health-Check-Endpunkte (wenn als Service ausgeführt):

```bash
# Server-Gesundheit prüfen
curl http://localhost:8080/health

# Antwort:
{
  "status": "healthy",
  "version": "1.0.0",
  "api_reachable": true
}
```

### Metriken

Metriksammlung aktivieren:

```bash
# Prometheus-Metriken aktivieren (Standard: false)
AUSTRIA_MCP_METRICS_ENABLED=true

# Metriken-Endpunkt-Port
AUSTRIA_MCP_METRICS_PORT=9090
```

Greifen Sie auf Metriken unter `http://localhost:9090/metrics` zu.

## Fehlerbehebung bei der Konfiguration

### Konfiguration nicht angewendet

1. **Überprüfe die Rangfolge der Umgebungsvariablen:**
   - System-Umgebungsvariablen
   - `.env`-Datei im Projektstamm
   - Claude Desktop Config `env`-Sektion
   - Standardwerte

2. **Überprüfe den Speicherort der .env-Datei:**
   ```bash
   # Sollte im Projektstamm sein
   ls -la /pfad/zu/datagvat-mcp/.env
   ```

3. **Prüfe auf Tippfehler:**
   ```bash
   # Variablennamen sind groß-/kleinschreibungssensitiv
   AUSTRIA_MCP_LOG_LEVEL=INFO  # Richtig
   austria_mcp_log_level=INFO  # Falsch
   ```

### Konfiguration debuggen

Aktiviere Debug-Logging, um geladene Konfiguration zu sehen:

```bash
AUSTRIA_MCP_LOG_LEVEL=DEBUG
AUSTRIA_MCP_DEV_MODE=true
```

Prüfe Logs auf Konfigurationswerte:

```
2024-01-17 10:00:00 DEBUG Geladene Konfiguration:
  PIVEAU_API_BASE: https://www.data.gv.at/api/hub/search
  REQUEST_TIMEOUT: 30
  LOG_LEVEL: DEBUG
  RATE_LIMIT: 10/s
```

## Konfigurationsvalidierung

Der Server validiert die Konfiguration beim Start:

```python
# Beispiel-Validierungsfehler
ConfigError: AUSTRIA_MCP_REQUEST_TIMEOUT muss positive Ganzzahl sein
ConfigError: AUSTRIA_MCP_LOG_LEVEL muss einer sein von: DEBUG, INFO, WARNING, ERROR, CRITICAL
ConfigError: AUSTRIA_MCP_PIVEAU_API_BASE muss gültige URL sein
```
