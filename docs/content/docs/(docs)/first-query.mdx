Once you've [installed the MCP server](/docs/installation), you're ready to start exploring Austria's 10,000+ open datasets.

## Search for Datasets

Ask your AI assistant in natural language:

<TryExample query="Find datasets about Vienna population" />


The MCP server searches data.gv.at and returns matching datasets with:

- **Title and description** in German (the source language)
- **Publisher** — which government agency provides the data
- **Formats** — CSV, JSON, XML, or other available downloads
- **Quality score** — 0-100 rating based on metadata completeness

Results are ranked by relevance and quality, so the best datasets appear first.

## Get Dataset Details

Once you find an interesting dataset, ask for more information:

```
Tell me more about [dataset title]
```

You'll get the full metadata: license terms, temporal coverage, spatial extent, update frequency, and all available download formats.

## Preview the Data

Before downloading a large file, preview its contents:

```
Preview the CSV from [dataset title]
```

The MCP server fetches the first rows and shows you:

- Column names and inferred types
- Sample values from each column
- Total row count estimate

This helps you verify the data structure matches your needs without downloading the entire file.

## Example Conversation

Here's a realistic session exploring energy data:

<Callout type="info">
**You:** Find datasets about renewable energy in Austria

**Assistant:** I found 23 datasets related to renewable energy. The top results are:

1. **Stromerzeugung aus erneuerbaren Energien** (Statistik Austria) — Monthly electricity production from solar, wind, hydro, and biomass. Quality: 92/100. Formats: CSV, JSON.

2. **Photovoltaik-Anlagen Österreich** (E-Control) — Registry of solar installations by federal state. Quality: 87/100. Format: CSV.

3. **Windkraftanlagen Standorte** (BMNT) — Wind turbine locations with capacity data. Quality: 78/100. Formats: GeoJSON, CSV.

**You:** Preview the first one

**Assistant:** Here's a preview of "Stromerzeugung aus erneuerbaren Energien":

| Jahr | Monat | Quelle | Erzeugung_GWh |
|------|-------|--------|---------------|
| 2024 | 1 | Solar | 142.3 |
| 2024 | 1 | Wind | 891.2 |
| 2024 | 1 | Wasserkraft | 2341.8 |

The dataset has 4 columns and approximately 2,400 rows covering 2015-2024.

**You:** What license is it under?

**Assistant:** This dataset uses CC BY 4.0 (Creative Commons Attribution), so you can use it freely for any purpose as long as you credit Statistik Austria.
</Callout>

## What You Can Ask

The MCP server supports these types of queries:

| Query Type | Example |
|------------|---------|
| Search | "Find datasets about X" |
| Details | "Tell me more about [dataset]" |
| Preview | "Preview the CSV/JSON from [dataset]" |
| Quality | "What's the quality score of [dataset]?" |
| Formats | "What formats are available for [dataset]?" |
| Related | "Find datasets similar to [dataset]" |
| Compare | "Compare [dataset A] with [dataset B]" |
