## Quick Install

```bash
uvx datagvat-mcp init
```

This single command:
- Detects your installed AI tools (Claude Desktop, Continue, Cline)
- Configures each tool automatically
- Verifies the setup works

<Callout type="info">
**No Python setup required.** The `uvx` command handles everything—virtual environments, dependencies, paths. Just run and go.
</Callout>

## Prerequisites

You need [uv](https://docs.astral.sh/uv/) installed:

<Tabs items={['macOS/Linux', 'Windows']} groupId="os" persist>

  <Tab value="Windows">

## Update Configuration

After updating the MCP server, refresh your tool configurations:

```bash
uvx datagvat-mcp update
```

## Commands Reference

| Command | Description |
|---------|-------------|
| `uvx datagvat-mcp` | Run the MCP server (used by AI tools internally) |
| `uvx datagvat-mcp init` | Install and configure AI tools |
| `uvx datagvat-mcp init -y` | Install without prompts |
| `uvx datagvat-mcp doctor` | Verify installation health |
| `uvx datagvat-mcp update` | Update tool configurations |
| `uvx datagvat-mcp --version` | Show version |

## Environment Variables

Optional configuration via environment variables (prefix `AUSTRIA_MCP_`):

| Variable | Default | Description |
|----------|---------|-------------|
| `PIVEAU_API_BASE` | `https://data.gv.at/katalog/api/hub/repo` | API base URL |
| `REQUEST_TIMEOUT` | `30` | HTTP timeout in seconds |
| `LOG_LEVEL` | `INFO` | Logging level (DEBUG, INFO, WARNING, ERROR) |

Set these in your shell profile or `.env` file if needed. Most users don't need to change anything.

## Supported AI Tools

The installer auto-detects and configures:

| Tool | Platform | Status |
|------|----------|--------|
| [Claude Desktop](https://claude.ai/download) | macOS, Windows, Linux | Full support |
| [Continue](https://continue.dev) | VS Code, JetBrains | Full support |
| [Cline](https://github.com/cline/cline) | VS Code | Full support |

Other MCP-compatible clients can be configured manually—see [Other Clients](/docs/integration/other-clients).

## Troubleshooting

### "uvx: command not found"

Install uv first:

```bash
# macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Then restart your terminal.

### "No AI tools detected"

The installer looks for config files in standard locations. If your tools are installed elsewhere:

1. Run `uvx datagvat-mcp doctor` to see what's detected
2. Check [Other Clients](/docs/integration/other-clients) for manual configuration

### Server not appearing in Claude Desktop

1. Make sure you've restarted Claude Desktop completely (Cmd+Q / right-click tray → Exit)
2. Run `uvx datagvat-mcp doctor` to verify configuration
3. Check Claude Desktop logs for errors:
   - macOS: `~/Library/Logs/Claude/`
   - Windows: `%APPDATA%\Claude\logs\`
   - Linux: `~/.config/Claude/logs/`

### Connection errors

Test API access directly:

```bash
curl https://www.data.gv.at/api/hub/search/catalogues
```

If this fails, check your network/firewall settings.

## Manual Installation

If you prefer manual setup or need a custom configuration:

<Tabs items={['Claude Desktop', 'Continue', 'Cline']} persist>
  <Tab value="Claude Desktop">
    Edit your Claude Desktop config:

    **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
    **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
    **Linux:** `~/.config/Claude/claude_desktop_config.json`

    ```json
    {
      "mcpServers": {
        "datagvat": {
          "command": "uvx",
          "args": ["datagvat-mcp"]
        }
      }
    }
    ```
  </Tab>

  <Tab value="Continue">
    Edit `~/.continue/config.json`:

    ```json
    {
      "experimental": {
        "modelContextProtocolServers": [
          {
            "transport": {
              "type": "stdio",
              "command": "uvx",
              "args": ["datagvat-mcp"]
            }
          }
        ]
      }
    }
    ```
  </Tab>

  <Tab value="Cline">
    In VS Code settings (`settings.json`):

    ```json
    {
      "cline.mcpServers": {
        "datagvat": {
          "command": "uvx",
          "args": ["datagvat-mcp"]
        }
      }
    }
    ```
  </Tab>
</Tabs>
