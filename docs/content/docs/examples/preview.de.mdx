# Vorschau-Beispiele

Lernen Sie, wie Sie Datensatzinhalte vor dem Herunterladen überprüfen.

## Schema-Inspektion

<Tabs items={['Schnellprüfung', 'Detaillierte Inspektion']} persist groupId="preview-complexity">
  <Tab value="Schnellprüfung">
    Überprüfen Sie die Struktur eines Datensatzes, ohne Daten herunterzuladen:

    ```python
    # CSV-Schema-Vorschau
    preview_schema(
      url="https://www.data.gv.at/katalog/dataset/beispiel.csv",
      format="CSV"
    )
    ```

    **Gibt zurück:**
    - Spaltennamen
    - Abgeleitete Datentypen (string, integer, float, boolean, date)
    - Typableitung basierend auf 10 Beispielzeilen

    **Unterstützte Formate:** CSV, JSON
  </Tab>

  <Tab value="Detaillierte Inspektion">
    Umfassende Schemaanalyse mit Validierung:

    ```python
    # Schema zuerst abrufen
    schema = preview_schema(
      url="https://www.data.gv.at/katalog/dataset/beispiel.csv",
      format="CSV"
    )

    # Struktur validieren
    print(f"{len(schema['columns'])} Spalten gefunden")

    for column in schema['columns']:
      print(f"  - {column['name']}: {column['type']}")

    # Auf erwartete Spalten prüfen
    erwartete_spalten = ["id", "name", "wert"]
    tatsaechliche_spalten = [c['name'] for c in schema['columns']]

    if all(col in tatsaechliche_spalten for col in erwartete_spalten):
      print("✓ Schema validiert - mit Datenvorschau fortfahren")
    else:
      fehlend = set(erwartete_spalten) - set(tatsaechliche_spalten)
      print(f"✗ Fehlende Spalten: {fehlend}")
    ```

    **Erweiterte Validierung:**
    - Spaltenvorhandensein überprüfen
    - Datentypen mit Erwartungen abgleichen
    - Potenzielle Datenqualitätsprobleme identifizieren
  </Tab>
</Tabs>

## Datenvorschau

<Tabs items={['Schnelle Stichprobe', 'Detaillierte Vorschau']} persist groupId="preview-complexity">
  <Tab value="Schnelle Stichprobe">
    Beispielzeilen aus einem Datensatz anzeigen:

    ```python
    # Vorschau der ersten 20 Zeilen
    preview_data(
      url="https://www.data.gv.at/katalog/dataset/beispiel.csv",
      max_rows=20,
      format="CSV"
    )
    ```

    **Konfiguration:**
    - `max_rows` - Anzahl der Vorschauzeilen (Standard: 100, Maximum: 1000)
    - `format` - Dateiformat (CSV oder JSON, automatisch aus URL erkannt, falls nicht angegeben)

    **Gibt zurück:**
    - Beispieldatenzeilen
    - Spaltennamen und Typen
    - Anzahl der Zeilen in der Vorschau
    - Geschätzte Gesamtzeilen (falls abgeschnitten)
  </Tab>

  <Tab value="Detaillierte Vorschau">
    Vollständiger Dateninspektion-Workflow:

    ```python
    # Detaillierte Vorschau abrufen
    vorschau = preview_data(
      url="https://www.data.gv.at/katalog/dataset/beispiel.csv",
      max_rows=100,
      format="CSV"
    )

    # Vorschauergebnisse analysieren
    print(f"Vorschau enthält {vorschau['row_count']} Zeilen")

    if 'estimated_total_rows' in vorschau:
      print(f"Geschätzte Gesamtzahl: {vorschau['estimated_total_rows']} Zeilen")
      print(f"Datei ist abgeschnitten - zeige Stichprobe")

    # Datenqualität untersuchen
    for i, row in enumerate(vorschau['data'][:10], 1):
      print(f"Zeile {i}: {row}")

    # Auf Null-Werte prüfen
    for row in vorschau['data']:
      null_felder = [k for k, v in row.items() if v is None or v == '']
      if null_felder:
        print(f"Warnung: Null-Werte in {null_felder}")
    ```

    **Datenqualitätsprüfungen:**
    - Erkennung von Null-Werten
    - Format-Konsistenz
    - Datenbereichsvalidierung
    - Kodierungsüberprüfung
  </Tab>
</Tabs>

## CSV-Verarbeitung

### Verschiedene Trennzeichen

<Tabs items={['Auto-Erkennung', 'Manuelle Behandlung']} persist groupId="preview-complexity">
  <Tab value="Auto-Erkennung">
    Das Vorschau-Tool erkennt CSV-Trennzeichen automatisch:

    ```python
    # Komma-getrennt (automatisch erkannt)
    preview_data(
      url="https://example.com/daten.csv",
      format="CSV"
    )

    # Semikolon-getrennt (automatisch erkannt, üblich in europäischen Datensätzen)
    preview_data(
      url="https://example.com/europaeische-daten.csv",
      format="CSV"
    )

    # Tabulator-getrennt (automatisch erkannt)
    preview_data(
      url="https://example.com/daten.tsv",
      format="CSV"
    )
    ```

    Verwendet Pythons `csv.Sniffer` zur automatischen Trennzeichenerkennung.
  </Tab>

  <Tab value="Manuelle Behandlung">
    Trennzeichenerkennung überprüfen und Sonderfälle behandeln:

    ```python
    # Vorschau mit Trennzeichenerkennung
    vorschau = preview_data(
      url="https://example.com/daten.csv",
      format="CSV"
    )

    # Überprüfen, ob Struktur korrekt aussieht
    if len(vorschau['data']) > 0:
      erste_zeile = vorschau['data'][0]
      anzahl_spalten = len(erste_zeile.keys())

      print(f"{anzahl_spalten} Spalten erkannt")

      # Prüfen, ob Spalten vernünftig erscheinen
      if anzahl_spalten < 2:
        print("⚠ Warnung: Nur eine Spalte erkannt")
        print("   Trennzeichen möglicherweise nicht korrekt erkannt")
      else:
        print("✓ Trennzeichenerkennung erfolgreich")

    # Für problematische Dateien Rohdaten prüfen
    # (Würde direkten HTTP-Download für manuelle Analyse benötigen)
    ```

    **Häufige Trennzeichenprobleme:**
    - Gemischte Trennzeichen in Datei
    - Trennzeichen innerhalb quotierter Werte
    - Nicht-standardmäßige Trennzeichen (Pipe, etc.)
  </Tab>
</Tabs>

### Große CSV-Dateien

<Tabs items={['Effiziente Vorschau', 'Leistungsoptimierung']} persist groupId="preview-complexity">
  <Tab value="Effiziente Vorschau">
    Vorschau verarbeitet große Dateien effizient:

    ```python
    # Standard: 64KB Vorschau (ausreichend für ~1000 Zeilen)
    preview_data(
      url="https://example.com/grosser-datensatz.csv",
      max_rows=100,
      format="CSV"
    )
    ```

    **Leistungsmerkmale:**
    - Standard-Chunk-Größe: 64KB
    - Maximale Chunk-Größe: 512KB
    - Lädt nur das Notwendige für die Vorschau herunter
    - Geschätzte Gesamtzeilen aus Stichprobe berechnet
  </Tab>

  <Tab value="Leistungsoptimierung">
    Vorschau für verschiedene Dateigrößen optimieren:

    ```python
    # Kleine Vorschau für schnelle Prüfung (20 Zeilen)
    schnell_vorschau = preview_data(
      url="https://example.com/grosser-datensatz.csv",
      max_rows=20,
      format="CSV"
    )

    # Mittlere Vorschau für Validierung (100 Zeilen)
    mittel_vorschau = preview_data(
      url="https://example.com/grosser-datensatz.csv",
      max_rows=100,
      format="CSV"
    )

    # Maximale Vorschau für umfassende Analyse (1000 Zeilen)
    volle_vorschau = preview_data(
      url="https://example.com/grosser-datensatz.csv",
      max_rows=1000,
      format="CSV"
    )

    # Geschätzte Gesamtzahl zur Stichprobenberechnung verwenden
    if 'estimated_total_rows' in schnell_vorschau:
      gesamt = schnell_vorschau['estimated_total_rows']
      stichproben_prozent = (20 / gesamt) * 100
      print(f"Vorschau von {stichproben_prozent:.2f}% der Daten")
    ```

    **Optimierungsstrategie:**
    - 20 Zeilen für schnelle Strukturprüfung verwenden
    - 100 Zeilen für Datenqualitätsvalidierung verwenden
    - 1000 Zeilen für statistische Stichproben verwenden
    - estimated_total_rows prüfen, um Abdeckung zu verstehen
  </Tab>
</Tabs>

## JSON-Verarbeitung

### Flache JSON-Arrays

<Tabs items={['Einfache Vorschau', 'Array-Analyse']} persist groupId="preview-complexity">
  <Tab value="Einfache Vorschau">
    JSON-Arrays direkt in der Vorschau anzeigen:

    ```python
    preview_data(
      url="https://example.com/daten.json",
      format="JSON"
    )
    ```

    **Beispiel-Eingabe:**
    ```json
    [
      {"id": 1, "name": "Wien", "population": 1900000},
      {"id": 2, "name": "Graz", "population": 290000}
    ]
    ```
  </Tab>

  <Tab value="Array-Analyse">
    JSON-Struktur und Daten analysieren:

    ```python
    # Vorschau abrufen
    vorschau = preview_data(
      url="https://example.com/daten.json",
      format="JSON"
    )

    # Array-Struktur analysieren
    if vorschau['data']:
      erstes_obj = vorschau['data'][0]
      felder = erstes_obj.keys()

      print(f"JSON-Objekte haben {len(felder)} Felder:")
      for feld in felder:
        print(f"  - {feld}")

      # Feld-Konsistenz über Objekte prüfen
      inkonsistent = []
      for i, obj in enumerate(vorschau['data']):
        if set(obj.keys()) != set(felder):
          inkonsistent.append(i)

      if inkonsistent:
        print(f"⚠ Objekte mit unterschiedlichen Feldern: {inkonsistent}")
      else:
        print("✓ Konsistente Struktur über alle Objekte")
    ```
  </Tab>
</Tabs>

    vorschau = preview_data(

    # Prüfen, was extrahiert wurde
    if vorschau['data']:

      erstes_element = vorschau['data'][0]

    # Für nicht-standardmäßige Strukturen möglicherweise erforderlich:
    # 1. Vollständiges JSON herunterladen
    # 2. Manuell zu Datenarray navigieren
    # 3. Nach Bedarf verarbeiten

### Wiederherstellung abgeschnittener JSON

<Tabs items={['Automatische Wiederherstellung', 'Wiederherstellungsanalyse']} persist groupId="preview-complexity">
  <Tab value="Automatische Wiederherstellung">
    Falls JSON abgeschnitten ist, versucht das Tool eine Wiederherstellung:

    ```python
    # Verarbeitet teilweise heruntergeladenes JSON
    preview_data(
      url="https://example.com/grosse-daten.json",
      max_rows=50,
      format="JSON"
    )
    ```

    Wiederherstellungsstrategie:
    1. Letztes vollständiges Objekt in abgeschnittenen Daten finden
    2. Erfolgreich abgeschlossene Objekte parsen
    3. Teilweise, aber gültige Ergebnisse zurückgeben
  </Tab>

  <Tab value="Wiederherstellungsanalyse">
    Wiederherstellungsergebnisse verstehen und überprüfen:

    ```python
    # Potenziell abgeschnittenes JSON in Vorschau anzeigen
    vorschau = preview_data(
      url="https://example.com/grosse-daten.json",
      max_rows=100,
      format="JSON"
    )

    # Prüfen, ob Abschneidung aufgetreten ist
    if 'estimated_total_rows' in vorschau:
      angefordert = 100
      erhalten = vorschau['row_count']

      if erhalten < angefordert:
        print(f"⚠ Abschneidung erkannt:")
        print(f"   Angefordert: {angefordert} Zeilen")
        print(f"   Erhalten: {erhalten} Zeilen")
        print(f"   Geschätzte Gesamtzahl: {vorschau['estimated_total_rows']}")

        # Vollständigkeit berechnen
        vollstaendigkeit = (erhalten / angefordert) * 100
        print(f"   Vorschau-Vollständigkeit: {vollstaendigkeit:.1f}%")
      else:
        print("✓ Vollständige Vorschau abgerufen")

    # Wiederhergestellte Daten auf Gültigkeit überprüfen
    if vorschau['data']:
      for i, obj in enumerate(vorschau['data']):
        if not isinstance(obj, dict):
          print(f"⚠ Warnung: Objekt {i} ist kein gültiges dict")
    ```
  </Tab>
</Tabs>

## Fehlerbehandlung

<Tabs items={['Grundlegende Fehler', 'Erweiterte Fehlerbehandlung']} persist groupId="preview-complexity">
  <Tab value="Grundlegende Fehler">
    Häufige Vorschaufehler behandeln:

    ```python
    # Ungültige URL
    try:
      preview_data(url="keine-gueltige-url", format="CSV")
    except ToolError as e:
      print(f"Fehler: {e}")

    # Nicht unterstütztes Format
    try:
      preview_data(
        url="https://example.com/daten.pdf",
        format="PDF"
      )
    except ToolError as e:
      print(f"Fehler: {e}")  # "Nicht unterstütztes Format: PDF"

    # Netzwerkprobleme
    try:
      preview_data(
        url="https://example.com/nichtexistent.csv",
        format="CSV"
      )
    except ToolError as e:
      print(f"Fehler: {e}")  # Verbindungsfehler mit Anleitung
    ```
  </Tab>

  <Tab value="Erweiterte Fehlerbehandlung">
    Umfassende Fehlerbehandlung und Wiederherstellung:

    ```python
    def sichere_vorschau(url, max_rows=20, format=None):
      """Vorschau mit umfassender Fehlerbehandlung."""
      try:
        # Vorschau versuchen
        vorschau = preview_data(
          url=url,
          max_rows=max_rows,
          format=format
        )

        # Überprüfen, ob Daten erhalten wurden
        if not vorschau.get('data'):
          return {
            'erfolg': False,
            'fehler': 'Keine Daten zurückgegeben',
            'vorschlag': 'URL könnte leer sein oder ungültiges Format haben'
          }

        # Datenqualität prüfen
        if vorschau['row_count'] == 0:
          return {
            'erfolg': False,
            'fehler': 'Leerer Datensatz',
            'vorschlag': 'Datei enthält keine Datenzeilen'
          }

        return {
          'erfolg': True,
          'vorschau': vorschau,
          'zeilen': vorschau['row_count']
        }

      except ToolError as e:
        fehler_text = str(e).lower()

        # Fehler kategorisieren
        if 'unsupported format' in fehler_text or 'nicht unterstützt' in fehler_text:
          return {
            'erfolg': False,
            'fehler': 'Nicht unterstütztes Format',
            'vorschlag': 'Nur CSV und JSON werden unterstützt'
          }
        elif 'invalid url' in fehler_text or 'ungültig' in fehler_text:
          return {
            'erfolg': False,
            'fehler': 'Ungültige URL',
            'vorschlag': 'URL muss mit http:// oder https:// beginnen'
          }
        elif 'connection' in fehler_text or 'verbindung' in fehler_text or 'network' in fehler_text:
          return {
            'erfolg': False,
            'fehler': 'Netzwerkfehler',
            'vorschlag': 'URL-Zugänglichkeit und Netzwerkverbindung prüfen'
          }
        else:
          return {
            'erfolg': False,
            'fehler': str(e),
            'vorschlag': 'Siehe Fehlermeldung für Details'
          }

    # Verwendung
    ergebnis = sichere_vorschau(url="https://example.com/daten.csv")

    if ergebnis['erfolg']:
      print(f"✓ Vorschau erfolgreich: {ergebnis['zeilen']} Zeilen")
    else:
      print(f"✗ Vorschau fehlgeschlagen: {ergebnis['fehler']}")
      print(f"   Vorschlag: {ergebnis['vorschlag']}")
    ```
  </Tab>
</Tabs>

## Best Practices

### 1. Vorschau vor Download

<Tabs items={['Schnelle Validierung', 'Umfassende Validierung']} persist groupId="preview-complexity">
  <Tab value="Schnelle Validierung">
    Zeigen Sie immer Schema und Beispieldaten vor dem Herunterladen großer Dateien an:

    ```python
    # Schema zuerst prüfen
    schema = preview_schema(url=download_url, format="CSV")

    # Struktur überprüfen
    if "erwartete_spalte" in [c["name"] for c in schema["columns"]]:
      # Struktur sieht gut aus, Beispieldaten abrufen
      preview_data(url=download_url, max_rows=20)
    ```
  </Tab>

  <Tab value="Umfassende Validierung">
    Vollständige Validierung vor Download-Verpflichtung:

    ```python
    def validieren_vor_download(url, erwartete_spalten, format="CSV"):
      """Umfassende Pre-Download-Validierung."""

      # Schritt 1: Schema-Validierung
      schema = preview_schema(url=url, format=format)
      tatsaechliche_spalten = [c['name'] for c in schema['columns']]

      fehlend = set(erwartete_spalten) - set(tatsaechliche_spalten)
      if fehlend:
        return {
          'gueltig': False,
          'grund': f'Fehlende Spalten: {fehlend}'
        }

      # Schritt 2: Datentyp-Validierung
      for col in schema['columns']:
        if col['name'] in erwartete_spalten:
          # Typ auf Angemessenheit prüfen
          if col['type'] == 'string' and col['name'].endswith('_id'):
            print(f"⚠ Warnung: {col['name']} ist string, Zahl erwartet?")

      # Schritt 3: Datenqualitätsprüfung
      vorschau = preview_data(url=url, max_rows=100, format=format)

      if vorschau['row_count'] == 0:
        return {
          'gueltig': False,
          'grund': 'Keine Datenzeilen'
        }

      # Null-Prozentsatz prüfen
      gesamt_zellen = vorschau['row_count'] * len(schema['columns'])
      null_zellen = sum(
        1 for row in vorschau['data']
        for value in row.values()
        if value is None or value == ''
      )
      null_prozent = (null_zellen / gesamt_zellen) * 100

      return {
        'gueltig': True,
        'schema': schema,
        'beispiel_zeilen': vorschau['row_count'],
        'null_prozentsatz': null_prozent,
        'download_empfohlen': null_prozent < 10
      }

    # Verwendung
    ergebnis = validieren_vor_download(
      url=download_url,
      erwartete_spalten=["id", "name", "wert"]
    )

    if ergebnis['gueltig'] and ergebnis['download_empfohlen']:
      print("✓ Validierung bestanden - sicher zum Herunterladen")
    ```

</Tabs>

## Leistungstipps

**Downloads minimieren:**
- Verwenden Sie `preview_schema` nur für Strukturprüfungen (schneller)
- Verwenden Sie kleine `max_rows` für schnelle Verifizierung
- Vorschau nur bei Bedarf verwenden

**Geschätzte Download-Größen:**
- CSV: ~500 Bytes pro Zeile (variiert je nach Spalten)
- JSON: ~200 Bytes pro Objekt (variiert je nach Struktur)
- Standard 64KB-Chunk: ~128 CSV-Zeilen oder ~320 JSON-Objekte
