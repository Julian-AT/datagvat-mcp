# Search Examples

Master dataset discovery with these practical search examples.

## Basic Text Search

<Tabs items={['Basic', 'Advanced']} persist groupId="search-complexity">
  <Tab value="Basic">
    Simple keyword search across all datasets:

    ```python
    # Search for population-related datasets
    search_datasets(query="population", limit=10)

    # Search for environmental data
    search_datasets(query="environment", limit=10)

    # Search for traffic data
    search_datasets(query="traffic", limit=10)
    ```

    **Tips:**
    - Use German keywords for better results (most datasets are in German)
    - The API searches titles, descriptions, and keywords
    - Relevance-based ranking is applied automatically
  </Tab>

  <Tab value="Advanced">
    Advanced search with fuzzy matching and wildcards:

    ```python
    # Fuzzy search (finds similar terms)
    search_datasets(query="health~", limit=10)

    # Wildcard search
    search_datasets(query="data*", limit=10)

    # Phrase search with exact matching
    search_datasets(query='"air quality"', limit=10)

    # Boost specific terms
    search_datasets(query="environment^2 climate", limit=10)
    ```

    **Advanced features:**
    - `~` suffix enables fuzzy matching
    - `*` matches zero or more characters
    - `"..."` requires exact phrase
    - `^N` boosts term importance
  </Tab>
</Tabs>

## Filtered Search

### By Category

<Tabs items={['Single Category', 'Multiple Categories']} persist groupId="search-complexity">
  <Tab value="Single Category">
    Filter by a single EU DCAT-AP theme:

    ```python
    # Health datasets only
    search_datasets(
      query="statistics",
      themes=["HEAL"],
      limit=10
    )

    # Environment datasets
    search_datasets(
      query="climate",
      themes=["ENVI"],
      limit=10
    )

    # Population and society data
    search_datasets(
      query="demographics",
      themes=["SOCI"],
      limit=10
    )
    ```
  </Tab>

  <Tab value="Multiple Categories">
    Combine multiple themes (OR logic):

    ```python
    # Environment OR Energy datasets
    search_datasets(
      query="climate",
      themes=["ENVI", "ENER"],
      limit=10
    )

    # Health OR Social datasets
    search_datasets(
      query="statistics",
      themes=["HEAL", "SOCI"],
      limit=10
    )

    # Government OR Justice datasets
    search_datasets(
      query="public",
      themes=["GOVE", "JUST"],
      limit=10
    )
    ```
  </Tab>
</Tabs>

**All 13 EU theme codes:**
- `AGRI` - Agriculture, fisheries, forestry and food
- `ECON` - Economy and finance
- `EDUC` - Education, culture and sport
- `ENER` - Energy
- `ENVI` - Environment
- `GOVE` - Government and public sector
- `HEAL` - Health
- `INTR` - International issues
- `JUST` - Justice, legal system and public safety
- `REGI` - Regions and cities
- `SOCI` - Population and society
- `TECH` - Science and technology
- `TRAN` - Transport

## Date Range Filtering

<Tabs items={['Simple Date Filters', 'Complex Date Filters']} persist groupId="search-complexity">

    ```python

    search_datasets(

      modified_since="2024-01-01",
      modified_until="2024-12-31",
      limit=10
    )

    # Recently updated datasets (last 30 days)
    search_datasets(
      query="",
      modified_since="2024-12-15",
      limit=10
    )

    # Datasets published before 2020
    search_datasets(
      query="",
      issued_until="2020-01-01",
      limit=10
    )
    ```

    **Date format:** ISO 8601 (YYYY-MM-DD)
  </Tab>

  <Tab value="Complex Date Filters">
    Combine date filters with other criteria:

    ```python

      issued_until="2023-12-31",

      limit=10
    ```

## Sorting Options

<Tabs items={['Basic Sorting', 'Advanced Sorting']} persist groupId="search-complexity">
  <Tab value="Basic Sorting">
    Control result ordering:

    ```python
    # Most relevant first (default with query)
    search_datasets(
      query="population",
      sort="relevance+desc",
      limit=10
    )

    # Most recently modified first
    search_datasets(
      query="",
      sort="modified+desc",
      limit=10
    )

    # Alphabetical by title
    search_datasets(
      query="",
      sort="title+asc",
      limit=10
    )
    ```

    **Available sort options:**
    - `relevance+desc` / `relevance+asc` - By search relevance (requires query)
    - `modified+desc` / `modified+asc` - By modification date
    - `issued+desc` / `issued+asc` - By publication date
    - `title+asc` / `title+desc` - Alphabetical
  </Tab>

  <Tab value="Advanced Sorting">
    Combine sorting with filters for targeted discovery:

    ```python
    # Most relevant high-quality health data
    search_datasets(
      query="health statistics",
      themes=["HEAL"],
      quality_boost=True,
      sort="relevance+desc",
      limit=10
    )

    # Recently published datasets, sorted by relevance
    search_datasets(
      query="climate",
      issued_since="2024-01-01",
      sort="relevance+desc",
      limit=10
    )

    # Oldest datasets from a publisher (historical data)
    search_datasets(
      query="",
      publishers=["Statistik Austria"],
      sort="issued+asc",
      limit=10
    )

    # Recently updated datasets across all categories
    search_datasets(
      query="",
      sort="modified+desc",
      limit=50
    )
    ```
  </Tab>
</Tabs>

## Pagination

<Tabs items={['Basic Pagination', 'Advanced Pagination']} persist groupId="search-complexity">
  <Tab value="Basic Pagination">
    Work with large result sets:

    ```python
    # Get first page (10 results)
    page1 = search_datasets(
      query="data",
      limit=10,
      offset=0
    )

    # Get second page (next 10 results)
    page2 = search_datasets(
      query="data",
      limit=10,
      offset=10
    )

    # Get third page
    page3 = search_datasets(
      query="data",
      limit=10,
      offset=20
    )
    ```

    **Result metadata:**
    - `count` - Total number of matching datasets
    - `results` - Array of datasets for current page

    Calculate total pages: `total_pages = ceil(count / limit)`
  </Tab>

  <Tab value="Advanced Pagination">
    Implement complete pagination with iteration:

    ```python
    # Paginate through all results
    all_results = []
    limit = 20
    offset = 0

    while True:
      page = search_datasets(
        query="environment",
        themes=["ENVI"],
        limit=limit,
        offset=offset
      )

      all_results.extend(page['results'])

      # Check if more pages exist
      if offset + limit >= page['count']:
        break

      offset += limit

    print(f"Retrieved {len(all_results)} total datasets")

    # Smart pagination with progress tracking
    def fetch_all_datasets(query, **filters):
      results = []
      limit = 50  # Larger page size for efficiency
      offset = 0
      total = None

      while True:
        page = search_datasets(
          query=query,
          limit=limit,
          offset=offset,
          **filters
        )

        if total is None:
          total = page['count']

        results.extend(page['results'])
        progress = len(results) / total * 100

        print(f"Progress: {progress:.1f}% ({len(results)}/{total})")

        if offset + limit >= page['count']:
          break

        offset += limit

      return results
    ```
  </Tab>
</Tabs>

## Quality-Aware Search

<Tabs items={['Enable Quality Boost', 'Quality-Driven Search']} persist groupId="search-complexity">
  <Tab value="Enable Quality Boost">
    Boost high-quality datasets in results:

    ```python
    # Prioritize complete, well-documented datasets
    search_datasets(
      query="health",
      quality_boost=True,
      limit=10
    )

    # Compare with and without quality boost
    without_boost = search_datasets(query="health", limit=10)
    with_boost = search_datasets(query="health", quality_boost=True, limit=10)
    ```

    Quality boost considers:
    - Metadata completeness (8 components)
    - Title and description presence
    - Keywords and categories
    - Publisher information
    - License clarity
    - Contact information
    - Temporal and spatial coverage
    - Documentation quality

    Score range: 0-100
  </Tab>

  <Tab value="Quality-Driven Search">
    Build workflows around quality metrics:

    ```python
    # Find high-quality recent datasets
    search_datasets(
      query="",
      themes=["HEAL"],
      modified_since="2024-01-01",
      quality_boost=True,
      sort="modified+desc",
      limit=20
    )

    # Production-ready datasets (high quality + accessible formats)
    search_datasets(
      query="statistics",
      formats=["CSV", "JSON"],
      quality_boost=True,
      sort="relevance+desc",
      limit=10
    )

    # Comprehensive search for well-documented data
    search_datasets(
      query="environment climate",
      themes=["ENVI", "ENER"],
      formats=["CSV"],
      modified_since="2023-01-01",
      quality_boost=True,
      sort="relevance+desc",
      limit=20
    )
    ```

    **Quality boost strategy:**
    - Use for production workflows
    - Combine with format filters (CSV, JSON) for API-ready data
    - Sort by relevance to get best quality AND most relevant
    - Filter by recent modification for maintained datasets
  </Tab>
</Tabs>
