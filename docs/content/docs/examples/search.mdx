# Search Examples

Master dataset discovery with these practical search examples.

## Basic Text Search

Simple keyword search across all datasets:

```python
# Search for population-related datasets
search_datasets(query="population", limit=10)

# Search for environmental data
search_datasets(query="environment", limit=10)

# Search for traffic data
search_datasets(query="traffic", limit=10)
```

**Tips:**
- Use German keywords for better results (most datasets are in German)
- The API searches titles, descriptions, and keywords
- Relevance-based ranking is applied automatically

## Filtered Search

### By Category

Filter by EU DCAT-AP theme codes:

```python
# Health datasets only
search_datasets(
  query="statistics",
  themes=["HEAL"],
  limit=10
)

# Environment OR Energy datasets
search_datasets(
  query="climate",
  themes=["ENVI", "ENER"],
  limit=10
)

# Population and society data
search_datasets(
  query="demographics",
  themes=["SOCI"],
  limit=10
)
```

**All 13 EU theme codes:**
- `AGRI` - Agriculture, fisheries, forestry and food
- `ECON` - Economy and finance
- `EDUC` - Education, culture and sport
- `ENER` - Energy
- `ENVI` - Environment
- `GOVE` - Government and public sector
- `HEAL` - Health
- `INTR` - International issues
- `JUST` - Justice, legal system and public safety
- `REGI` - Regions and cities
- `SOCI` - Population and society
- `TECH` - Science and technology
- `TRAN` - Transport

### By Format

Filter by available file formats:

```python
# CSV datasets only
search_datasets(
  query="data",
  formats=["CSV"],
  limit=10
)

# JSON or XML datasets
search_datasets(
  query="api",
  formats=["JSON", "XML"],
  limit=10
)

# Excel files
search_datasets(
  query="statistics",
  formats=["XLSX"],
  limit=10
)
```

**Common formats:** CSV, JSON, XML, XLSX, PDF, HTML, RDF, SHP (shapefile)

### By Publisher

Filter by publishing organization:

```python
# Data from Vienna
search_datasets(
  query="",
  publishers=["Stadt Wien"],
  limit=10
)

# Federal government datasets
search_datasets(
  query="",
  publishers=["Bundesministerium"],
  limit=10
)
```

### Combined Filters

Combine multiple filters for precise results:

```python
# CSV health data from Vienna
search_datasets(
  query="health",
  themes=["HEAL"],
  formats=["CSV"],
  publishers=["Stadt Wien"],
  limit=10
)
```

## Date Range Filtering

Filter by modification or publication date:

```python
# Datasets modified in 2024
search_datasets(
  query="",
  modified_since="2024-01-01",
  modified_until="2024-12-31",
  limit=10
)

# Recently updated datasets (last 30 days)
search_datasets(
  query="",
  modified_since="2024-12-15",
  limit=10
)

# Datasets published before 2020
search_datasets(
  query="",
  issued_until="2020-01-01",
  limit=10
)
```

**Date format:** ISO 8601 (YYYY-MM-DD)

## Sorting Options

Control result ordering:

```python
# Most relevant first (default with query)
search_datasets(
  query="population",
  sort="relevance+desc",
  limit=10
)

# Most recently modified first
search_datasets(
  query="",
  sort="modified+desc",
  limit=10
)

# Alphabetical by title
search_datasets(
  query="",
  sort="title+asc",
  limit=10
)

# Recently published datasets
search_datasets(
  query="",
  sort="issued+desc",
  limit=10
)
```

**Available sort options:**
- `relevance+desc` / `relevance+asc` - By search relevance (requires query)
- `modified+desc` / `modified+asc` - By modification date
- `issued+desc` / `issued+asc` - By publication date
- `title+asc` / `title+desc` - Alphabetical

## Pagination

Work with large result sets:

```python
# Get first page (10 results)
page1 = search_datasets(
  query="data",
  limit=10,
  offset=0
)

# Get second page (next 10 results)
page2 = search_datasets(
  query="data",
  limit=10,
  offset=10
)

# Get third page
page3 = search_datasets(
  query="data",
  limit=10,
  offset=20
)
```

**Result metadata:**
- `count` - Total number of matching datasets
- `results` - Array of datasets for current page

Calculate total pages: `total_pages = ceil(count / limit)`

## Quality-Aware Search

Boost high-quality datasets in results:

```python
# Prioritize complete, well-documented datasets
search_datasets(
  query="health",
  quality_boost=True,
  limit=10
)
```

Quality boost considers:
- Metadata completeness (8 components)
- Title and description presence
- Keywords and categories
- Publisher information
- License clarity
- Contact information
- Temporal and spatial coverage
- Documentation quality

Score range: 0-100

## Advanced Search Patterns

### Multi-theme Discovery

Find datasets that span multiple domains:

```python
# Climate and energy data
search_datasets(
  query="renewable",
  themes=["ENVI", "ENER"],
  limit=10
)
```

### Format Comparison

Compare availability across formats:

```python
# Find if data is available as both CSV and JSON
csv_results = search_datasets(query="statistics", formats=["CSV"])
json_results = search_datasets(query="statistics", formats=["JSON"])
```

### Publisher Exploration

Explore what a publisher offers:

```python
# All datasets from a specific catalogue
search_datasets(
  query="",
  catalogues=["l9"],  # Stadt Wien catalogue ID
  limit=50
)
```
