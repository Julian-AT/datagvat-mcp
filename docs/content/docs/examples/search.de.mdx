# Suchbeispiele

Meistern Sie die Datensatzsuche mit diesen praktischen Beispielen.

## Einfache Textsuche

<Tabs items={['Einfach', 'Erweitert']} persist groupId="search-complexity">
  <Tab value="Einfach">
    Einfache Schlüsselwortsuche über alle Datensätze:

    ```python
    # Suche nach Bevölkerungsdaten
    search_datasets(query="Bevölkerung", limit=10)

    # Suche nach Umweltdaten
    search_datasets(query="Umwelt", limit=10)

    # Suche nach Verkehrsdaten
    search_datasets(query="Verkehr", limit=10)
    ```

    **Tipps:**
    - Verwenden Sie deutsche Schlüsselwörter für bessere Ergebnisse (die meisten Datensätze sind auf Deutsch)
    - Die API durchsucht Titel, Beschreibungen und Schlüsselwörter
    - Relevanzbasiertes Ranking wird automatisch angewendet
  </Tab>

  <Tab value="Erweitert">
    Erweiterte Suche mit Fuzzy-Matching und Wildcards:

    ```python
    # Fuzzy-Suche (findet ähnliche Begriffe)
    search_datasets(query="Gesundheit~", limit=10)

    # Wildcard-Suche
    search_datasets(query="Daten*", limit=10)

    # Phrasensuche mit exakter Übereinstimmung
    search_datasets(query='"Luftqualität"', limit=10)

    # Bestimmte Begriffe verstärken
    search_datasets(query="Umwelt^2 Klima", limit=10)
    ```

    **Erweiterte Funktionen:**
    - `~` Suffix aktiviert Fuzzy-Matching
    - `*` passt auf null oder mehr Zeichen
    - `"..."` erfordert exakte Phrase
    - `^N` verstärkt die Bedeutung des Begriffs
  </Tab>
</Tabs>

## Gefilterte Suche

### Nach Kategorie

<Tabs items={['Einzelne Kategorie', 'Mehrere Kategorien']} persist groupId="search-complexity">
  <Tab value="Einzelne Kategorie">
    Filtern nach einem einzelnen EU DCAT-AP Thema:

    ```python
    # Nur Gesundheitsdaten
    search_datasets(
      query="Statistiken",
      themes=["HEAL"],
      limit=10
    )

    # Umweltdaten
    search_datasets(
      query="Klima",
      themes=["ENVI"],
      limit=10
    )

    # Bevölkerungs- und Gesellschaftsdaten
    search_datasets(
      query="Demographie",
      themes=["SOCI"],
      limit=10
    )
    ```
  </Tab>

  <Tab value="Mehrere Kategorien">
    Mehrere Themen kombinieren (ODER-Logik):

    ```python
    # Umwelt- ODER Energiedaten
    search_datasets(
      query="Klima",
      themes=["ENVI", "ENER"],
      limit=10
    )

    # Gesundheits- ODER Sozialdaten
    search_datasets(
      query="Statistiken",
      themes=["HEAL", "SOCI"],
      limit=10
    )

    # Regierungs- ODER Justizdaten
    search_datasets(
      query="öffentlich",
      themes=["GOVE", "JUST"],
      limit=10
    )
    ```
  </Tab>
</Tabs>

**Alle 13 EU-Themencodes:**
- `AGRI` - Landwirtschaft, Fischerei, Forstwirtschaft und Nahrungsmittel
- `ECON` - Wirtschaft und Finanzen
- `EDUC` - Bildung, Kultur und Sport
- `ENER` - Energie
- `ENVI` - Umwelt
- `GOVE` - Regierung und öffentlicher Sektor
- `HEAL` - Gesundheit
- `INTR` - Internationale Themen
- `JUST` - Justiz, Rechtssystem und öffentliche Sicherheit
- `REGI` - Regionen und Städte
- `SOCI` - Bevölkerung und Gesellschaft
- `TECH` - Wissenschaft und Technologie
- `TRAN` - Verkehr

## Datumsbereichsfilterung

<Tabs items={['Einfache Datumsfilter', 'Komplexe Datumsfilter']} persist groupId="search-complexity">
  <Tab value="Einfache Datumsfilter">
    Filtern nach Änderungs- oder Veröffentlichungsdatum:

    ```python
    # Im Jahr 2024 geänderte Datensätze
    search_datasets(
      query="",
      modified_since="2024-01-01",
      modified_until="2024-12-31",
      limit=10
    )

    # Kürzlich aktualisierte Datensätze (letzte 30 Tage)
    search_datasets(
      query="",
      modified_since="2024-12-15",
      limit=10
    )

    # Vor 2020 veröffentlichte Datensätze
    search_datasets(
      query="",
      issued_until="2020-01-01",
      limit=10
    )
    ```

    **Datumsformat:** ISO 8601 (YYYY-MM-DD)
  </Tab>

  <Tab value="Komplexe Datumsfilter">
    Datumsfilter mit anderen Kriterien kombinieren:

    ```python
    # Aktuelle Gesundheitsdaten aus Wien
    search_datasets(
      query="Gesundheit",
      themes=["HEAL"],
      publishers=["Stadt Wien"],
      modified_since="2024-01-01",
      sort="modified+desc",
      limit=10
    )

    # 2023 veröffentlichte, 2024 aktualisierte Datensätze
    search_datasets(
      query="",
      issued_since="2023-01-01",
      issued_until="2023-12-31",
      modified_since="2024-01-01",
      limit=10
    )

    # Legacy-Datensätze (vor 2020 veröffentlicht), die noch aktualisiert werden
    search_datasets(
      query="",
      issued_until="2020-01-01",
      modified_since="2024-01-01",
      sort="modified+desc",
      limit=10
    )
    ```
  </Tab>

## Sortieroptionen

<Tabs items={['Einfache Sortierung', 'Erweiterte Sortierung']} persist groupId="search-complexity">
  <Tab value="Einfache Sortierung">
    Steuerung der Ergebnisreihenfolge:

    ```python
    # Am relevantesten zuerst (Standard bei Abfrage)
    search_datasets(
      query="Bevölkerung",
      sort="relevance+desc",
      limit=10
    )

    # Zuletzt geändert zuerst
    search_datasets(
      query="",
      sort="modified+desc",
      limit=10
    )

    # Alphabetisch nach Titel
    search_datasets(
      query="",
      sort="title+asc",
      limit=10
    )
    ```

    **Verfügbare Sortieroptionen:**
    - `relevance+desc` / `relevance+asc` - Nach Suchrelevanz (erfordert Abfrage)
    - `modified+desc` / `modified+asc` - Nach Änderungsdatum
    - `issued+desc` / `issued+asc` - Nach Veröffentlichungsdatum
    - `title+asc` / `title+desc` - Alphabetisch
  </Tab>

  <Tab value="Erweiterte Sortierung">
    Sortierung mit Filtern für gezielte Suche kombinieren:

    ```python
    # Relevanteste hochwertige Gesundheitsdaten
    search_datasets(
      query="Gesundheit Statistiken",
      themes=["HEAL"],
      quality_boost=True,
      sort="relevance+desc",
      limit=10
    )

    # Kürzlich veröffentlichte Datensätze, nach Relevanz sortiert
    search_datasets(
      query="Klima",
      issued_since="2024-01-01",
      sort="relevance+desc",
      limit=10
    )

    # Älteste Datensätze eines Herausgebers (historische Daten)
    search_datasets(
      query="",
      publishers=["Statistik Austria"],
      sort="issued+asc",
      limit=10
    )

    # Kürzlich aktualisierte Datensätze über alle Kategorien
    search_datasets(
      query="",
      sort="modified+desc",
      limit=50
    )
    ```
  </Tab>
</Tabs>

## Paginierung

<Tabs items={['Einfache Paginierung', 'Erweiterte Paginierung']} persist groupId="search-complexity">
  <Tab value="Einfache Paginierung">
    Arbeiten mit großen Ergebnismengen:

    ```python
    # Erste Seite (10 Ergebnisse)
    seite1 = search_datasets(
      query="Daten",
      limit=10,
      offset=0
    )

    # Zweite Seite (nächste 10 Ergebnisse)
    seite2 = search_datasets(
      query="Daten",
      limit=10,
      offset=10
    )

    # Dritte Seite
    seite3 = search_datasets(
      query="Daten",
      limit=10,
      offset=20
    )
    ```

    **Ergebnis-Metadaten:**
    - `count` - Gesamtzahl übereinstimmender Datensätze
    - `results` - Array von Datensätzen für aktuelle Seite

    Gesamtseitenzahl berechnen: `gesamt_seiten = ceil(count / limit)`
  </Tab>

  <Tab value="Erweiterte Paginierung">
    Vollständige Paginierung mit Iteration implementieren:

    ```python
    # Durch alle Ergebnisse paginieren
    alle_ergebnisse = []
    limit = 20
    offset = 0

    while True:
      seite = search_datasets(
        query="Umwelt",
        themes=["ENVI"],
        limit=limit,
        offset=offset
      )

      alle_ergebnisse.extend(seite['results'])

      # Prüfen, ob weitere Seiten existieren
      if offset + limit >= seite['count']:
        break

      offset += limit

    print(f"{len(alle_ergebnisse)} Datensätze insgesamt abgerufen")

    # Intelligente Paginierung mit Fortschrittsverfolgung
    def hole_alle_datensaetze(query, **filter):
      ergebnisse = []
      limit = 50  # Größere Seitengröße für Effizienz
      offset = 0
      gesamt = None

      while True:
        seite = search_datasets(
          query=query,
          limit=limit,
          offset=offset,
          **filter
        )

        if gesamt is None:
          gesamt = seite['count']

        ergebnisse.extend(seite['results'])
        fortschritt = len(ergebnisse) / gesamt * 100

        print(f"Fortschritt: {fortschritt:.1f}% ({len(ergebnisse)}/{gesamt})")

        if offset + limit >= seite['count']:
          break

        offset += limit

      return ergebnisse
    ```
  </Tab>
</Tabs>

## Qualitätsbewusste Suche

<Tabs items={['Qualitätsverstärkung aktivieren', 'Qualitätsgetriebene Suche']} persist groupId="search-complexity">
  <Tab value="Qualitätsverstärkung aktivieren">
    Hochwertige Datensätze in den Ergebnissen bevorzugen:

    ```python
    # Vollständige, gut dokumentierte Datensätze priorisieren
    search_datasets(
      query="Gesundheit",
      quality_boost=True,
      limit=10
    )

    # Mit und ohne Qualitätsverstärkung vergleichen
    ohne_boost = search_datasets(query="Gesundheit", limit=10)
    mit_boost = search_datasets(query="Gesundheit", quality_boost=True, limit=10)
    ```

    Qualitätsverstärkung berücksichtigt:
    - Metadatenvollständigkeit (8 Komponenten)
    - Vorhandensein von Titel und Beschreibung
    - Schlüsselwörter und Kategorien
    - Herausgeberinformationen
    - Lizenzklarheit
    - Kontaktinformationen
    - Zeitliche und räumliche Abdeckung
    - Dokumentationsqualität

    Bewertungsbereich: 0-100
  </Tab>

  <Tab value="Qualitätsgetriebene Suche">
    Workflows um Qualitätsmetriken aufbauen:

    ```python
    # Hochwertige aktuelle Datensätze finden
    search_datasets(
      query="",
      themes=["HEAL"],
      modified_since="2024-01-01",
      quality_boost=True,
      sort="modified+desc",
      limit=20
    )

    # Produktionsreife Datensätze (hohe Qualität + zugängliche Formate)
    search_datasets(
      query="Statistiken",
      formats=["CSV", "JSON"],
      quality_boost=True,
      sort="relevance+desc",
      limit=10
    )

    # Umfassende Suche nach gut dokumentierten Daten
    search_datasets(
      query="Umwelt Klima",
      themes=["ENVI", "ENER"],
      formats=["CSV"],
      modified_since="2023-01-01",
      quality_boost=True,
      sort="relevance+desc",
      limit=20
    )
    ```

    **Qualitätsverstärkung-Strategie:**
    - Für Produktions-Workflows verwenden
    - Mit Formatfiltern (CSV, JSON) für API-bereite Daten kombinieren
    - Nach Relevanz sortieren für beste Qualität UND höchste Relevanz
    - Nach aktueller Änderung filtern für gewartete Datensätze
  </Tab>
</Tabs>

### Herausgeber-Erkundung

<Tabs items={['Einfache Erkundung', 'Erweiterte Erkundung']} persist groupId="search-complexity">

  <Tab value="Erweiterte Erkundung">
    Umfassende Herausgeberanalyse:

    ```python
    # Aktuelle Gesundheitsdaten aus Wien
    search_datasets(
      query="",
      publishers=["Stadt Wien"],
      themes=["HEAL"],
      modified_since="2023-01-01",
      sort="modified+desc",
      limit=50
    )

    # Herausgebervergleich (Wien vs. Bundesebene)
    wien_daten = search_datasets(
      query="Verkehr",
      publishers=["Stadt Wien"],
      formats=["CSV"]
    )

    bund_daten = search_datasets(
      query="Verkehr",
      publishers=["Bundesministerium"],
      formats=["CSV"]
    )

    print(f"Wien: {wien_daten['count']} Verkehrsdatensätze")
    print(f"Bund: {bund_daten['count']} Verkehrsdatensätze")

    # Kategorienverteilung für einen Herausgeber
    alle_wien = search_datasets(
      query="",
      publishers=["Stadt Wien"],
      limit=100
    )

    # Themen analysieren
    themen_zaehler = {}
    for datensatz in alle_wien['results']:
      for kategorie in datensatz.get('categories', []):
        thema_id = kategorie.get('id')
        themen_zaehler[thema_id] = themen_zaehler.get(thema_id, 0) + 1

    print("\nWien Themenverteilung:")
    for thema, anzahl in sorted(themen_zaehler.items(), key=lambda x: x[1], reverse=True):
      print(f"  {thema}: {anzahl} Datensätze")
    ```
