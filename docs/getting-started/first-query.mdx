# Your First Query

Learn how to perform a complete dataset discovery workflow with Austria MCP - from search to data preview.

## Prerequisites

Before starting, ensure you have:

- [ ] Completed the [Quickstart Guide](/getting-started/quickstart)
- [ ] Claude Desktop running with Austria MCP connected
- [ ] MCP server showing green status in toolbar

<Callout type="info">
**New to Austria MCP?** Complete the [Quickstart Guide](/getting-started/quickstart) first for a quick introduction.
</Callout>

## Step 1: Search for Datasets

Let's search for Vienna population data using semantic search:

```
Find datasets about Vienna population statistics
```

**What happens:**
- Austria MCP analyzes "Vienna population statistics"
- Expands query with related terms (demographics, census, inhabitants)
- Searches data.gv.at catalog
- Returns results ranked by quality and relevance

**Expected output:**

```json
{
  "results": [
    {
      "id": "17f04f16-1c02-4f94-90e3-e27e92535a83",
      "title": "Vienna Population Statistics 2023",
      "description": "Aktuelle Bevölkerungsstatistik der Stadt Wien...",
      "publisher": "Stadt Wien",
      "themes": ["SOCI"],
      "formats": ["CSV", "JSON"],
      "quality_score": 95,
      "last_modified": "2024-01-15"
    },
    {
      "id": "8d2c1e4a-5b7f-4d8c-9e3a-2f1b6c8d4e9a",
      "title": "Vienna Demographics Historical Data",
      "description": "Demografische Entwicklung Wien 2000-2023...",
      "publisher": "Statistik Austria",
```

**Verify:**
- [ ] You received dataset results with titles and IDs
- [ ] Quality scores appear (0-100 range)
- [ ] Results include publisher and format information

## Step 2: Get Dataset Details

Pick a dataset from results and get complete metadata:

```
Show me details for dataset 17f04f16-1c02-4f94-90e3-e27e92535a83
```

**What happens:**
- Austria MCP calls `get_dataset` tool with dataset ID
- Retrieves full DCAT-AP metadata from data.gv.at
- Returns structured dataset information

**Expected output:**

```json
{
  "id": "17f04f16-1c02-4f94-90e3-e27e92535a83",
  "title": "Vienna Population Statistics 2023",
  "description": "Aktuelle Bevölkerungsstatistik der Stadt Wien nach Bezirken, Geschlecht und Altersgruppen. Die Daten werden monatlich aktualisiert und umfassen alle 23 Wiener Gemeindebezirke.",
  "publisher": {
    "name": "Stadt Wien",
    "email": "open@post.wien.gv.at"
  },
  "themes": ["SOCI"],
  "keywords": ["Bevölkerung", "Wien", "Statistik", "Demografie"],
  "license": "CC-BY-4.0",
  "temporal_coverage": {
    "start": "2023-01-01",
    "end": "2023-12-31"
  },
  "spatial_coverage": "Wien, Österreich",
  "distributions": [
    {
      "title": "Population Data CSV",
      "format": "CSV",
      "access_url": "https://www.data.gv.at/katalog/dataset/population-vienna-2023.csv"
    },
    {
      "title": "Population Data JSON",
      "format": "JSON",
      "access_url": "https://www.data.gv.at/katalog/dataset/population-vienna-2023.json"
    }
  ],
  "last_modified": "2024-01-15",
  "quality_score": 95
}
```

**Verify:**
- [ ] Full description in German
- [ ] License information (CC-BY-4.0)
- [ ] Multiple distributions with download URLs
- [ ] Temporal and spatial coverage details

<Callout type="warn">
**Dataset IDs:** Always use exact IDs from search results. IDs are unique identifiers and case-sensitive.
</Callout>

## Step 3: Get Dataset Distributions

Before previewing data, get the list of available download formats:

```
List distributions for dataset 17f04f16-1c02-4f94-90e3-e27e92535a83
```

**What happens:**
- Austria MCP extracts distribution information
- Returns all available download formats and URLs
- Shows file sizes and modification dates

**Expected output:**

```json
[
  {
    "title": "Population Data CSV",
    "format": "CSV",
    "access_url": "https://www.data.gv.at/katalog/dataset/population-vienna-2023.csv",
    "byte_size": 45678,
    "modified": "2024-01-15"
  },
  {
    "title": "Population Data JSON",
    "format": "JSON",
    "access_url": "https://www.data.gv.at/katalog/dataset/population-vienna-2023.json",
    "byte_size": 67890,
    "modified": "2024-01-15"
  }
]
```

**Verify:**
- [ ] Each distribution shows format (CSV, JSON, etc.)
- [ ] Access URLs are provided
- [ ] File sizes appear in bytes

## Step 4: Preview Data

Now preview the CSV data to see structure and sample rows:

```
Preview data from https://www.data.gv.at/katalog/dataset/population-vienna-2023.csv
```

**What happens:**
- Austria MCP downloads first 64KB of file
- Detects CSV format and delimiter
- Infers column types from sample rows
- Returns schema and preview data

**Expected output:**

```json
{
  "format": "CSV",
  "rows_previewed": 20,
  "total_rows_estimate": 276,
  "schema": {
    "columns": [
      {
        "name": "Bezirk",
        "type": "string",
        "sample_values": ["1. Innere Stadt", "2. Leopoldstadt", "3. Landstraße"]
      },
      {
        "name": "Geschlecht",
        "type": "string",
        "sample_values": ["männlich", "weiblich", "divers"]
      },
      {
        "name": "Altersgruppe",
        "type": "string",
        "sample_values": ["0-14", "15-24", "25-64"]
      },
      {
        "name": "Bevölkerung",
        "type": "integer",
        "sample_values": [12543, 23678, 45123]
      }
    ]
  },
  "preview": [
    ["Bezirk", "Geschlecht", "Altersgruppe", "Bevölkerung"],
    ["1. Innere Stadt", "männlich", "0-14", "1234"],
    ["1. Innere Stadt", "männlich", "15-24", "2345"],
    ["1. Innere Stadt", "männlich", "25-64", "8765"],
    ["1. Innere Stadt", "weiblich", "0-14", "1123"],
    ["1. Innere Stadt", "weiblich", "15-24", "2456"],
    ["2. Leopoldstadt", "männlich", "0-14", "3456"],
    ["2. Leopoldstadt", "männlich", "15-24", "4567"],
    ["2. Leopoldstadt", "männlich", "25-64", "12345"],
    ["3. Landstraße", "männlich", "0-14", "2345"],
    ["3. Landstraße", "männlich", "15-24", "3456"]
  ]
}
```

**Verify:**
- [ ] Schema shows column names and types
- [ ] Preview includes header row
- [ ] Sample values demonstrate data format
- [ ] Row estimates help understand dataset size

<Callout type="info">
**Preview limits:** Default preview is 20 rows, configurable up to 100. Large datasets are estimated from preview sample.
</Callout>
