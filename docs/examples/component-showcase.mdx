# Component Showcase

This page demonstrates all interactive components used throughout Austria MCP documentation.

## Progressive Disclosure with Tabs

<Tabs items={['Basic', 'Advanced']} groupId="search-complexity" persist>
  <Tab value="Basic">
    ### Basic Dataset Search

    Simple text search for datasets:

    ```typescript
    const results = await mcp.callTool('search_datasets', {
      query: 'gesundheit wien'
    });

    console.log(`Found ${results.count} datasets`);
    ```

    This returns up to 20 datasets matching "gesundheit wien".
  </Tab>

  <Tab value="Advanced">
    ### Advanced Search with Filters

    Search with faceted filtering and quality boost:

    ```typescript
    const results = await mcp.callTool('search_datasets', {
      query: 'gesundheit wien',
      filters: {
        organization: 'Stadt Wien',
        tags: ['Gesundheit', 'COVID-19'],
        license: 'cc-by'
      },
      limit: 50,
      quality_boost: true
    });

    // Access facets for filter UI
    console.log('Available orgs:', results.facets.organization);
    ```

    Quality boost re-ranks results by metadata completeness.
  </Tab>
</Tabs>

**Tab behavior verification:**
- Switch tabs → selection persists across page reload (localStorage)
- `groupId="search-complexity"` → same selection on other pages with same groupId
- Mobile responsive → tabs stack vertically on narrow screens

## Scannable Reference with Accordion

<Accordions type="single" collapsible>
  <Accordion title="search_datasets" id="search-datasets">
    Full-text search across the Data.gv.at catalog with faceted filtering.

    ### Parameters

    <TypeTable type={{
      query: {
        type: "string",
        description: "Search query for titles, descriptions, keywords"
      },
      limit: {
        type: "number",
        default: 20,
        description: "Maximum number of results (1-100)"
      },
      filters: {
        type: "object",
        description: "Faceted filters (organization, tags, license, format)",
        default: {}
      },
      quality_boost: {
        type: "boolean",
        default: false,
        description: "Re-rank by metadata quality (DQV score)"
      }
    }} />

    ### Returns

    ```json
    {
      "count": 42,
      "results": [
        {
          "id": "dataset-id",
          "title": "Gesundheitsdaten Wien",
          "description": "...",
          "tags": ["Gesundheit"],
          "organization": "Stadt Wien"
        }
      ],
      "facets": {
        "organization": ["Stadt Wien", "..."],
        "tags": ["Gesundheit", "COVID-19"]
      }
    }
    ```

    ### Example

    ```typescript
    const results = await mcp.callTool('search_datasets', {
      query: 'health',
      limit: 10
    });
    ```
  </Accordion>

  <Accordion title="get_dataset" id="get-dataset">
    Retrieve detailed metadata for a specific dataset by ID.

    ### Parameters

    <TypeTable type={{
      id: {
        type: "string",
        description: "Dataset identifier from search results"
      }
    }} />

    ### Returns

    Full dataset metadata including distributions, quality metrics, and temporal coverage.

    ### Example

    ```typescript
    const dataset = await mcp.callTool('get_dataset', {
      id: 'some-dataset-id'
    });

    console.log('Quality score:', dataset.quality.score);
    ```
  </Accordion>

  <Accordion title="preview_dataset" id="preview-dataset">
    Preview dataset contents (first 64KB) with schema inference.

    ### Parameters

    <TypeTable type={{
      url: {
        type: "string",
        description: "Distribution URL (CSV, JSON, XML)"
      },
      format: {
        type: "string",
        description: "Data format (auto-detected if omitted)"
      }
    }} />

    ### Example

    ```typescript
    const preview = await mcp.callTool('preview_dataset', {
      url: 'https://data.gv.at/.../file.csv'
    });

    console.log('Columns:', preview.schema.columns);
    console.log('Sample:', preview.sample_data);
    ```
  </Accordion>
</Accordions>

**Accordion behavior verification:**
- Only one accordion open at a time (`type="single"`)
- URL hash `#search-datasets` auto-expands correct accordion
- Keyboard navigation: Tab/Enter to expand, Escape to collapse
- Mobile responsive → full-width on narrow screens
