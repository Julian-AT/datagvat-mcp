Access Austria's 60,000+ open government datasets through Claude Desktop and other MCP-compatible AI tools.

## Installation

```bash
uvx datagvat-mcp init
```

The installer detects your AI tools and configures them automatically. See the [Installation Guide](/docs/installation) for details.

## Example Query

Ask Claude Desktop:

```
Find datasets about Vienna population
```

The MCP server searches data.gv.at, ranks results by quality, and returns structured metadata including download links.
