## What you can do

**Search and discovery**
Find datasets using keyword search, theme filters, or semantic search with automatic query expansion.

**Data preview**
Inspect CSV and JSON data before downloading. View structure, types, and sample rows.

**Quality analysis**
Get quality scores (0-100) based on metadata completeness.

**Related datasets**
Discover similar datasets by shared themes, keywords, or publisher.

## Example queries

Ask Claude in natural language:

- "Find health datasets from Vienna"
- "Show me high-quality datasets about population statistics"
- "Preview the first 20 rows of that CSV"
- "What datasets are related to this one?"
